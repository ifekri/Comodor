# كيف يتعلّم

معظم الوكلاء ينسون لحظة انتهاء الجلسة. أما هذا فيراقب ما تغيّره في مخرجاته ويحفظه.

---

## الفكرة

المدح رخيص والتصحيحات مكلفة، فالتصحيحات هي ما يتعلّم منها.

عندما تعدّل ملفًا كتبه، أو تخبره صراحةً أنه أخطأ، يصبح ذلك **درسًا**: قاعدة قصيرة مع ثقة ترتفع في كل مرة تصح فيها وتتلاشى إذا لم تُستخدم. وتُستدعى الدروس عندما تبدو الحالة مشابهة، وتُحقَن في ذلك الدور — لا في system prompt أبدًا، لأن ذلك سيكلّف ذاكرة prompt المؤقتة.

لا شيء يترك جهازك. والعقل ملف SQLite تحت دليل الإعدادات لديك.

---

## المساران

### Reflex — مجاني، فوري، دائم التشغيل

لا استدعاء نموذج، ولا توكنات، ولا تأخير.

- **التصحيحات.** تعدّل `"` إلى `'` في ملف كتبه. هذا فرق (diff)، والفرق حقيقة.
- **القواعد.** يقرأ شيفرةك القائمة مرة واحدة، في البداية، ويستخرج منها العادات — المسافة البادئة، وأسلوب علامات التنصيص، وكيفية تسمية الاختبارات.
- **الإعلانات.** عندما تُطبَّق قاعدة، يقول ذلك في سطر واحد. فالقاعدة التي لا تراها قاعدة لا تستطيع تصحيحها.
- **الجلب المسبق.** يبدأ الاستدعاء وأنت ما زلت تكتب.

وهذا المسار يعمل حتى عندما يكون Reflection مطفأًّ، لأنه لا يكلّف شيئًا.

### Reflection — استدعاء نموذج، بعد مهمة

في نهاية المهمة يطالع ما حدث ويدوّن ما ينبغي أن يتذكره. وهذا يكلّف استدعاءً. فاستخدم له نموذجًا أرخص إن أحببت:

```json
{ "learning": { "reflect_model": "claude-haiku-4-5" } }
```

أو أطفئه مع إبقاء Reflex:

```json
{ "learning": { "reflect": false } }
```

## تعليمه عمدًا

| | |
|---|---|
| `/good` | ذلك الجواب كان صحيحًا |
| `/bad` | ذلك الجواب كان خاطئًا |
| `/teach we use pytest, never unittest` | تذكّر هذا |

ولا يكلّفك `/good` و`/bad` سوى ضغطة مفتاح، وهما أرخص شيء يمكنك فعله له.

ورفضُ مطالبة إذن يعلّمه أيضًا. فالرفض أوضح إشارة تفضيل تجمعها الواجهة، وهو يُعامَل كذلك.

## الاستدعاء، ولماذا ليس في system prompt

الدروس المستدعاة تركب الدور، بوصفها جزءًا من رسالة المستخدم، لا في system prompt.

وهذا قرار تكلفة. فتخزين prompt المؤقت لا يعمل إلا على بادئة مطابقة بايتًا ببايت، وsystem prompt هو تلك البادئة. ووضع أي شيء معتمد على الاستعلام فيها يُبطل المخزن المؤقت في كل دور بلا استثناء. ونقل الاستدعاء إلى الدور رفع معدلات إصابة المخزن المقيسة من 72% إلى 87%. انظر [التكلفة](cost.md).

## الكلمات التي يتعلّمها منك

ويتعلّم أيضًا أي كلمات *من عندك* تسير معًا، من مهامك المنجزة — أن «the parser» و«tokenise» تنتميان إلى الزاوية نفسها من قاعدة الشيفرة لديك. وهذا لا يكلّف توكنات ولا استدعاء نموذج؛ إنه مجرد عدّ.

وهذا ما يتيح لدرس مدوَّن عن «the tokeniser» أن يظهر عندما تسأل عن «the lexer».

```json
{ "learning": { "associative": true } }
```

## النطاق

```json
{ "learning": { "share_scope": "project" } }
```

يبقي `project` الدروس في المستودع الذي تُعلِّمت فيه — وهو الافتراضي الصحيح، إذ العادة الصحيحة في قاعدة شيفرة خاطئة في أخرى. و`global` يشاركها في كل مكان.

---

## النسيان

الدرس الذي لا يُستخدم يتلاشى. ويضبط `half_life_days` (45 افتراضيًا) سرعة ذلك، و`min_confidence` (0.15) هو الحد الأدنى الذي يتحول دونها إلى عدم استدعاء.

وهذا مهم: فقاعدة الشيفرة تغيّر رأيها، والوكيل الذي يتمسك بعادة عمرها سنتان بثقة كاملة أسوأ من وكيل نسيها.
