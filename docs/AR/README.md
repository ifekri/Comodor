## أقصر نسخة ممكنة

```bash
curl -fsSL get.comodor.ai | sh      # macOS, Linux
irm get.comodor.ai | iex           # Windows

comodor                  # it asks a few questions, once
```

ثم اكتب ما تريد. صحّحه عندما يخطئ — عدّل الملف بنفسك أو قل ذلك فقط — ويتعلم.
يُظهر لك `/progress` ما إذا كان ذلك يعمل فعلًا.

```bash
comodor run "fix the failing test in tests/test_parser.py"   # one task, no interface
comodor web                                                  # from a browser
comodor doctor                                               # is everything alright?
comodor help                                                 # the written help page
```

## ما يميزه

**يتعلم من التصحيحات، لا من المدح.** معظم الوكلاء ينسون في اللحظة التي تنتهي
فيها الجلسة. يراقب Comodor ما تغيّره في مخرجاته ويحوّله إلى درس بدرجة ثقة
ترتفع عندما يثبت صحه وتنخفض عندما لا يثبت. يشرح [كيف يتعلم](learning.md)
الآلية؛ ويعرض `/progress` الدليل.

**يسأل قبل أن يتصرف، وكل شيء قابل للتراجع.** القراءة صامتة. الكتابة تسأل.
تشغيل أمر يسأل بصوت أعلى. كل كتابة محفوظة كنقطة استرجاع، ويعيد `/undo` آخر
واحدة منها. [السلامة والأذونات](safety.md).

**تبعية واحدة.** عميل HTTP، وقارئ SSE، وWebSocket الخاص بالمتصفح، ومشفّر PNG
للقطات الشاشة — كلها جزء من الحزمة. يُدخل تثبيت Comodor `rich` ولا شيء غيرها.

**يستطيع استخدام متصفح حقيقي وسطح مكتب حقيقي.** ليس مجرد جامع نصوص: متصفح
يشغّل JavaScript ويحفظ ملفات تعريف الارتباط، و — على Windows — الفأرة
ولوحة المفاتيح، مع هالة على الشاشة تبين لك أين سينقر.
[المتصفح](browser.md)، [الشاشة](computer.md).
