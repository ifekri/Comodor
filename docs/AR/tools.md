# ما يستطيع الوكيل فعله

ثلاث عشرة أداة. تصرح كل واحدة عن طبقة مخاطر، وهي التي تحدد ما إذا كانت ستسأل
أولًا — راجع [السلامة](safety.md#risk-tiers).

---

## الملفات

| | المخاطر | |
|---|---|---|
| `read_file` | safe | قراءة ملف نصي. بالبث، فيمكن الوصول إلى شريحة من سجل كبير |
| `list_dir` | safe | مداخل دليل، مع الأحجام |
| `glob` | safe | إيجاد الملفات بنمط اسم — `src/**/*.py` |
| `grep` | safe | البحث في المحتويات بتعبير نمطي |
| `write_file` | write | إنشاء ملف أو استبداله كليًا |
| `edit_file` | write | استبدال سلسلة حرفية بعينها في ملف |

كل شيء محصور في مجلد المشروع إلا إذا أوقفت `safety.workspace_only`.

يُفضَّل `edit_file` على `write_file` في تغيير لملف قائم: فهو أصغر، ويُراجع
كفرق diff، ولا يمكنه أن يُفقد صمتًا بقية الملف.

---

## تشغيل الأشياء

| | المخاطر | |
|---|---|---|
| `run_shell` | dangerous | أمر صدفة في مساحة العمل |
| `run_python` | dangerous | مقطع Python قصير، في عملية فرعية |

كلتاهما تسأل قبل التشغيل، وكلتاهما خاضعة لـ `safety.deny_commands`، ولكلتا حدود
لمخرجاتهما — راجع [حين تكون المخرجات كبيرة جدًا](#when-output-is-too-big).

في الواجهة يمكنك تجاوز النموذج كليًا:

```
!git status
```

يشغّله، ويعرض لك المخرجات، ولا يذكره للنموذج أبدًا. أسرع وأرخص من السؤال.

---

## الويب

| | المخاطر | |
|---|---|---|
| `web_fetch` | dangerous | تنزيل عنوان URL وإرجاع نصه المقروء |
| `web_search` | dangerous | البحث، وإرجاع العناوين وعناوين URL والمقتطفات |
| `browse` | dangerous | متصفح حقيقي — JavaScript وملفات تعريف الارتباط وتسجيلات الدخول |

`web_fetch` هي الرخيصة: تقلّع الصفحة إلى نص. استخدمها حين تكون الصفحة وثيقة.

و`browse` لحين تكون تطبيقًا — شيئًا يحتاج JavaScript أو تسجيل دخول أو نقرة.
[الدليل الكامل](browser.md).

## الآلة

| | المخاطر | |
|---|---|---|
| `computer` | dangerous | الفأرة ولوحة المفاتيح والشاشة، في أي تطبيق |

متوقفة إلا إذا شغّلتها، وحينئذ تبقى غير مسموحة حتى تُمنَح.
[الدليل الكامل](computer.md). على Windows وحده حتى الآن.

## متابعة المسار

| | المخاطر | |
|---|---|---|
| `todo_write` | safe | قائمة المهام التي تراها في الشريط الجانبي |

يكتب الوكيل خطته هنا. وليست زينة — إنها كيف تبقى المهمة الطويلة متماسكة، وكيف
ترى أين هو.

## أحيانًا موجودة، وأحيانًا لا

لا يعرض Comodor سوى أداة يستطيع النموذج استخدامها فعلًا. أما أداة يراها ولا
يستطيع استخدامها بنجاح قط فتدعو إلى نداء هادر في كل دور.

| | تظهر عندما |
|---|---|
| `read_skill_file` | تحتوي مهارة ثبّتها على ملفات |
| `search_history` | توجد جلسات سابقة للبحث فيها |
| `delegate` | يمكن إنشاء وكيل فرعي |
| `computer` | للمنصة نظام خلفي **و**أنك فعّلتها |
| أدوات MCP | خادم مضبوط ومفعّل |

لـ `browse` تنفيذان: المتصفح الحقيقي حين يكون Chrome أو Chromium أو Edge أو
Brave مثبتًا، ومتصفح نصي حين لا يكون كذلك. وكلتاهما تُدعى `browse`، لأن
الاختيار بين شيئين يُدعى «browser» دورٌ لا ينبغي أن يُنفق النموذج عليه.

## حين تكون المخرجات كبيرة جدًا

الأمر الذي يطبع خمسين ألف سطر لا يُقتطع إلى فقدان النفع، ولا يفجّر السياق.

ما يتسع يذهب إلى النموذج — الرأس والذيل، إذ هناك تكمن الإجابة عادة. والباقي
يُكتب في ملف تحت `~/.comodor/output/`، ويُخبَر النموذج بالمسار وكيف يقرؤه.
فهو يستطيع الذهاب والنظر إن احتاج، ولا يدفع شيئًا إن لم يكن.

```json
{ "agent": { "max_tool_chars": 12000 } }
```

## الوكلاء الفرعيون

يشغّل `delegate` وكيلًا ثانيًا في **git worktree** — نسخة عمل معزولة من
المستودع نفسه. يعمل هناك، وتعود تغييراته كرقعة تُطبق بدمج ثلاثي.

لا ذاكرة له، ولا يستطيع التفويض أبعد، ولا يُعطى الشاشة. ويرث إلغاء الأب،
فيوقفه `Esc` أيضًا.

مفيد لشيء منفصل فعلًا — «انقل هذه الوحدة إلى الواجهة البرمجية الجديدة بينما
أواصل أنا العمل» — ومسرف لكل شيء آخر.

## أدوات MCP

أي شيء يوفره خادم Model Context Protocol مفعّل يظهر بجوار الأدوات المدمجة
ويمر عبر بوابة الأذونات نفسها تمامًا.

```bash
comodor mcp list
```

[الدليل الكامل](mcp.md).
