# استكشاف الأخطاء وإصلاحها

## ابدأ من هنا

```bash
comodor doctor
```

يفحص ملف الإعدادات وأذوناته، والمزوّد، والنموذج، وحد الإنفاق، والعقل، وفهرس البحث، ومهاراتك، والملفات المتبقية، وخوادم MCP، وما إذا كان هناك إصدار أحدث.

```bash
comodor doctor --fix
```

يصلح ما يُصلَح. وهو لا يغيّر أبدًا شيئًا لم يبلّغ عنه أولًا.

---

## يرفض البدء

**`comodor: command not found`، مباشرة بعد التثبيت** — وضع المُثبِّت الأمر في `PATH` لديك، لكن العملية الابنة لا تستطيع تغيير بيئة الصَدَفة التي أنشأتها. وكل طرفية *جديدة* تعمل بالفعل. أما الطرفية التي أنت فيها فقد طبع المُثبِّت السطر الواجب لصقه؛ أو:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

**`comodor: command not found`، في طرفية جديدة** — هذه مشكلة حقيقية. يؤكد `python -m comodor` ما إذا كان مثبتًا أصلًا، و`ls ~/.local/bin/comodor` في الموضع الذي ينبغي أن يكون فيه.

**`No provider is configured`** — شغّل `comodor setup`، أو صدِّر مفتاحًا:

```bash
export ANTHROPIC_API_KEY=sk-ant-…
```

**Python قديم جدًا.** يحتاج Comodor إلى 3.11 أو أحدث. تحقق بـ`python --version`.

## إعداد يبدو أنه لا يفعل شيئًا

يخبرك Comodor عندما يرفض إعدادًا:

```
config: agent.max_steps must be a whole number; keeping 0
config: this project cannot set safety, computer — only your own can
```

فإن لم يقل شيئًا وبقي الإعداد بلا أثر، تحقق من أي طبقة تغلب:

```
/settings          # what is actually loaded
```

```bash
comodor doctor     # the same, plus where every file is
```

الوسيط `--model` في سطر الأوامر يغلّب ملف إعداداتك، والمفتاح في بيئتك يغلّب الموجود في الملف. وهذا مقصود —
[الإعدادات](configuration.md#what-wins).

---

## `/save` لم يحفظ ما توقعت

هذا بحكم التصميم. فهو يكتب **ما اخترته أنت فقط** — لا إعدادات مستودع، ولا مفتاحًا تحفظه في بيئتك، ولا علمًا (flag) مرّرته لتشغيل واحد.

ولتحويل إعداد مستودع إلى إعداد لك، اضبطه بنفسك أولًا (`/model x`) ثم احفظ.

## الطلبات تخفق

**`401` أو `invalid api key`** — المفتاح خاطئ أو منتهٍ أو يعود لمزوّد آخر. يعرض `comodor doctor` أي مزوّد نشط.

**`404 model not found`** — ذلك المزوّد لا يقدّم معرّف النموذج ذاك. يسرد `/model` ما يقدّمه فعلًا.

**انتهاء المهلة.** قد يستغرق نموذج محلي على جهاز متواضع دقائق فعلًا. ارفع `providers.<name>.timeout`.

**يتوقف مبكرًا.** انظر إلى `stopped`. فـ`max_steps` و`budget` سقفان يؤديان عملهما، لا إخفاقات. ارفعهما لتشغيل واحد عبر `--max-steps`، أو بشكل دائم تحت `agent`.

## أداة المتصفح

**«no browser found»** — ثبّت Chrome أو Chromium أو Edge أو Brave، أو اضبط `browser.executable`. ومن دون واحد يتراجع `browse` إلى متصفح نصّي ما يزال يجيب عن معظم الأسئلة حول الصفحة.

**أريد مشاهدة عمله** — `browser.headless: false`.

**يحتاج تسجيل دخول عندي مسبقًا** — شغّل متصفحك بنفسك مع منفذ DevTools واضبط `browser.port`، فيستخدم تلك الجلسة بدلًا من تسليمه ملف تعريفك.

## أداة الشاشة

**ليست في قائمة الأدوات.** إما أن لهذه المنصة لا خلفية — نظام Windows فقط حتى الآن — أو أن `computer.enabled` تساوي false. اسأله:

```
/computer
```

**النقرات تقع في المكان الخطأ.** هذا لا ينبغي أن يحدث: يُضبَط إبلاغ DPI قبل قراءة أي مقياس من الشاشة. فإن حدث، أرجو التبليغ عنه مع مقياس عرضك ودقتها. هذه علة حقيقية.

**توقف من تلقاء نفسه.** ذهبت الفأرة إلى زاوية من الشاشة، وهذا ينهي المنح عمدًا. ويبدأ `/computer 15m` منحًا آخر.

**النص الذي وصل ليس النص الذي كتبه.** أعاد التطبيق كتابته — فأداة Notepad في Windows 11 تصحح تلقائيًا أثناء الكتابة. ليس هذا علة في Comodor، وهو يقول ذلك مع كل `type`. [المزيد](computer.md#typed-is-not-the-same-as-arrived).

## واجهة الويب

**يرفض البدء.** لا مزوّد مضبوط، ولا سبيل لواجهة المتصفح لإضافة واحد. وتذكر الرسالة ما يجب ضبطه.

**«Unauthorised».** يُولَّد رمز جديد في كل تشغيل — استخدم الـ URL من التشغيل *الحالي*، أو اضبط `COMODOR_WEB_TOKEN` لإبقائه ثابتًا.

**في Docker، لا شيء على `localhost:8765`.** تحقق من نشر المنفذ بصيغة `127.0.0.1:8765:8765`. [Docker](docker.md).

---

## شيء ما بطيء

**أول طلب في جلسة.** لم يُخزَّن شيء بعد؛ والطلب الثاني أسرع بكثير.

**Reflection بعد كل مهمة.** استدعاء نموذج واحد. استخدم `learning.reflect_model` لنموذج أرخص، أو `reflect: false`.

**لقطات الشاشة.** نحو 80 ms لالتقاطها، إضافة إلى النموذج وهو ينظر إليها. اخفض `computer.screenshot_tokens` إن كنت ما زلت تقرأ النتيجة.
