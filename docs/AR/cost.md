## التخزين المؤقت للمطالبة، وهو معظم الأمر

يعيد كل طلب إرسال الأجزاء التي لا تتغير — مطالبة النظام، ومخططات الأدوات،
والمحادثة حتى الآن. وسيعيد المزوّدون تقديم بادئة متطابقة بايتًا ببايت بنحو عشر
السعر.

مبني Comodor حول هذا، وهو قيد التشغيل افتراضيًا:

```json
{ "agent": { "prompt_cache": true, "prompt_cache_ttl": "5m" } }
```

قيست على جلسات حقيقية: **86% من رموز الإدخال قُدّمت من الذاكرة المؤقتة**.

### لماذا لا يدخل شيء ديناميكي في مطالبة النظام

يعمل التخزين المؤقت فقط على بادئة متطابقة بايتًا ببايت مع المرة الأخيرة. ومطالبة
النظام *هي* البادئة. وأي شيء يتغير كل دور — الدروس المستدعاة، والمهارة المطابقة،
وساعة اليوم — يُبطلها، فتدفع الثمن الكامل لكل شيء، في كل دور.

لذلك تركب الدروس المستدعاة على *الدور*، بوصفها جزءًا من رسالة المستخدم. وقد
رفعت ذلك التغيير الواحد معدل الإصابة المقيس للذاكرة المؤقتة من 72% إلى 87%.

وإن أضفت تعليمات دائمة من عندك، فضعها في `agent.system_prompt_extra`، فهي
مستقرة، بدل أن تتنوّعها.

### الذاكرة المؤقتة لساعة واحدة

```json
{ "agent": { "prompt_cache_ttl": "1h" } }
```

تكلف نحو 25% زيادة لـ*كتابة* مدخل وتُبقيه ساعة بدل خمس دقائق. وتستحق إن كنت
تعود إلى جلسة مرارًا؛ وهي مسرفة في انفجار عمل واحد.

## السقوف

```json
{
  "agent": {
    "max_steps": 0,
    "max_seconds": 3600,
    "max_cost_usd": 2.0
  }
}
```

ويوقف أولهما المهمة، و`0` تعني بلا حد. ويقول `stopped` في `--json` أيها كان.

**لا حد للخطوات افتراضيًا.** فأربع وعشرون خطوة لا شيء على كودباس حقيقي — وقد
نفدت من إعادة هيكلة عبر دزينة ملفات في منتصف الفكر — وعدد الخطوات لا علاقة له
بالضرر: فعشر خطوات تقرأ الملفات تكاد لا تكلف شيئًا. أما السقوف التي تقابل
الضرر فهي الوقت والمال، وهما يبقيان قيد التشغيل. واضبط `max_steps` برقم إن
أردت توقفًا صارمًا.

وحين يوقف أحدها مهمة، تقول الرسالة كيف تجاوزه، و«أكمل» تواصل من حيث كان.

### حين لا يستطيع الحد أن يعمل

**حد الإنفاق لا يعمل إلا لنموذج له سعر معلَن.**

إن جدول الأسعار يترك أسعارًا غير مضبوطة للنماذج التي لا يثق بها عمدًا — فاختراع
سعر ينتج أرقامًا خاطئة، وهو أسوأ من لا شيء. ولنموذج غير مسعَّر يقرأ عدّاد الكلفة
صفرًا، فلا يكون `spent >= max_cost_usd` صحيحًا أبدًا ولا يعمل الحد قط.

ويقول Comodor ذلك بدل أن يدعك تظن أنك محمي:

```
the $2.00 spend limit cannot be enforced for gpt-4o — no published rate is
known, so the cost meter reads zero. The step and time limits still apply.
```

يُقال في بداية جلسة، وفي `comodor doctor`:

```
  warn  spend limit    $2.00 per task cannot be enforced for gpt-4o
                       → No published rate is known for this model, so the
                         cost meter reads zero and the limit never fires.
                         The step and time limits still apply.
```

ولنموذج يعمل على جهازك أنت يقول شيئًا مختلفًا، لأنه هناك لا يكلف شيئًا في
الأصل.

## ما يكلّف المال فعلًا

**لقطات الشاشة.** نحو 1,600 رمز بصري لكل واحدة بالميزانية الافتراضية — ومثله
مرة أخرى في كل دور تبقى فيه في المحادثة. ويحتفظ Comodor بآخر اثنتين ويستبدل
البقية بسطر يقول إن واحدة كانت هناك. ودون ذلك، تحمل مهمة سطح مكتب من ثلاثين
خطوة نحو خمسين ألف رمز من البكسلات تصف شاشات نُقِر فيها منذ حين.

```json
{ "agent":    { "keep_screenshots": 2 } }
{ "computer": { "screenshot_tokens": 1600 } }
```

لا تضبط `screenshot_tokens` منخفضًا أكثر من اللازم. فالصورة التي لا يستطيع
النموذج قراءتها أسوأ من لا صورة: فهو يخمّن بدل أن يسأل. راجع
[استخدام شاشتك](computer.md#screenshots-and-what-they-cost).

**مخرجات الأدوات الكبيرة.** محدودة بـ `agent.max_tool_chars`. وما لا يتسع
يُكتب في ملف يُخبر النموذج كيف يقرؤه، فيدفع فقط إن نظر.

**الانعكاس.** نداء نموذج واحد في نهاية مهمة. ووجّهه إلى نموذج أرخص:

```json
{ "learning": { "reflect_model": "claude-haiku-4-5" } }
```

أو أوقفه. والمسار المجاني — التصحيحات، والقواعد، والإعلانات — يواصل العمل في
الحالتين. [كيف يتعلم](learning.md#the-two-lanes).

**المتصفح، حين ينظر.** يعيد `browse` نصًا افتراضيًا ولقطة شاشة فقط عند
الطلب، لأن صورة صفحة تكلف المثل في كل مرة ولا يمكن تقليمها.
