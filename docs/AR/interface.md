# الواجهة

ما تراه، وما تضغطه، ومن أين يأتي كل ما على الشاشة.

```bash
comodor          # شغّلها
comodor --demo   # الواجهة كاملة، دون اتصال، دون مفتاح
```

تعمل الواجهة على [Bun](https://bun.sh) — ويقول `comodor doctor` ما إذا كان
موجودًا. ومن دونه، ينجز `comodor run "..."` مهمة واحدة بلا واجهة، ويقدّم
`comodor web` واجهة في المتصفح.

أما كيف بُنيت — النواة التي تقودها، والبروتوكول بينهما، ولماذا كل حقيقة على
الشاشة هي حقيقة النواة لا الشاشة — فذلك في [tui-v2.md](../tui-v2.md). هذه
الصفحة هي النسخة القصيرة لمن يستخدمها.

## الشاشة

```
┌──────────────────────────────────────────┬───────────────────────┐
│ Comodor   ~/work/my-project  fake-1      │ Agents         1 live │
│                                          │  ● d1 running    12.3s│

│  fix the failing parser test             │ Tasks            2/5  │
│                                          │  ◐ write the tests    │
│  Comodor                                 │  ● read the code      │
│  The test expects parse("") to raise, …  │  ○ run the suite      │
│  ✓ read_file  tests/test_parser.py  0.2s │                       │
│  ● run_shell  pytest tests/…     running…│                       │
│      collected 12 items                  │                       │
│                                          │                       │
├──────────────────────────────────────────┴───────────────────────┤
│ ▌ask for anything                                                │
├──────────────────────────────────────────────────────────────────┤
│  [ACT]   PLAN    ASK    Reads, writes and runs commands…         │
│ ● 1 agent  tab Mode  ctrl+b Work  ctrl+k Commands      42% ctx  │
└──────────────────────────────────────────────────────────────────┘
```

**الترويسة** تسمّي المشروع، والمزوّد والنموذج اللذين يجيبان. وهي ما تبلّغ به
النواة، لا ما يقوله ملف إعداد: فعندما يتغير النموذج — من هنا، أو من عميل آخر،
أو بيد النواة نفسها — تتبعه الترويسة.

**المحادثة** تحمل في داخلها خط زمن الأدوات. كل استدعاء أداة يجلس حيث وقع، في
صف واحد: علامة (`●` يعمل، `✓` انتهى، `×` فشل)، والاسم، وملخص في سطر، وكم
استغرق. الأداة الجارية تعرض آخر سطور مخرجاتها؛ والمنتهية تنطوي، والنقر عليها
يفتح ما تزال النواة تحتفظ به.

**منضدة العمل** — `Ctrl+B` — هي العمل خارج المحادثة: قائمة المهام التي يحتفظ
بها الوكيل لنفسه، وأي وكلاء في الخلفية شغّلهم، كلٌّ بحالته. وفي الطرفية الضيقة
تُفتح فوق المحادثة بدل جانبها، والمفتاح نفسه يغلقها.

**التذييل** يطبع ما يمكنك ضغطه، من القائمة نفسها التي تُقرأ منها المفاتيح، وما
كلّفته هذه الجلسة حيث يقيس المزوّد ذلك.

## المفاتيح

| المفتاح | يفعل |
|---|---|
| `Enter` | يرسل ما كتبته |
| `Tab` / `Shift+Tab` | النمط التالي / السابق |
| `Ctrl+K` | لوحة الأوامر — كل إجراء، قابل للبحث |
| `Ctrl+B` | فتح منضدة العمل أو إغلاقها |
| `End` | العودة إلى أحدث المخرجات بعد التمرير لأعلى |
| `PageUp` / `PageDown` | تمرير المحادثة |
| `Ctrl+R` | إعادة إرسال رسالة رفضتها النواة |
| `Ctrl+C` | إيقاف ما يفعله؛ والخروج عندما يكون خاملًا |
| `Ctrl+D` | الخروج |
| `Esc` | إغلاق اللوحة، أو مغادرة حقل، أو أخذ الخيار الآمن لبطاقة |

كل اختصار يعرضه التذييل موجود؛ فلا يمكن طباعة تلميح لمفتاح غير مربوط.

## الأنماط

```
ACT    يقرأ ويكتب ويشغّل الأوامر، ويسأل قبل أن يغيّر شيئًا
PLAN   يقرأ ويخطط؛ لا يستطيع الكتابة أو التشغيل أو تغيير أي شيء
ASK    يتحدث في الأمر؛ بلا أدوات إطلاقًا
```

`Tab` يتنقل بينها. وتتحرك التسمية عندما تؤكد النواة، لا عند نزول المفتاح:
فالضغطات داخل رحلة ذهاب وإياب واحدة تتراكم — ثلاث `Tab` تسأل مرة واحدة، عمّا
أشارت إليه الثالثة — والتغيير المرفوض يقول ذلك بالكلمات بدل تحريك التسمية.

---

## عندما يسألك شيئًا

بطاقة الإذن أو نموذج الأسئلة يستحوذ على لوحة المفاتيح ما دام معروضًا، حتى لا
يستطيع مفتاح قُصد به قرارٌ أن يرسل رسالة أيضًا.

- **الأسهم** تتنقل بين الخيارات أو الأسئلة؛ و**Enter** يرسل.
- **Esc** يأخذ الخيار الآمن الخاص بالطلب — للإذن هو *الرفض*، ولتغيير النمط
  المقترح هو *لا تغيير* — وتقول البطاقة أيهما. ولا يسمح بشيء أبدًا.
- لا يوجد اختصار بمفتاح واحد لـ*السماح*. فالسماح يكلّف حركة إلى الخيار وحركة
  لتأكيده، حتى لا يستطيع مفتاح ضُغط لأي سبب آخر أن يأذن بأمر.
- السؤال الذي يعرض صفًا «اكتب إجابتك» يفتح حقلًا له بـ`Space`؛ و`Esc` يغادر
  الحقل قبل أن يلغي النموذج.

يمكن أن ينتظر شيئان في آن واحد — أداتان متوازيتان قد تسأل كل منهما — ويُعرضان
بترتيب وصولهما، ولا يضيع أي منهما.

مفاتيح الأنماط تظل تعمل والبطاقة معروضة. أما اللوحة فلا: فمشغّل فوق قرار كان
سيخفي ما يجب الإجابة عنه.

## المتابعة

الإجابة الطويلة تُبقي أحدث سطر في مرمى البصر. مرّر لأعلى فتتوقف عن المتابعة؛
والمخرجات الجديدة لا تسحبك لأسفل، وعلامة تقول إن هناك المزيد في الأسفل. `End`
يعيدك إلى الذيل الحي، وإرسال رسالة جديدة يفعل الشيء نفسه.

---

## الجلسات

`Ctrl+K` ← *فتح محادثة سابقة* يسرد ما احتفظت به النواة، ويفتح واحدة في مكانها.
والمخزن نفسه يخدم المتصفح، فالمحادثة التي بدأت هنا يمكن إعادة فتحها هناك.

`comodor --resume` يعيد فتح الأحدث عند البدء؛ و`--resume ID` يسمّي واحدة.

## نسخ النص للخارج

حدّد بالفأرة كما تسمح طرفيتك. أما العلمان `--theme` و`--ascii` فينطبقان على ما
تطبعه الأوامر — `setup` و`doctor` و`help` — لا على الواجهة، التي ترسم من رموز
تصميمها الخاصة.

---

## النص من اليمين إلى اليسار

الفارسية والعربية والسطور المختلطة تُمرَّر إلى الطرفية كما كُتبت، ولا يعكسها
البرنامج أبدًا. ومدى جودة تشكيل السطر المختلط شأن الطرفية، والطرفيات التي
تحسنه تحسنه هنا.
