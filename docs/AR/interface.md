# الواجهة

ما تراه، وما تضغطه، وجميع الأوامر الـ 29.

```bash
comodor          # start it
comodor --demo   # the whole interface, offline, no key
```

---

## التخطيط

```
┌────────────────────────────────────────────────────────────────────────┐
│  Comodor                              Anthropic · claude-sonnet-5      │
│  ────────────────────────────────────────────────────────────────────  │
│                                                                        │
│  TASKS                    > fix the failing parser test                │
│  ● read the test          ▸ read_file  tests/test_parser.py     0.1s   │
│  ◐ find the cause         ▸ run_shell  pytest tests/test_pa…    2.3s   │
│  ○ fix it                                                              │
│                           The test expects `parse("")` to raise, but…  │
│                                                                        │
│  ────────────────────────────────────────────────────────────────────  │
│  ▌Type a task, or / for commands                                       │
│                                                                        │
│  act · loop on · 12% of 1M · $0.03      ⏎ send  ^O attach  F3 mode     │
└────────────────────────────────────────────────────────────────────────┘
```

**الشريط الجانبي** هو الخطة، عندما توجد واحدة. يخفيه `F2` — وهو أمر جدير
بالفعل في طرفية ضيقة.

**سطر الحالة** يعرض النمط، وما إذا كان يواصل التكرار، ومدى امتلاء السياق،
وكم كلفت هذه الجلسة. رقم السياق حقيقي: يتبع النموذج، لذا فإن الانتقال من
نموذج بمليون رمز إلى نموذج 128k يغيّره فورًا.

يعمل من نحو 60 عمودًا فما فوق. وتطوى الشريط الجانبي من تلقاء نفسها دون ذلك.
يرسم `comodor preview 80x24` الواجهة بأي حجم دون بدء جلسة.

## الأنماط

| النمط | ما يجوز للوكيل فعله | |
|---|---|---|
| **act** | كل شيء، سائلًا قبل الكتابات والأوامر | الافتراضي |
| **plan** | القراءة فقط. لا كتابات، لا أوامر، لا شبكة | لسؤال «ماذا ستفعل؟» |
| **chat** | لا أدوات على الإطلاق | لسؤال عن كود تلصقه |

يتبدّل بينها `F3`. يضبط `/mode plan` نمطًا واحدًا مباشرة.

نمط الخطة للقراءة فقط حقًا — يُفرَض على طبقة الأذونات، لا بمجامللة النموذج.
وتُرفض أداة مخاطرها أعلى من «safe» قبل تشغيلها.

## الأوامر

اكتب `/` وتتصفى القائمة أثناء الكتابة.

### اطلب منه تغيير ما يفعله

| | |
|---|---|
| `/mode [act\|plan\|chat]` | ما يجوز له فعله |
| `/loop` | مواصلة العمل حتى الانتهاء، أو الإجابة مرة واحدة |
| `/model [id]` | اختيار النموذج — قائمة، أو اذكر واحدًا |
| `/provider [name]` | اختيار المزوّد |
| `/gw` | البوابة: توجيه عبر المزوّدين حسب التكلفة أو السرعة أو الجودة |

### علّمه

| | |
|---|---|
| `/good` | تلك الإجابة كانت صحيحة |
| `/bad` | تلك الإجابة كانت خاطئة |
| `/teach <text>` | تذكّر هذا |
| `/memory` | ما تعلمه |
| `/rules` | القواعد العامة التي استخلصها من كودك وتعديلاتك |
| `/progress` | الدليل على أنه يتحسن |
| `/skills` | إجراءات يتّبعها عندما يتطابق العمل معها |

يعتبر `/good` و`/bad` أرخص ما يمكنك فعله من أجله. راجع
[كيف يتعلم](learning.md).

### التراجع والنظر إلى الوراء

| | |
|---|---|
| `/undo` | استعادة آخر ملف غيّره |
| `/clear` | بدء محادثة جديدة |
| `/resume [id]` | إعادة فتح جلسة سابقة |
| `/search <text>` | البحث عن شيء في محادثة سابقة |
| `/export [path]` | كتابة هذه الجلسة في ملف |

### دَعه يصل أبعد

| | |
|---|---|
| `/computer [15m\|1h this app\|stop]` | السماح له باستخدام شاشتك — [الدليل](computer.md) |
| `/mcp` | خوادم MCP وأدواتها — [الدليل](mcp.md) |
| `/attach <path>` | إضافة ملف إلى الرسالة التالية |

### اضبطه

| | |
|---|---|
| `/settings` | ما مضبوط الآن |
| `/approve [writes\|shell\|all]` | التوقف عن السؤال قبل تلك الأنواع |
| `/theme [name]` | ember، midnight، matrix، mono |
| `/save` | كتابة الإعدادات الحالية إلى ملف الإعداد لديك |
| `/cost` | الرموز، الإنفاق، وما وفّره التخزين المؤقت |
| `/copy [all\|task]` | آخر إجابة، أو كل شيء، إلى الحافظة |
| `/mouse [on\|off]` | تتبع الفأرة، لتتمكن من تحديد النص بنفسك |
| `/help` | كل ما سبق، داخل الواجهة |
| `/quit` | الخروج |

**يكتب `/save` ما اخترته فقط.** لا إعدادات المستودع، ولا مفتاحًا تحفظه في
بيئتك، ولا `--model` مرّرته لتشغيل واحد. راجع
[الإعداد](configuration.md#what-save-writes).

## الموافقات

عندما يريد الوكيل كتابة ملف أو تشغيل أمر:

```
  Write  src/parser.py
  ────────────────────────────────────────────
   - def parse(text):
   -     return text.split(",")
   + def parse(text):
   +     if not text:
   +         raise ValueError("nothing to parse")
   +     return text.split(",")

  [a] allow   [A] allow always this session   [d] deny
```

يتذكر `A` خلال الجلسة، بحسب نوع الشيء — فالسماح بالكتابات لا يسمح بالأوامر.

الرفض ليس هدرًا. إن الرفض أوضح إشارة تفضيل تجمعها الواجهة على الإطلاق، وتذهب
إلى محرك التعلم: يقل احتمال أن يقترح الوكيل ذلك مرة أخرى.

للتوقف عن السؤال نهائيًا:

```
/approve writes      files, yes; commands, still ask
/approve all         everything
```

كل شيء يبقى محفوظًا كنقاط استرجاع. يعمل `/undo` على أي حال.

## نسخ النص إلى الخارج

أثناء تتبع الفأرة، تنتمي عملية السحب إلى Comodor ولا تراها الطرفية أبدًا —
لذا لا يعمل التحديد والنسخ المعتادان. ثلاث طرق للالتفاف على ذلك:

```
/copy              the last answer
/copy all          the whole conversation
/copy task         the last thing you asked for
/mouse             mouse tracking off, so selection works as usual
```

لا يحتاج `/copy` إلى تثبيت أي شيء على Windows أو macOS. وعلى Linux يستخدم
`wl-copy` أو `xclip` أو `xsel`، أيّها وجد، ويخبرك بأيها مفقود إن لم يوجد أي
منها.

عبر SSH يلجأ إلى تسلسل هروب يطلب من طرفيتك *أنت* ضبط *حافظتك* — فيهبط النص
القادم من وكيل على خادم حيث يمكنك لصقه، لا على خادم بلا حافظة.

وتتيح لك معظم الطرفيات أيضًا التحديد مع الاستمرار في الضغط على **Shift**،
متجاوزةً تتبع الفأرة دون إيقافه.

## من المتحدث

يقع كل دور على شريط هادئ — درجة لونية خلف ما كتبته، وأخرى خلف الإجابة:

```
▌ › why does the parser drop the last field?              ← warm

▌   Because split is called with a maxsplit of 2 …        ← neutral
▌
▌   ┌─ python ────────────────────────┐
▌   │ return text.split(',', 2)       │
▌   └─────────────────────────────────┘
```

مكبوَت عمدًا. إنه خلف نص أساسي تقرؤه دقائق متواصلة، وخلفية ذات حضور من
تلقاء نفسها تزاحم الكلمات. لكل سمة زوجها الخاص، بنسبة بضع نقاط مئوية عن
خلفيتها؛ و`mono` لا يملك شيئًا منها، لأن سمة مسلّمتها انعدام اللون لا تريد
اثنين منها.

لا تستهلك مساحة عمودية — فتغيّر اللون هو الحد الفاصل.

## النص من اليمين إلى اليسار

تُنضد الفارسية والعربية والعبرية إلى اليمين، حيث تبدأ أسطرها، بحزمة خطوط
تناسبها. وتُعالَج الفقرات المختلطة — معرّف إنجليزي داخل جملة فارسية — سطرًا
بسطر لا ملفًا بملف، وهو ما يحدث فعلًا في محادثة تقنية.

## السمات

```
/theme midnight
```

`ember` (الافتراضية، كهرماني دافئ)، و`midnight` (أزرق بارد)، و`matrix`
(أخضر)، و`mono` (بلا لون إطلاقًا).

يستبدل `--ascii` محارف رسم الصناديق بـ ASCII، للطرفيات التي تفتقر إليها.
ويُحترم `NO_COLOR` في بيئتك.
