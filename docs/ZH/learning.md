# 它如何学习

大多数代理在会话结束的那一刻就忘记了。这个代理会观察你改动它输出的地方，并把那些记住。

---

## 这个想法

夸奖是廉价的，纠正才是昂贵的，所以纠正才是它学习的东西。

当你修改它写的文件，或直截了当地告诉它错了，这就成了一条**经验（lesson）**：一条简短的规则，带有一个置信度——每当它应验时就上升，闲置不用时就衰减。经验在情况看起来相似时被召回，并注入到那个回合中——绝不注入系统提示词，那会毁掉提示词缓存。

没有任何东西离开你的机器。大脑（brain）是配置目录下的一个 SQLite 文件。

---

## 两条通道

### 反射（Reflex）——免费、即时、始终开启

没有模型调用，没有 token，没有延迟。

- **纠正。** 你把 `"` 改成 `'`，在一个它写的文件里。那是一个 diff，而 diff 就是事实。
- **规则。** 它在开始时通读一遍你现有的代码，并从中提炼惯例——缩进、引号风格、测试如何命名。
- **告知。** 当一条规则被应用时，它会说明，只用一行。一条你看不见的规则，就是一条你无法纠正的规则。
- **预取。** 召回在你还在打字时就开始了。

这条通道即使在反思被关闭时也是开着的，因为它不花钱。

### 反思（Reflection）——一次模型调用，在一个任务之后

在一个任务结束时，它审视发生了什么，并写下它应该记住的东西。这条要花一次调用。想省一点就用一个更便宜的模型：

```json
{ "learning": { "reflect_model": "claude-haiku-4-5" } }
```

或者关掉它，保留 Reflex：

```json
{ "learning": { "reflect": false } }
```

---

## 刻意地教它

| | |
|---|---|
| `/good` | 那个回答是对的 |
| `/bad` | 那个回答是错的 |
| `/teach we use pytest, never unittest` | 记住这个 |

`/good` 和 `/bad` 只需一次按键，是你能为它做的最便宜的事。

拒绝一个权限提示也是在教它。一次拒绝是界面收集到的最清晰的偏好信号，它也被当作信号对待。

## 召回，以及为什么它不在系统提示词里

被召回的经验搭在回合上，作为用户消息的一部分，而不放进系统提示词。

这是一个成本决定。提示词缓存只对逐字节相同的前缀生效，而系统提示词就是那个前缀。在里面放任何与查询相关的东西，都会在每一个回合上让缓存失效。把召回挪到回合上之后，实测的缓存命中率从 72% 提高到 87%。参见[成本](cost.md)。

---

## 它从你那里学到的词

它还学习*你的*哪些词是成对出现的，数据来自你自己完成的任务——"解析器"和"分词"属于你代码库的同一个角落。这不花 token，也不调模型；它只是在数数。

这就是为什么一条记在"分词器"名下的经验，会在你问"词法分析器"时浮现出来。

```json
{ "learning": { "associative": true } }
```

---

## 作用范围

```json
{ "learning": { "share_scope": "project" } }
```

`project` 把经验限制在学到它们的那一个仓库里——这是正确的默认值，因为一个代码库里的惯例在另一个里是错的。`global` 则在所有地方共享。

---

## 遗忘

一条闲置不用的经验会衰减。`half_life_days`（默认 45）设定衰减快慢，`min_confidence`（0.15）是它不再被召回的下限。

这很重要：一个代码库会改变主意，而一个满怀十足信心抱着一条两年前的惯例不放的代理，比一个忘了的更糟。

---

## 把它关掉

```json
{ "learning": { "enabled": false } }
```

一切照常工作。它只是每次会话都以一个陌生人开场。

---

## 它住在哪里

```
~/.comodor/brain.db
```

SQLite。属于你的。`comodor uninstall` 会移除它，并说明它有多大体量。
