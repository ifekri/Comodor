# 智能体能做什么

十三个工具。每个工具都声明一个风险等级，决定它是否先询问——参见[安全](safety.md#risk-tiers)。

---

## 文件

| | Risk | |
|---|---|---|
| `read_file` | safe | 读取一个文本文件。流式处理，因此大日志的某个片段也能读到 |
| `list_dir` | safe | 目录条目，附带大小 |
| `glob` | safe | 按名称模式查找文件——`src/**/*.py` |
| `grep` | safe | 用正则表达式搜索内容 |
| `write_file` | write | 创建一个文件，或整体替换它 |
| `edit_file` | write | 替换文件中一段精确的字符串 |

一切都被限制在项目文件夹之内，除非你关闭 `safety.workspace_only`。

对已有文件的修改优先使用 `edit_file` 而不是 `write_file`：它更小，能以 diff 的形式审阅，也不会悄悄丢失文件的其余部分。

---

## 运行东西

| | Risk | |
|---|---|---|
| `run_shell` | dangerous | 工作区中的一条 shell 命令 |
| `run_python` | dangerous | 一小段 Python，运行在子进程中 |

两者都会在运行前询问，都受 `safety.deny_commands` 约束，输出也都有上限——参见[输出过大时](#when-output-is-too-big)。

在界面中你可以完全绕过模型：

```
!git status
```

直接运行，显示输出，并且绝不向模型提及。比询问更快也更便宜。

---

## 网络

| | Risk | |
|---|---|---|
| `web_fetch` | dangerous | 下载一个 URL 并返回其可读文本 |
| `web_search` | dangerous | 搜索，并返回标题、URL 和摘要 |
| `browse` | dangerous | 真实浏览器——JavaScript、cookie、登录 |

`web_fetch` 是便宜的那个：它把页面剥成纯文本。当页面是一份文档时用它。

`browse` 用于它是一个应用的场合——需要 JavaScript、登录或点击的东西。[完整指南](browser.md)。

---

## 机器

| | Risk | |
|---|---|---|
| `computer` | dangerous | 鼠标、键盘和屏幕，适用于任何应用 |

默认关闭，除非你打开它；而且打开之后也仍需授权才能使用。[完整指南](computer.md)。目前仅支持 Windows。

---

## 记录进度

| | Risk | |
|---|---|---|
| `todo_write` | safe | 你在侧边栏看到的任务列表 |

智能体在这里写下它自己的计划。这不是装饰——它是长任务保持连贯的方式，也是你能看到它进行到哪里去的方式。

---

## 时有时无

Comodor 只提供模型真正能使用的工具。一个看得见却永远用不成功的工具，每一轮都会招致一次浪费的调用。

| | 出现时机 |
|---|---|
| `read_skill_file` | 你安装的某个技能附带文件 |
| `search_history` | 存在可供搜索的历史会话 |
| `delegate` | 可以派生子智能体 |
| `computer` | 平台有后端**且**你启用了它 |
| MCP 工具 | 某个服务器已配置并启用 |

`browse` 有两种实现：装了 Chrome、Chromium、Edge 或 Brave 时用真实浏览器，一个都没装时用文本浏览器。两者都叫 `browse`，因为在两个都叫"browser"的东西之间做选择，是模型不该浪费的一轮。

---

## 输出过大时

一个打印五万行的命令不会被截断得毫无用处，也不会撑爆上下文。

放得下的部分交给模型——开头和结尾，因为答案通常在那里。其余部分写入 `~/.comodor/output/` 下的一个文件，并告知模型路径和读取方式。于是它需要时可以去查看，不需要时也分文不付。

```json
{ "agent": { "max_tool_chars": 12000 } }
```

---

## 子智能体

`delegate` 在一个 **git worktree** 中运行第二个智能体——同一仓库的一个隔离检出。它在那里工作，其改动以补丁形式返回，经三方合并后应用。

它没有记忆，不能再委派，也不会被给予屏幕。它继承父级的取消信号，所以 `Esc` 也能停掉它。

适合真正独立的任务——"在我继续工作的同时把这个模块移植到新 API"——其他情况则纯属浪费。

---

## MCP 工具

任何已启用的 Model Context Protocol 服务器所提供的东西，都会与内置工具并列出现，并通过完全相同的权限闸门。

```bash
comodor mcp list
```

[完整指南](mcp.md)。
