# 终端界面

你看到什么、按什么键，以及屏幕上的每样东西从哪里来。

```bash
comodor          # 启动
comodor --demo   # 完整的界面，离线，无需密钥
```

界面运行在 [Bun](https://bun.sh) 之上——`comodor doctor` 会告诉你它是否存在。没有它，`comodor run "..."` 可以不带界面地完成一项任务，`comodor web` 则在浏览器里提供一个界面。

它是如何构建的——它驱动的核心、两者之间的协议，以及为什么屏幕上的每一个事实都属于核心而不属于屏幕——见 [tui-v2.md](../tui-v2.md)。本页是给使用者看的简短版本。

## 屏幕

```
┌──────────────────────────────────────────┬───────────────────────┐
│ Comodor   ~/work/my-project  fake-1      │ Agents         1 live │
│                                          │  ● d1 running    12.3s│
│  You                                     │    survey the retries │
│  fix the failing parser test             │ Tasks            2/5  │
│                                          │  ◐ write the tests    │
│  Comodor                                 │  ● read the code      │
│  The test expects parse("") to raise, …  │  ○ run the suite      │
│  ✓ read_file  tests/test_parser.py  0.2s │                       │
│  ● run_shell  pytest tests/…     running…│                       │
│      collected 12 items                  │                       │
│                                          │                       │
├──────────────────────────────────────────┴───────────────────────┤
│ ▌ask for anything                                                │
├──────────────────────────────────────────────────────────────────┤
│  [ACT]   PLAN    ASK    Reads, writes and runs commands…         │
│ ● 1 agent  tab Mode  ctrl+b Work  ctrl+k Commands      42% ctx  │
└──────────────────────────────────────────────────────────────────┘
```

**页眉**写明项目，以及正在作答的提供商和模型。它显示的是核心报告的内容，而不是某个配置文件的说法：当模型变化时——不论是从这里、从另一个客户端，还是由核心自己——页眉都会跟着变。

**对话**内部带有工具时间线。每次工具调用都停留在它发生的位置，占一行：一个标记（`●` 运行中、`✓` 完成、`×` 失败）、名称、一行摘要，以及花了多长时间。运行中的工具显示其输出的最后几行；完成的工具会折叠起来，点击它可以打开核心仍然保留的内容。

**工作台**——`Ctrl+B`——是对话之外的工作：智能体为自己维护的任务列表，以及它启动的任何后台智能体，各自带有状态。在较窄的终端里，它会覆盖在对话之上而不是并排显示，同一个按键可以关闭它。

**页脚**打印你可以按的键——来自读取按键的同一份列表——以及在提供商能够计量的情况下，本次会话到目前为止的花费。

## 按键

| 按键 | 作用 |
|---|---|
| `Enter` | 发送你输入的内容 |
| `Tab` / `Shift+Tab` | 下一个 / 上一个模式 |
| `Ctrl+K` | 命令面板——所有操作，可搜索 |
| `Ctrl+B` | 打开或关闭工作台 |
| `End` | 向上翻阅之后回到最新输出 |
| `PageUp` / `PageDown` | 滚动对话 |
| `Ctrl+R` | 重新发送一条被核心拒绝的消息 |
| `Ctrl+C` | 停止它正在做的事；空闲时退出 |
| `Ctrl+D` | 退出 |
| `Esc` | 关闭面板、离开一个输入框，或采用卡片的安全选项 |

页脚显示的每一个快捷键都存在；未绑定的按键不会被打印成提示。

## 模式

```
ACT    读取、写入并运行命令，在改动之前会询问
PLAN   读取并规划；不能写入、运行或改动任何东西
ASK    只是讨论；完全不用工具
```

`Tab` 在它们之间循环。标签在核心确认时才移动，而不是按键按下时：一次往返之内的多次按键会累积——按三次 Tab 只询问一次，指向第三次所指的模式——被拒绝的切换会用文字说明，而不是移动标签。

---

## 当它向你提问时

权限卡片或问题表单在显示期间会占用键盘，这样一个用于决定的按键就不会同时发送消息。

- **方向键**在选项或问题之间移动；**Enter** 发送。
- **Esc** 采用请求自身的安全选项——对于权限是*拒绝*，对于建议的模式切换是*不变*——卡片会说明是哪一个。它从不允许任何事情。
- *允许*没有单键快捷方式。允许需要一次移动到该选项、再一次确认，这样因为任何其他原因按下的键都无法授权一条命令。
- 提供“自己填写”一行的问题，按 `Space` 会为它打开一个输入框；`Esc` 先离开输入框，然后才会取消表单。

两件事可能同时在等待——两个并行工具可能各自提问——它们按到达顺序显示，一个都不会丢失。

卡片显示时模式按键仍然可用。面板不行：叠在一个决定之上的启动器会遮住必须回答的东西。

---

## 跟随输出

长回答会让最新一行保持在视野内。向上滚动就会停止跟随；新输出不会把你拉回底部，一个标记会提示下面还有更多。`End` 回到实时末尾，发送新消息也会如此。

---

## 会话

`Ctrl+K` → *打开较早的对话* 列出核心保留的对话，并就地打开一个。同一个存储也服务于浏览器，所以在这里开始的对话可以在那里重新打开。

`comodor --resume` 在启动时重新打开最近的一个；`--resume ID` 指定某一个。

---

## 复制文本

按你的终端允许的方式用鼠标选择。`--theme` 和 `--ascii` 标志作用于各命令的打印输出——`setup`、`doctor`、`help`——而不是界面，界面从自己的设计标记中绘制。

---

## 从右到左的文本

波斯语、阿拉伯语和混合行按原样传给终端，程序从不反转它们。混合行的排版效果取决于终端，排版得好的终端在这里也一样好。
