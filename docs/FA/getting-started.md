# شروع به کار

پنج دقیقه، که با انجام کاری مفید از طرف عامل به پایان می‌رسد.

---

## ۱. نصب

یک خط. بقیه را خودش حل می‌کند.

**macOS · Linux · BSD**

```bash
curl -fsSL get.comodor.ai | sh
```

**Windows** — PowerShell

```powershell
irm get.comodor.ai | iex
```

```
Comodor — it learns the way you correct it.

  Linux x86_64
> Installing uv, a package manager Comodor needs (about 15 MB)
  from https://astral.sh/uv — it fetches a Python too, if one is missing
> Installing with uv

✓ comodor 0.9.0

  Linked into /usr/local/bin, which is on your PATH.

  comodor              start the interface
  comodor --demo       try it offline, no API key needed
  comodor doctor       check what is configured
```

**یک آدرس برای هر دو.** `get.comodor.ai` نام فایلی را نمی‌آورد. می‌خواند که
کدام کلاینت در حال پرسیدن است و `curl` و `wget` را به نصب‌کنندهٔ شل، PowerShell
را به نصب‌کنندهٔ ویندوز، و مرورگر را به همین صفحه می‌فرستد — پس خطی که می‌چسبانید
در همهٔ سیستم‌ها یکسان است و هرگز لازم نیست انتخابی بکنید.

**به کارش می‌رسد.** کسی که یک خط را از یک صفحهٔ وب اجرا می‌کند تعهدی به دیباگ
کردن چیزی نداده است، پس اسکریپت هر چه نیاز دارد را نصب می‌کند — یک محیط ایزوله،
یک مدیریت بسته، یک پایتون — به جای آنکه توقف کند و توضیح بدهد چه چیزی باید از
قبل داشتید. روی یک `debian:bookworm-slim` کاملاً خالی، بدون هیچ پایتونی، راستی‌آزمایی
شده است.

### تقریباً همیشه چیزی برای تایپ کردن باقی نمی‌ماند

هر جا که بتواند، `comodor` را جایی می‌گذارد که شل شما از قبل به آن نگاه می‌کند،
پس در همان ترمینالی که آن را اجرا کرده‌اید کار می‌کند — بدون `export`، بدون
پنجرهٔ جدید. این موضوع ریشه، کانتینرها، CI، و هر مک با Homebrew را پوشش می‌دهد.

هر جا که نتواند — یک حساب لینوکس معمولی، که هیچ‌چیز روی `PATH` آن قابل نوشتن
نیست — هیچ نصب‌کننده‌ای نمی‌تواند کمک کند، چون یک فرزند (child) نمی‌تواند محیط
شلی که آن را اجرا کرده تغییر دهد. پس همین را می‌گوید:

```
  Every new terminal can run comodor already.
  This one started before the install, and no installer
  can reach back into the shell that ran it. For this
  terminal only:

    export PATH="/home/you/.local/bin:$PATH"
```

یک ترمینال جدید باز کنید و صرفاً کار می‌کند. این خط هم در فایل rc شل شما و هم
در پروفایل ورودتان نوشته می‌شود، پس هر نوع شلی آن را پیدا می‌کند — تعاملی،
ورودی، غیرتعاملی، و یک نشست دسکتاپ.

### اگر ترجیح می‌دهید اسکریپتی را داخل شل نریزید

کاملاً منطقی است. هر دو اسکریپت متنی ساده‌اند که می‌توانید اول بخوانید — با
آدرس کامل نام‌گذاری شده‌اند، چون آدرس کوتاه هر چیزی که یک دریافت‌کننده نباشد را
به صفحه می‌فرستد:

```bash
curl -fsSL https://comodor.ai/install.sh  | less
curl -fsSL https://comodor.ai/install.ps1 | less
```

یا از یک مدیریت بسته که از قبل دارید استفاده کنید:

```bash
uv tool install comodor      # ایزوله، و سریع‌ترین
pipx install comodor         # ایزوله
pip install comodor          # داخل هر محیطی که در آن هستید
```

کامودور به **Python 3.11 یا جدیدتر** نیاز دارد و هیچ چیز دیگری.

### بررسی کنید که رسیده است

```bash
comodor --version
```

اگر شل نتوانست پیدا کند، نصب‌کننده دایرکتوری‌ای به `PATH` شما افزوده که این
ترمینال هنوز از آن خبر ندارد. یکی جدید باز کنید، یا خط `export`ای که نصب‌کننده
چاپ کرد را اجرا کنید.

### گزینه‌هایی که نصب‌کننده‌ها می‌فهمند

| | |
|---|---|
| `COMODOR_FORCE_TOOL` | ثابت کردن روش: `uv`، `pipx`، `venv` یا `pip` |
| `COMODOR_NO_BOOTSTRAP` | هرگز ابزاری دانلود نکن؛ به جایش شکست بخور |
| `COMODOR_NO_MODIFY_PATH` | پروفایل شل شما را دستکاری نکن |
| `COMODOR_INSTALL_REF` | نصب از یک ref گیت یا یک مسیر محلی به جای PyPI |

```bash
COMODOR_NO_MODIFY_PATH=1 curl -fsSL get.comodor.ai | sh
```

> **هنوز مطمئن نیستید نصبش کنید؟** `comodor --demo` کل رابط را در برابر یک
> ارائه‌دهندهٔ آفلاین اسکریپت‌شده اجرا می‌کند. بدون کلید، بدون حساب، بدون شبکه.

## ۲. انتخاب یک مدل

اجرا کنید. بار اول شش پرسش می‌پرسد و دیگر هرگز نمی‌پرسد.

```bash
comodor
```

```
 1/6  Which model provider?
┌─  Providers  ───────────────────────────────────────────┐
│ ›  OpenRouter        One key, hundreds of models         │
│    Anthropic         Claude, direct from the source      │
│    OpenAI            GPT models, direct                  │
│    Ollama (local)    Runs on your machine. No key        │
└──────────────────────────────────────────────────────────┘
  ↑↓ move   enter choose   tab more   esc cancel
```

کلیدهای جهت‌دار، یا برای فیلتر کردن تایپ کنید. **Tab** توضیح کامل هر چیزی که
فلش روی آن است را در همان فریم باز می‌کند — فهرست‌ها برای جا شدن در صفحه در هر
سطر فقط یک خط نشان می‌دهند، و بعضی از آن توضیح‌ها یک پاراگراف تمام‌عیارند.

در حالت پایپ یا اسکریپت، همین پرسش‌ها به شکل یک فهرست شماره‌دار می‌رسند، پس
قابل خودکارسازی است.

**نه کلید دارید نه پول؟** **Ollama** یا **LM Studio** را انتخاب کنید. روی
دستگاه خودتان اجرا می‌شوند، کلید نمی‌خواهند، و هزینه‌ای ندارند. همهٔ این مستندات
با آن‌ها کار می‌کند، به جز بخش‌هایی که خلاف آن را می‌گویند.

**از قبل از OpenClaw یا Hermes استفاده می‌کنید؟** اولین صفحه پیشنهاد می‌دهد
کلیدها، مدل و مهارت‌های شما را بیاورد. هیچ چیزی جابه‌جا نمی‌شود و هیچ تنظیمی که
از قبل اینجا برقرار است جایگزین نمی‌شود. به [آمده از عامل دیگری](migrating.md)
نگاه کنید.

پاسخ‌های شما در `~/.comodor/config.json` ذخیره می‌شوند، که فقط خودتان می‌توانید
بخوانید. بعداً با `comodor setup` نظرتان را عوض کنید، یا یکی‌یکی تنظیمات را —
به [پیکربندی](configuration.md) نگاه کنید.

### پرسش آخر گوشی شماست

```
 6/6  Run it from your phone?
┌─  From your phone  ─────────────────────────────────────────────┐
│ ›  Not now    you can set any of them up later                   │
│    Telegram   one token from @BotFather — about a minute         │
│    Slack      an app from a manifest, two tokens — five minutes  │
│    WhatsApp   a Meta app and a public address — twenty minutes   │
└──────────────────────────────────────────────────────────────────┘
```

**تلگرام** یک توکن از [@BotFather](https://t.me/botfather) می‌گیرد، همان‌جا و
همان لحظه آن را با تلگرام بررسی می‌کند، و کدی نشان می‌دهد که به ربات می‌فرستید
تا بداند پاسخش به کدام حساب برود — از اول تا آخر یک دقیقه.
به [از گوشی شما](telegram.md) نگاه کنید.

**Slack** حدود پنج دقیقه طول می‌کشد. اپ از یک مانیفست که کامودور چاپ می‌کند
ساخته می‌شود، پس یک چسباندن است به جای یک صفحه چک‌باکس، و Socket Mode یعنی اصلاً
آدرس عمومی لازم نیست — به [از Slack](slack.md) نگاه کنید.

**واتس‌اپ** همان کار را می‌کند و حدود بیست دقیقه طول می‌کشد: یک اپ متا، یک شمارهٔ
تجاری، یک رمز اپ (app secret) و یک آدرس HTTPS عمومی، که هیچ‌کدام از داخل
ترمینال ساخته نمی‌شوند. فقط وقتی ارزشش را دارد که ناچار باشد واتس‌اپ باشد — به
[از WhatsApp](whatsapp.md) نگاه کنید.

در هر صورت تا وقتی شما نگویید، فقط می‌خواند و برنامه می‌ریزد، و رد کردنش هزینهٔ
فقط یک کلید دارد.

### و بعد پیشنهاد شروع می‌دهد

```
 What now?
   1  Start Comodor          — the interface, here in this terminal
   2  Start the Telegram bot — in the background, answers while this is closed
   3  Both
   4  Nothing yet            — `comodor` starts it whenever you want
```

نصب و راه‌اندازی قبلاً همین‌جا تمام می‌شد: برگشتن به پرامپت شل بدون هیچ چیز
در حال اجرا. یک خط گوشی برای هر کانالی که وصل شده و جفت‌سازی شده ظاهر می‌شود،
با نام درست — کسی که واتس‌اپ را راه انداخته به او «ربات تلگرام» پیشنهاد
نمی‌شود.

## ۳. می‌پرسد کدام پوشه

```
  Work in  /home/you/projects/api-server ?
```

هر پوشه یک بار پرسیده می‌شود. هر چیزی که عامل ممکن است دست بزند زیر همین پوشه
است — بدون اینکه آگاهانه آن را خاموش کنید، نمی‌تواند بیرون از آن بخواند یا
بنویسد. پوشه‌های تأییدشده به خاطر سپرده می‌شوند.

## ۴. چیزی بخواهید

بنویسید و Enter را بزنید.

```
> the tests in tests/test_parser.py are failing, work out why and fix it
```

فایل‌ها را می‌خواند، تست‌ها را اجرا می‌کند، و چیزی را عوض می‌کند. قبل از اینکه
فایلی بنویسد، یک diff و یک انتخاب به شما می‌دهد:

```
  Write  src/parser.py
    - 12 lines removed, 8 added
  [a] allow   [A] allow always this session   [d] deny
```

یک بار `a` را جواب بدهید، یا اگر ترجیح می‌دهید برای باقی نشست دیگر نپرسد، `A`
را. در هر صورت هر نوشتن یک نقطهٔ بازگشت دارد: `/undo` آخرین آن را برمی‌گرداند.

## ۵. اصلاحش کنید — این همان بخش مهم است

وقتی چیزی را غلط انجام داد، بگویید. دو راه هست، و هر دو یک چیز به او یاد
می‌دهند:

**خودتان فایل را ویرایش کنید.** کامودور می‌فهمد که در خروجی‌اش چه تغییر
داده‌اید.

**همین‌طور بگویید.**

```
> no — we use single quotes in this codebase, not double
```

در هر صورت به یک درس تبدیل می‌شود: دفعهٔ بعد که وضعیت شبیه به نظر برسد به یادش
می‌آید، با اطمینانی که وقتی درست از آب درآید بالا می‌رود و وقتی درست از آب
درنیاید کم می‌شود.

بعد از چند نشست:

```
> /progress
```

## اگر چیزی خراب شد

```bash
comodor doctor
```

هر چه می‌تواند را بررسی می‌کند و برای هر چیزی که پیدا کند می‌گوید چه بکنید.
`comodor doctor --fix` هر چه قابل تعمیر است را تعمیر می‌کند. به
[عیب‌یابی](troubleshooting.md) نگاه کنید.
