# مهارت‌ها

یک مهارت، رویه‌ای مکتوب است که عامل وقتی کار اقتضا کند دنبالش می‌رود.

نه یک پرامپت که هر بار بچسبانید — فایلی که خودش وقتی وضعیت شبیه بود بارگذاری
می‌کند.

---

## تهیه کردن چندتا

`comodor setup` کتابخانه را یک بار، در انتها، پیشنهاد می‌دهد. با کلیدهای جهت‌دار
حرکت کنید، **space** را برای تیک زدن هر تعدادی که خواستید بزنید، و **enter**
همهٔ آن‌ها را نصب می‌کند. از اول هیچ چیزی تیک نخورده است، و enter با هیچ چیزی
تیک‌خورده هیچ‌کدام را نمی‌گیرد — هرگز چیزی که نخواسته‌اید به شما داده نمی‌شود.

```
┌─ Skills ──────────────────────────────────────────────────┐
│    ☑ review        Review a change before it is committed │
│ ›  ☐ commit-style  Match the commit messages already here │
│    ☑ python-tests  Write tests the way this project does  │
└───────────────────────────────────── 2 selected ──────────┘
  ↑↓ move   space select   enter install 2   tab more   esc cancel
```

**هر مهارت یک خط**، تا کل فهرست فارغ از اینکه کتابخانه چقدر بزرگ شود در یک صفحه
جا شود، و پنجره دنبال فلش می‌رود نه اینکه از آن عقب بماند. بعضی از این
توضیح‌ها سرراست تا یک پاراگراف می‌روند — **tab** توضیح کامل هر چیزی که فلش روی
آن است را در همان فریم باز می‌کند، و دوباره tab آن را می‌بندد.

تایپ کردن فهرست را فیلتر می‌کند، که وقتی بیش از مشتی باشد از پیمایش سریع‌تر
است. تیک‌ها حین فیلتر کردن حفظ می‌شوند، پس می‌توانید فهرست را باریک کنید، یکی را
تیک بزنید، فیلتر را پاک کنید و یکی دیگر را تیک بزنید.

بدون ترمینال، می‌تواند کنترل را به دست بگیرد — یک پایپ، یک اسکریپت،
`curl | sh` — همان پرسش به شکل یک فهرست شماره‌دار پرسیده می‌شود، یک صفحه در هر
بار:

| | |
|---|---|
| `1,3` یا `1 3` | این‌ها را بردار |
| `m` / `b` | صفحهٔ بعد، صفحهٔ قبل |
| `/word` | فقط چیزهای منطبق را نشان بده |
| `?7` | توضیح کامل شمارهٔ ۷ را بخوان |
| enter | تمام |

شماره‌ها مطلق‌اند: شمارهٔ ۹۲ نودودومین مهارت است هر صفحه یا جست‌وجویی که در آن
باشید، پس عددی که یادداشت کرده‌اید همان عددی است که تایپ می‌کنید.

---

## استفاده کردن از یکی

```bash
comodor skills browse            # چه چیزهایی موجود است
comodor skills add review        # نصبش کن
comodor skills list              # شما چه دارید
```

```
/skills                          # همان، در رابط
```

از آن به بعد، وقتی چیزی بخواهید که یک مهارت پوشش می‌دهد، آن بارگذاری می‌شود و
عامل دنبالش می‌رود. وقتی این رخ می‌دهد به شما گفته می‌شود:

```
  ▸ skill: review — Review a change for correctness before it is committed
```

مهارتی که اعمال شدنش را نبینید، مهارتی است که نمی‌توانید اصلاحش کنید.

## نوشتن یکی

پوشه‌ای با یک `SKILL.md` در آن:

```
~/.comodor/skills/our-tests/SKILL.md
```

```markdown
---
name: our-tests
description: How tests are written and run in this project.
---

# Tests in this project

- pytest, never unittest.
- One file per module, mirroring `src/`.
- Name the test after the behaviour, not the function:
  `test_an_empty_input_raises`, not `test_parse_2`.
- Never mock what you can construct.

## Running them

    uv run pytest -x -q

Not `python -m pytest` — the project needs the venv's own interpreter.
```

**توضیح (description)** بیشترین اهمیت را دارد. همان چیزی است که کامودور با درخواست
شما مطابقت می‌دهد تا تصمیم بگیرد اصلاً مهارت را بارگذاری کند یا نه، پس آن را به
شکلِ وضعیت بنویسید، نه به شکل یک عنوان.

ری‌استارت کنید، یا `/skills`، و آنجاست.

### به همراه داشتن فایل

یک مهارت می‌تواند کنار `SKILL.md` فایل هم حمل کند:

```
~/.comodor/skills/our-tests/
  SKILL.md
  references/
    fixtures.md
    conventions.md
```

`SKILL.md` به آن‌ها اشاره می‌کند؛ عامل یکی را فقط وقتی می‌خواند که لازمش داشته
باشد. این خود مهارت را کوتاه نگه می‌دارد — که اهمیت دارد، چون مهارت در همان
نوبت بارگذاری می‌شود و یکی بلند، خواه جزئیات لازم باشد خواه نباشد، توکن می‌سوزاند.

---

## مخصوص هر پروژه

```
./.comodor/skills/<name>/SKILL.md
```

با مخزن کامیت می‌شود، پس همهٔ کسانی که روی آن کار می‌کنند همان رویه‌ها را
دارند. مهارت‌های پروژه کنار مهارت‌های شما بارگذاری می‌شوند.

---

## بودجه

```json
{
  "skills": {
    "enabled": true,
    "top_k": 2,
    "max_tokens": 12000
  }
}
```

`top_k` تعدادی است که در یک نوبت مجاز به بارگذاری‌اند؛ `max_tokens` سقفی است
روی اینکه روی‌هم چقدر ممکن است خرج کنند. مهارتی که بزرگ‌تر از آن باشد که جا
شود رد می‌شود، و به شما گفته می‌شود کدام — سکوت اینجا یک بار یک باگ واقعی بود،
که یک مهارتِ بیش از اندازه بزرگ، آرام و بی‌سروصدا مهارت‌های کوچک‌تر را از جایشان
می‌زد.

## مدیریتشان

```bash
comodor skills add review taste output    # چندتایی با هم
comodor skills update                     # تازه‌سازی نصب‌شده‌ها
comodor skills remove review
comodor skills list                       # با نسخه‌ها
```
