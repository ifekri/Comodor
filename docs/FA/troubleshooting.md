# عیب‌یابی

## از همین‌جا آغاز کنید

```bash
comodor doctor
```

فایل پیکربندی و مجوزهایش، ارائه‌دهنده، مدل، سقف خرج، مغز، نمایه‌ی جست‌وجو،
مهارت‌های شما، فایل‌های باقی‌مانده، سرورهای MCP، و اینکه آیا انتشار تازه‌تری
هست، بررسی می‌کند.

```bash
comodor doctor --fix
```

هر آنچه قابل ترمیم است ترمیم می‌کند. هرگز چیزی را تغییر نمی‌دهد که نخست گزارشش
نکرده باشد.

---

## اجرا نمی‌شود

**`comodor: command not found`، بلافاصله پس از نصب** — نصب‌کننده آن را روی
`PATH` شما گذاشته، اما یک فرآیند فرزند نمی‌تواند محیطِ پوسته‌ای که آن را اجرا
کرده تغییر دهد. تک‌تک ترمینال‌های *تازه* از همین حالا کار می‌کنند. برای ترمینالی
که الان در آن هستید، نصب‌کننده خطی برای چسباندن چاپ کرد؛ یا:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

**`comodor: command not found`، در یک ترمینال تازه** — این دیگر یک مشکل واقعی
است. `python -m comodor` تأیید می‌کند اصلاً نصب هست یا نه، و `ls ~/.local/bin/comodor`
می‌گوید کجاست که باید باشد.

**`No provider is configured`** — `comodor setup` را اجرا کنید، یا یک کلید
بریزید:

```bash
export ANTHROPIC_API_KEY=sk-ant-…
```

**Python خیلی قدیمی است.** Comodor به 3.11 یا تازه‌تر نیاز دارد. با
`python --version` بررسی کنید.

---

## یک تنظیم به نظر کاری نمی‌کند

Comodor وقتی یک تنظیم را رد می‌کند به شما می‌گوید:

```
config: agent.max_steps must be a whole number; keeping 0
config: this project cannot set safety, computer — only your own can
```

اگر چیزی گفته نمی‌شود و همچنان اثری ندارد، بررسی کنید کدام لایه برنده می‌شود:

```
/settings          # what is actually loaded
```

```bash
comodor doctor     # the same, plus where every file is
```

یک `--model` روی خط فرمان از فایل پیکربندی شما جلوتر است، و کلیدی در محیط
شما از کلیدِ فایل جلوتر. این از روی عمد است —
[پیکربندی](configuration.md#what-wins).

---

## `/save` چیزی را که انتظار داشتم ذخیره نکرد

از روی طراحی. **تنها آنچه خودتان برگزیده‌اید** را می‌نویسد — نه تنظیمات یک
مخزن، نه کلیدی که در محیط خود نگه می‌دارید، نه پرچمی که برای یک اجرا داده‌اید.

برای مالک شدنِ یک تنظیمِ مخزن، نخست خودتان آن را تنظیم کنید (`/model x`) و سپس
ذخیره کنید.

---

## درخواست‌ها شکست می‌خورند

**`401` یا `invalid api key`** — کلید غلط است، منقضی شده، یا متعلق به ارائه‌دهنده‌ای
دیگر است. `comodor doctor` نشان می‌دهد کدام ارائه‌دهنده فعال است.

**`404 model not found`** — آن ارائه‌دهنده آن شناسه‌ی مدل را سرو نمی‌کند.
`/model` فهرست می‌کند واقعاً چه می‌دهد.

**تایم‌اوت‌ها.** یک مدل محلی روی ماشینی معمولی می‌تواند واقعاً دقیقه‌ها طول
بکشد. `providers.<name>.timeout` را بالا ببرید.

**زود می‌ایستد.** به `stopped` نگاه کنید. `max_steps` و `budget` سقف‌هایی هستند
که کارشان را می‌کنند، نه شکست‌ها. برای یک اجرا با `--max-steps` بالا ببرید، یا
به‌طور دائمی زیر `agent`.

## سقف خرج کار نمی‌کند

احتمالاً اصلاً نمی‌تواند کار کند، و Comodor همین را می‌گوید. به
[هزینه — وقتی سقف نمی‌تواند فعال شود](cost.md#when-the-limit-cannot-fire)
ببینید.

## ابزار مرورگر

**«no browser found»** — Chrome، Chromium، Edge یا Brave را نصب کنید، یا
`browser.executable` را تنظیم کنید. بدون یکی، `browse` به مرورگر متنی برمی‌گردد
که همچنان به بیشتر پرسش‌ها درباره‌ی یک صفحه پاسخ می‌دهد.

**می‌خواهم کار کردنش را ببینم** — `browser.headless: false`.

**به ورودی‌ای نیاز دارد که من از قبل دارم** — مرورگر خودتان را با یک پورت
DevTools اجرا کنید و `browser.port` را تنظیم کنید، تا از آن نشست استفاده کند
به‌جای اینکه پروفایل شما به او سپرده شود.

---

## ابزار صفحه‌نمایش

**در فهرست ابزارها نیست.** یا این پلتفرم بک‌اند ندارد — فعلاً فقط ویندوز — یا
`computer.enabled` برابر false است. از او بپرسید:

```
/computer
```

**کلیک‌ها جای اشتباه می‌فرستند.** این نباید رخ دهد: آگاهی از DPI پیش از خواندن
هر سنجه‌ی صفحه‌نمایش تنظیم می‌شود. اگر شد، لطفاً با مقیاس و رزولوشن نمایشگرتان
گزارشش کنید. این یک باگ واقعی است.

**خودش متوقف شد.** موس به گوشه‌ای از صفحه‌نمایش رفته، که از روی عمد اعطا را
پایان می‌دهد. `/computer 15m` یکی دیگر آغاز می‌کند.

**متنی که رسیده همان نیست که تایپ کرده.** اپلیکیشن بازنویسیش کرده — Notepad در
Windows 11 همان‌طور که تایپ می‌کنید اصلاح می‌کند. باگ Comodor نیست، و روی هر
`type` همین را می‌گوید. [بیشتر](computer.md#typed-is-not-the-same-as-arrived).

## رابط وب

**از اجرا خودداری می‌کند.** هیچ ارائه‌دهنده‌ای پیکربندی نشده، و رابط مرورگری
راهی برای اضافه کردن ندارد. پیام می‌گوید چه چیزی را تنظیم کنید.

**«Unauthorised».** در هر اجرا توکن تازه‌ای ساخته می‌شود — از URL اجرای *همین*
اجرا استفاده کنید، یا `COMODOR_WEB_TOKEN` را تنظیم کنید تا پایدار بماند.

**در Docker، هیچ چیز در `localhost:8765`.** بررسی کنید پورت به‌صورت
`127.0.0.1:8765:8765` منتشر شده باشد. [Docker](docker.md).

---

## چیزی کند است

**نخستین درخواست یک نشست.** هنوز هیچ چیزی کش نشده؛ دومی بسیار تندتر است.

**بازاندیشی پس از هر کار.** یک فراخوانی مدل. برای یکی ارزان‌تر از
`learning.reflect_model` استفاده کنید، یا `reflect: false`.

**اسکرین‌شات‌ها.** حدود ۸۰ میلی‌ثانیه برای گرفتن، به‌علاوه‌ی نگاه مدل به آن‌ها.
`computer.screenshot_tokens` را پایین بیاورید، اگر همچنان می‌توانید نتیجه را
بخوانید.

```bash
comodor uninstall --dry-run     # what would go, named
comodor uninstall               # do it
```

```bash
rm ~/.comodor/brain.db
```

## گزارش یک مشکل

این‌ها را ضمیمه کنید:

```bash
comodor --version

```

`doctor` کلید شما را پوشانده می‌کند. لطفاً به هر حال پیش از چسباندن، خروجی را
بخوانید.
