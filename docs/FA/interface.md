# رابط کاربری

چه می‌بینید، چه می‌فشارید، و هر ۲۹ فرمان.

```bash
comodor          # راه‌اندازی
comodor --demo   # کل رابط، آفلاین، بدون کلید
```

---

## چیدمان

```
┌────────────────────────────────────────────────────────────────────────┐
│  Comodor                              Anthropic · claude-sonnet-5      │
│  ────────────────────────────────────────────────────────────────────  │
│                                                                        │
│  TASKS                    > fix the failing parser test                │
│  ● read the test          ▸ read_file  tests/test_parser.py     0.1s   │
│  ◐ find the cause         ▸ run_shell  pytest tests/test_pa…    2.3s   │
│  ○ fix it                                                              │
│                           The test expects `parse("")` to raise, but…  │
│                                                                        │
│  ────────────────────────────────────────────────────────────────────  │
│  ▌Type a task, or / for commands                                       │
│                                                                        │
│  act · loop on · 12% of 1M · $0.03      ⏎ send  ^O attach  F3 mode     │
└────────────────────────────────────────────────────────────────────────┘
```

**نوار کناری** همان برنامه است، وقتی برنامه‌ای در کار باشد. `F2` آن را پنهان
می‌کند — روی یک ترمینال تنگ این کار ارزشش را دارد.

**خط وضعیت** حالت را نشان می‌دهد، اینکه آیا در حال تکرار است، چقدر زمینهٔ
(context) پر شده، و این نشست چه هزینه‌ای داشته. عدد زمینه واقعی است: از مدل
پیروی می‌کند، پس رفتن از یک مدل میلیون‌توکنی به یک مدل ۱۲۸ هزار توکنی همان لحظه
آن را عوض می‌کند.

از حدود ۶۰ ستون به بالا کار می‌کند. پایین‌تر از آن نوار کناری خودش جمع می‌شود.
`comodor preview 80x24` آن را در هر اندازه‌ای، بدون شروع یک نشست، رندر می‌کند.

## حالت‌ها

| حالت | کاری که عامل اجازه دارد بکند | |
|---|---|---|
| **act** | همه‌چیز، با پرسیدن قبل از نوشتن‌ها و فرمان‌ها | پیش‌فرض |
| **plan** | فقط خواندن. نه نوشتن، نه فرمان، نه شبکه | برای «چه می‌خواستی بکنی؟» |
| **chat** | هیچ ابزاری اصلاً | برای پرسشی دربارهٔ کدی که می‌چسبانید |

`F3` بین آن‌ها می‌چرخد. `/mode plan` یکی را مستقیم تعیین می‌کند.

حالت plan واقعاً فقط‌خواندنی است — در لایهٔ مجوز اعمال می‌شود، نه با خواهش
وتمنای مدل. ابزاری که ریسکش بالاتر از «safe» باشد قبل از اجرا رد می‌شود.

## فرمان‌ها

`/` را تایپ کنید و فهرست همان‌طور که می‌روید فیلتر می‌شود.

### بخواهید که کاری که می‌کند را عوض کند

| | |
|---|---|
| `/mode [act\|plan\|chat]` | به چه کاری اجازه دارد |
| `/loop` | کار کردن تا تمام شود، یا یک بار پاسخ دادن |
| `/model [id]` | انتخاب مدل — یک فهرست، یا نام بردن یکی |
| `/provider [name]` | انتخاب ارائه‌دهنده |
| `/gw` | دروازه: مسیریابی میان ارائه‌دهنده‌ها بر اساس هزینه، سرعت یا کیفیت |

### یاد بدهید

| | |
|---|---|
| `/good` | آن پاسخ درست بود |
| `/bad` | آن پاسخ غلط بود |
| `/teach <text>` | این را به خاطر بسپار |
| `/memory` | چه چیزهایی یاد گرفته |
| `/rules` | قواعد مشترکی که از کد و ویرایش‌های شما درآورده |
| `/progress` | مدرکی بر اینکه دارد بهتر می‌شود |
| `/skills` | رویه‌هایی که وقتی کار شبیه باشد دنبال می‌کند |

`/good` و `/bad` ارزان‌ترین کاری است که برایش می‌توانید بکنید. به
[نحوهٔ یادگیری آن](learning.md) نگاه کنید.

### برگرداندن و مرور گذشته

| | |
|---|---|
| `/undo` | برگرداندن آخرین فایلی که عوض کرد |
| `/clear` | شروع یک گفت‌وگوی تازه |
| `/resume [id]` | باز کردن دوبارهٔ یک نشست قبلی |
| `/search <text>` | یافتن چیزی در یک گفت‌وگوی قبلی |
| `/export [path]` | نوشتن این نشست در یک فایل |

### دامنه‌اش را گسترش دهید

| | |
|---|---|
| `/computer [15m\|1h this app\|stop]` | بگذارید از صفحهٔ شما استفاده کند — [راهنما](computer.md) |
| `/mcp` | سرورهای MCP و ابزارهایشان — [راهنما](mcp.md) |
| `/attach <path>` | افزودن یک فایل به پیام بعدی |

### سر و سامان بدهید

| | |
|---|---|
| `/settings` | همین حالا چه چیزهایی پیکربندی شده |
| `/approve [writes\|shell\|all]` | قبل از آن‌ها دیگر نپرسد |
| `/theme [name]` | ember، midnight، matrix، mono |
| `/save` | نوشتن تنظیمات فعلی در فایل پیکربندی شما |
| `/cost` | توکن‌ها، هزینه، و اینکه حافظهٔ نهان چه چیزی را صرفه‌جویی کرد |
| `/copy [all\|task]` | آخرین پاسخ، یا همه‌چیز، به کلیپ‌بورد |
| `/mouse [on\|off]` | ردگیری موس، تا خودتان بتوانید متن را انتخاب کنید |
| `/help` | همهٔ همین‌ها، داخل رابط |
| `/quit` | خروج |

**`/save` فقط همان چیزی را می‌نویسد که شما انتخاب کرده‌اید.** نه تنظیمات
مخزن را، نه کلیدی که در محیط (environment) نگه می‌دارید را، نه `--model`ای که
فقط برای یک اجرا پاس داده‌اید. به
[پیکربندی](configuration.md#what-save-writes) نگاه کنید.

## تأییدها

وقتی عامل بخواهد فایلی بنویسد یا فرمانی اجرا کند:

```
  Write  src/parser.py
  ────────────────────────────────────────────
   - def parse(text):
   -     return text.split(",")
   + def parse(text):
   +     if not text:
   +         raise ValueError("nothing to parse")
   +     return text.split(",")

  [a] allow   [A] allow always this session   [d] deny
```

`A` برای کل نشست، به تفکیک نوع کار به خاطر می‌سپارد — اجازهٔ نوشتن‌ها اجازهٔ
فرمان‌ها را هم نمی‌دهد.

رد کردن هدررفت نیست. یک رد کردن روشن‌ترین سیگنالِ ترجیحی است که رابط تا به حال
جمع می‌کند، و به موتور یادگیری می‌رود: احتمال اینکه عامل دوباره چنین چیزی پیشنهاد
دهد کمتر می‌شود.

برای اینکه اصلاً نپرسد:

```
/approve writes      files, yes; commands, still ask
/approve all         everything
```

همه‌چیز همچنان نقطهٔ بازگشت دارد. `/undo` در هر حال کار می‌کند.

## بیرون کشیدن متن

وقتی موس در حال ردگیری است، یک درگ متعلق به کامودور است و ترمینال هرگز آن را
نمی‌بیند — پس انتخاب و کپی همیشگی کار نمی‌کند. سه راه دور زدنش:

```
/copy              the last answer
/copy all          the whole conversation
/copy task         the last thing you asked for
/mouse             mouse tracking off, so selection works as usual
```

`/copy` در ویندوز یا macOS چیزی برای نصب نمی‌خواهد. در لینوکس از `wl-copy`،
`xclip` یا `xsel` استفاده می‌کند — هر کدام که باشد — و اگر هیچ‌کدام نباشد
می‌گوید کدام غایب است.

روی SSH به یک دنبالهٔ گریز (escape sequence) برمی‌گردد که از ترمینالِ *خودتان*
می‌خواهد کلیپ‌بوردِ *خودتان* را تنظیم کند — پس متن از عاملی روی یک سرور جایی
می‌نشیند که بتوانید بچسبانیدش، نه روی سروری که اصلاً کلیپ‌بورد ندارد.

بیشتر ترمینال‌ها اجازه می‌دهند با نگه داشتن **Shift** متن را انتخاب کنید، که ردگیری
موس را دور می‌زند بدون آنکه خاموشش کند.

## چه کسی دارد حرف می‌زند

هر نوبت روی یک نوار کم‌رنگ می‌نشیند — یک سایه پشت چیزی که شما تایپ کرده‌اید،
و سایه‌ای دیگر پشت پاسخ:

```
▌ › why does the parser drop the last field?              ← warm

▌   Because split is called with a maxsplit of 2 …        ← neutral
▌
▌   ┌─ python ────────────────────────┐
▌   │ return text.split(',', 2)       │
▌   └─────────────────────────────────┘
```

عمداً کم‌رنگ است. این پشت متنی است که دقایق طولانی آن را می‌خوانید، و پس‌زمینه‌ای
که هر حضور مستقلی داشته باشد با کلمات رقابت می‌کند. هر پوسته جفت مخصوص خودش را
دارد، چند درصد فاصله از پس‌زمینه‌اش؛ `mono` هیچ‌کدام را ندارد، چون پوسته‌ای که
مبنایش نبودِ رنگ است دو تا هم نمی‌خواهد.

هیچ فضای عمودی نمی‌گیرند — تغییر رنگ همان مرز است.

## متن راست‌به‌چپ

فارسی، عربی و عبری به سمت راست حروف‌چینی می‌شوند، همان‌جا که خطوطشان آغاز
می‌شود، با پشتهٔ فونتی که برایشان مناسب است. پاراگراف‌های درهم — یک شناسهٔ
انگلیسی درون جمله‌ای فارسی — خط‌به‌خط اداره می‌شوند نه فایل‌به‌فایل، که همان
چیزی است که واقعاً در یک گفت‌وگوی فنی اتفاق می‌افتد.

## پوسته‌ها

```
/theme midnight
```

`ember` (پیش‌فرض، کهربایی گرم)، `midnight` (آبی خنک)، `matrix` (سبز)،
`mono` (بدون هیچ رنگی).

`--ascii` نویسه‌های خط‌کشی جعبه را با ASCII عوض می‌کند، برای ترمینال‌هایی که
آن‌ها را ندارند. `NO_COLOR` در محیط شما محترم شمرده می‌شود.
