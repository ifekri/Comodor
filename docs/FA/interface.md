# رابط کاربری

چه می‌بینید، چه می‌فشارید، و هر چیزی که روی صفحه است از کجا می‌آید.

```bash
comodor          # راه‌اندازی
comodor --demo   # کل رابط، آفلاین، بدون کلید
```

رابط روی [Bun](https://bun.sh) اجرا می‌شود — `comodor doctor` می‌گوید هست یا
نه. بدون آن، `comodor run "..."` یک کار را بدون رابط انجام می‌دهد و
`comodor web` یکی را به مرورگر می‌رساند.

برای اینکه چطور ساخته شده — هسته‌ای که آن را می‌راند، پروتکل میان آن دو، و
اینکه چرا هر واقعیت روی صفحه از آنِ هسته است نه از آنِ صفحه — به
[tui-v2.md](../tui-v2.md) نگاه کنید. این صفحه نسخهٔ کوتاه برای کسی است که از
آن استفاده می‌کند.

## صفحه

```
┌──────────────────────────────────────────┬───────────────────────┐

│  ● run_shell  pytest tests/…     running…│                       │
│      collected 12 items                  │                       │
│                                          │                       │
├──────────────────────────────────────────┴───────────────────────┤
│ ▌ask for anything                                                │
├──────────────────────────────────────────────────────────────────┤
│  [ACT]   PLAN    ASK    Reads, writes and runs commands…         │
│ ● 1 agent  tab Mode  ctrl+b Work  ctrl+k Commands      42% ctx  │
└──────────────────────────────────────────────────────────────────┘
```

**سرصفحه** نام پروژه و ارائه‌دهنده و مدلی را می‌گوید که پاسخ می‌دهند. این
همان چیزی است که هسته گزارش می‌کند، نه آنچه یک فایل پیکربندی می‌گوید: وقتی مدل
عوض شود — از همین‌جا، از کلاینتی دیگر، یا به دست خود هسته — سرصفحه دنبالش
می‌رود.

**گفتگو** خط زمانی ابزارها را درون خودش دارد. هر فراخوانی ابزار همان‌جایی
می‌نشیند که رخ داده، به شکل یک سطر: یک نشان (`●` در حال اجرا، `✓` تمام‌شده،
`×` ناموفق)، نام، یک خط خلاصه، و اینکه چقدر طول کشید. ابزار در حال اجرا
آخرین سطرهای خروجی‌اش را نشان می‌دهد؛ ابزار تمام‌شده جمع می‌شود، و کلیک روی
آن هر چه هسته هنوز نگه داشته را باز می‌کند.

**میز کار** — `Ctrl+B` — کارهای بیرون از گفتگوست: فهرست وظایفی که عامل برای
خودش نگه می‌دارد، و هر عامل پس‌زمینه‌ای که راه انداخته، هرکدام با وضعیتش. در
ترمینال باریک به جای کنار گفتگو، روی آن باز می‌شود، و همان کلید آن را می‌بندد.

**پانوشت** آنچه می‌توانید بفشارید را چاپ می‌کند، از همان فهرستی که کلیدها از
آن خوانده می‌شوند، و اینکه این نشست تا اینجا چقدر هزینه داشته، هر جا که
ارائه‌دهنده اندازه می‌گیرد.

## کلیدها

| کلید | کار |
|---|---|
| `Enter` | آنچه نوشته‌اید را بفرست |
| `Tab` / `Shift+Tab` | حالت بعدی / قبلی |
| `Ctrl+K` | پالت فرمان — هر عملی، قابل جست‌وجو |
| `Ctrl+B` | باز یا بسته کردن میز کار |
| `End` | بعد از بالا رفتن، برگشت به تازه‌ترین خروجی |
| `PageUp` / `PageDown` | پیمایش گفتگو |
| `Ctrl+R` | فرستادن دوبارهٔ پیامی که هسته رد کرد |
| `Ctrl+C` | متوقف کردن کاری که می‌کند؛ خروج وقتی بیکار است |
| `Ctrl+D` | خروج |
| `Esc` | بستن پالت، بیرون آمدن از یک فیلد، یا گرفتن گزینهٔ امنِ یک کارت |

هر میان‌بری که پانوشت نشان می‌دهد وجود دارد؛ راهنمایی برای کلیدی که بسته نشده
چاپ نمی‌شود.

## حالت‌ها

```
ACT    می‌خواند، می‌نویسد و فرمان اجرا می‌کند، و پیش از تغییر دادن چیزی می‌پرسد
PLAN   می‌خواند و برنامه می‌ریزد؛ نمی‌تواند بنویسد، اجرا کند یا چیزی را تغییر دهد
ASK    فقط گفتگو می‌کند؛ هیچ ابزاری در کار نیست
```

`Tab` میان آن‌ها می‌چرخد. برچسب وقتی جابه‌جا می‌شود که هسته تأیید کند، نه وقتی
کلید فشرده می‌شود: فشارهای درون یک رفت‌وبرگشت روی هم جمع می‌شوند — سه `Tab`
یک بار می‌پرسد، برای همان‌جایی که سومی اشاره کرده — و تغییرِ ردشده به جای
جابه‌جا کردن برچسب، با کلمات می‌گوید.

## وقتی چیزی از شما می‌پرسد

یک کارت مجوز یا یک فرم پرسش تا وقتی بالاست صفحه‌کلید را می‌گیرد، تا کلیدی که
برای یک تصمیم زده شده نتواند همزمان پیامی هم بفرستد.

- **کلیدهای جهت‌دار** میان گزینه‌ها یا پرسش‌ها حرکت می‌کنند؛ **Enter**
  می‌فرستد.
- **Esc** گزینهٔ امنِ خودِ درخواست را می‌گیرد — برای مجوز *رد* است، برای
  پیشنهاد تغییر حالت *بدون تغییر* — و کارت می‌گوید کدام. هرگز چیزی را اجازه
  نمی‌دهد.
- برای *اجازه* میان‌بر تک‌کلیدی وجود ندارد. اجازه دادن یک حرکت تا گزینه و یک
  حرکت برای تأییدش هزینه دارد، تا کلیدی که به هر دلیل دیگری فشرده شده نتواند
  فرمانی را مجاز کند.
- پرسشی که ردیفِ «خودتان بنویسید» دارد با `Space` فیلدی برایش باز می‌کند؛
  `Esc` پیش از آنکه فرم را لغو کند، از فیلد بیرون می‌آید.

دو چیز می‌توانند همزمان منتظر باشند — دو ابزار موازی ممکن است هرکدام بپرسند —
و به ترتیب رسیدن نشان داده می‌شوند، بی‌آنکه یکی گم شود.

کلیدهای حالت وقتی کارتی بالاست همچنان کار می‌کنند. پالت نه: یک راه‌انداز روی
یک تصمیم، چیزی را پنهان می‌کرد که باید پاسخ داده شود.

## دنبال کردن

پاسخ بلند تازه‌ترین سطر را در دید نگه می‌دارد. بالا بروید و دنبال کردن متوقف
می‌شود؛ خروجی تازه شما را پایین نمی‌کشد، و یک نشانگر می‌گوید پایین‌تر باز هم
هست. `End` به دنبالهٔ زنده برمی‌گرداند، و فرستادن پیام تازه هم همین کار را
می‌کند.

---

## نشست‌ها

`Ctrl+K` ← *بازکردن یک گفتگوی پیشین* آنچه هسته نگه داشته را فهرست می‌کند و
یکی را همان‌جا باز می‌کند. همین انبار به مرورگر هم خدمت می‌دهد، پس گفتگویی که
اینجا آغاز شده می‌تواند آنجا باز شود.

`comodor --resume` تازه‌ترین را هنگام شروع باز می‌کند؛ `--resume ID` یکی را
نام می‌برد.

---

## بیرون کشیدن متن

با موس، آن‌طور که ترمینالتان اجازه می‌دهد، انتخاب کنید. پرچم‌های `--theme` و
`--ascii` روی آنچه فرمان‌ها چاپ می‌کنند اثر دارند — `setup`، `doctor`،
`help` — نه روی رابط، که از توکن‌های طراحی خودش می‌کشد.

---

## متن راست‌به‌چپ

فارسی، عربی و سطرهای مخلوط همان‌طور که نوشته شده‌اند به ترمینال داده می‌شوند،
و برنامه هرگز آن‌ها را وارونه نمی‌کند. اینکه یک سطر مخلوط چقدر خوب شکل بگیرد
کار ترمینال است، و آن‌هایی که خوب شکل می‌دهند اینجا هم خوب شکل می‌دهند.
