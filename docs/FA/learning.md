# چگونه یاد می‌گیرد

بیشتر ایجنت‌ها لحظه‌ای که نشست تمام می‌شود فراموش می‌کنند. این یکی تماشا می‌کند
چه چیزی را درباره‌ی خروجی‌اش تغییر می‌دهید، و آن را نگه می‌دارد.

---

## ایده

ستایش ارزان است و اصلاح‌ها گران، پس اصلاح‌ها هستند که از آن‌ها یاد می‌گیرد.

وقتی فایلی را که نوشته ویرایش می‌کنید، یا ساده و رک به او می‌گویید که اشتباه
بود، آن می‌شود یک **درس**: قاعده‌ای کوتاه با اطمینانی که هر بار که درست از آب
درآید بالا می‌رود و وقتی بلااستفاده بماند کم می‌شود. درس‌ها وقتی موقعیت شبیه به
نظر برسد فراخوانی می‌شوند، و به همان نوبت تزریق می‌شوند — هرگز به پرامپت سیستم،
که کش پرامپت را به بها می‌انداخت.

هیچ چیزی از ماشین شما بیرون نمی‌رود. مغز یک فایل SQLite زیر دایرکتوری پیکربندی
شماست.

---

## دو مسیر

### بازتاب (Reflex) — رایگان، بی‌درنگ، همیشه روشن

بدون فراخوانی مدل، بدون توکن، بدون تأخیر.

- **اصلاح‌ها.** شما در فایلی که او نوشته `"` را به `'` تغییر می‌دهید. آن یک
  دیف است، و دیف یک واقعیت است.
- **قواعد.** یک بار، در آغاز، کد موجود شما را می‌خواند و از آن سنت‌ها را
  بیرون می‌کشد — تورفتگی، سبک نقل‌قول، نام‌گذاری تست‌ها.
- **اعلام‌ها.** وقتی قاعده‌ای اعمال می‌شود، می‌گوید، در یک خط. قاعده‌ای که
  نمی‌بینید، قاعده‌ای است که نمی‌توانید اصلاحش کنید.
- **پیش‌واکشی.** فراخوانی وقتی آغاز می‌شود که هنوز در حال تایپ هستید.

این مسیر حتی وقتی بازاندیشی خاموش است هم روشن است، چون هیچ بهایی ندارد.

### بازاندیشی (Reflection) — یک فراخوانی مدل، پس از یک کار

در پایان یک کار به آنچه رخ داد نگاه می‌کند و آنچه را که باید به یاد بسپارد
می‌نویسد. این یکی بهای یک فراخوانی را دارد. اگر خواستید برایش مدلی ارزان‌تر
بکارید:

```json
{ "learning": { "reflect_model": "claude-haiku-4-5" } }
```

یا خاموشش کنید، با نگه داشتن Reflex:

```json
{ "learning": { "reflect": false } }
```

## آموزش دادنش، آگاهانه

| | |
|---|---|
| `/good` | آن پاسخ درست بود |
| `/bad` | آن پاسخ غلط بود |
| `/teach we use pytest, never unittest` | این را به یاد بسپار |

`/good` و `/bad` یک کلید می‌گیرند و ارزان‌ترین کاری هستند که می‌توانید برایش
بکنید.

رد کردن یک پیام اجازه هم به او می‌آموزد. یک رد، واضح‌ترین سیگنال ترجیحی است که
رابط جمع می‌کند، و همین‌طور هم رفتار می‌شود.

## دیدن آنچه می‌داند

```
/memory
```

فهرستی قابل جست‌وجو — هر درس با آنچه آن را راه می‌اندازد، چه می‌گوید، جنسش و
اطمینان کنونیش:

```
┌─  Memory (23)  ────────────────────────────────────────────────────┐
│ ›  #41 writing Python strings                                      │
│      Use single quotes for string literals.  [style 91%]           │
│    #38 adding a test                                               │
│      Tests go in tests/, mirroring the src layout.  [layout 84%]   │
│    #29 adding a dependency                                         │
│      Ask before adding one; this project has exactly one.  [78%]   │
│    #12 parsing empty input                                         │
│      Raise, do not return an empty list.  [behaviour 62%]          │
└────────────────────────────────────────────────────────────────────┘
  ↑↓ move   enter open   type filter   esc close
```

`/memory <text>` جست‌وجو می‌کند. باز کردن یکی به شما اجازه‌ی پین کردنش را می‌دهد،
تا از پژمردن باز بایستد، یا اگر غلط بود حذفش کنید.

```
/rules
```

قواعد خانه، که از کد شما بیرون کشیده، نه از اینکه شما به او گفته باشید.

## فراخوانی، و چرا در پرامپت سیستم نیست

درس‌های فراخوانی‌شده سوار بر نوبت‌اند، بخشی از پیام کاربر، نه در پرامپت سیستم.

این یک تصمیم درباره‌ی بها است. کش پرامپت تنها روی پیشوندی بایت‌به‌بایت یکسان
کار می‌کند، و پرامپت سیستم همان پیشوند است. گذاشتن هر چیز وابسته به پرسش در
آن، کش را در هر یک نوبت باطل می‌کند. انتقال فراخوانی روی نوبت، نرخ موفقیت کش
اندازه‌گیری‌شده را از ۷۲٪ به ۸۷٪ برد. به [هزینه](cost.md) ببینید.

## واژه‌هایی که از شما می‌آموزد

می‌آموزد کدام واژه‌های *شما* با هم می‌آیند، از کارهای تمام‌شده‌ی خودتان — اینکه
«پارسر» و «توکنایز» به یک گوشه از کدبیس شما تعلق دارند. این نه توکنی به بها
می‌گذارد و نه فراخوانی مدل؛ شمردن است.

همین است که درسی که درباره‌ی «توکنایزر» ثبت شده، وقتی درباره‌ی «لکسر» می‌پرسید
سر برمی‌آورد.

```json
{ "learning": { "associative": true } }
```

---

## دامنه

```json
{ "learning": { "share_scope": "project" } }
```

`project` درس‌ها را به مخزنی که در آن آموخته شده‌اند محدود می‌کند — پیش‌فرضِ
درست، چون سنت‌ای در یک کدبیس، در دیگری غلط است. `global` همه‌جا شریک‌شان می‌کند.

---

## فراموش کردن

درسی که بلااستفاده بماند پژمرده می‌شود. `half_life_days` (پیش‌فرض ۴۵) تعیین
می‌کند چقدر تند، و `min_confidence` (۰٫۱۵) کف است که زیر آن دیگر فراخوانی
نمی‌شود.

این مهم است: یک کدبیس نظرش را عوض می‌کند، و ایجنتی که سنتِ دوساله‌ای را با
اطمینان کامل نگه دارد، از یکی که فراموش کرده بدتر است.

---

## خاموش کردنش

```json
{ "learning": { "enabled": false } }
```

همه چیز همچنان کار می‌کند. فقط هر نشست را مثل یک غریبه آغاز می‌کند.
