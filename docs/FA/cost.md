## حافظهٔ نهان پرامپت، که بیشترِ کار همین است

هر درخواست، بخش‌هایی را که عوض نمی‌شوند دوباره می‌فرستد — پرامپت سیستم،
اسکیماهای ابزارها، گفت‌وگو تا اینجا. ارائه‌دهنده‌ها یک پیشوند کاملاً یکسان بایت‌به‌بایت
را با حدود یک‌دهم قیمت دوباره سرو می‌کنند.

کامودور دور همین ساخته شده، و به صورت پیش‌فرض روشن است:

```json
{ "agent": { "prompt_cache": true, "prompt_cache_ttl": "5m" } }
```

اندازه‌گیری روی نشست‌های واقعی: **۸۶٪ توکن‌های ورودی از حافظهٔ نهان سرو شده**.

### چرا هیچ چیز پویا وارد پرامپت سیستم نمی‌شود

حافظهٔ نهان فقط روی پیشوندی کار می‌کند که با بارات قبلی، بایت‌به‌بایت یکسان
باشد. پرامپت سیستم *همان* پیشوند است. هر چیزی که در هر نوبت عوض می‌شود — درس‌های
به یاد آمده، مهارت منطبق، ساعت روز — آن را باطل می‌کند، و شما برای همه‌چیز، در
هر نوبت، قیمت کامل می‌پردازید.

پس درس‌های به یاد آمده سوار بر *نوبت* می‌شوند، به عنوان بخشی از پیام کاربر.
همین یک تغییر، نرخ برخورد اندازه‌گیری‌شدهٔ حافظهٔ نهان را از ۷۲٪ به ۸۷٪ برد.

اگر دستورهای همیشگی خودتان را اضافه می‌کنید، در
`agent.system_prompt_extra` بگذارید، که پایدار است، به جای اینکه متغیرشان کنید.

### حافظهٔ نهان یک‌ساعته

```json
{ "agent": { "prompt_cache_ttl": "1h" } }
```

*نوشتن* یک مدخل حدود ۲۵٪ گران‌تر تمام می‌شود و به جای پنج دقیقه یک ساعت نگهش
می‌دارد. اگر مدام به یک نشست برمی‌گردید می‌ارزد؛ برای یک انفجار تک‌بارهٔ کار
هدر دادن است.

## سقف‌ها

```json
{
  "agent": {
    "max_steps": 0,
    "max_seconds": 3600,
    "max_cost_usd": 2.0
  }
}
```

هر کدام زودتر برسد وظیفه را می‌ایستاند، و `0` یعنی بی‌نهایت. `stopped` در
`--json` می‌گوید کدام بوده.

**به صورت پیش‌فرض هیچ سقف گامی نیست.** بیست‌وچهار گام روی یک کدبیس واقعی هیچ
چیز نیست — یک refactor روی دوازده فایل وسط فکر جا کم آورد — و شمار گام هیچ
ربطی به آسیب ندارد: ده گام خواندن فایل تقریباً هیچ هزینه‌ای ندارد. سقف‌هایی که
واقعاً با آسیب متناظرند زمان و پول‌اند، و آن‌ها روشن می‌مانند. اگر توقف سخت را
می‌خواهید برگردانید، `max_steps` را روی یک عدد بگذارید.

وقتی یکی از آن‌ها واقعاً وظیفه‌ای را می‌ایستاند، پیام می‌گوید چطور از آن بگذرید،
و گفتنِ «continue» از همان‌جا که بود ادامه می‌دهد.

### وقتی سقف نمی‌تواند فعال شود

**یک سقف هزینه فقط برای مدلی با نرخِ منتشرشده کار می‌کند.**

جدول قیمت‌گذاری عمداً نرخ مدل‌هایی که به آن‌ها مطمئن نیست را خالی می‌گذارد —
اختراع یک قیمت، اعداد غلط تولید می‌کند که از بی‌عددی بدتر است. برای یک مدل
بدون قیمت، کنتور هزینه صفر را می‌خواند، پس `spent >= max_cost_usd` هرگز درست
نمی‌شود و سقف هرگز فعال نمی‌شود.

کامودور به جای اینکه بگذارد فکر کنید در حفاظ هستید، همین را می‌گوید:

```
the $2.00 spend limit cannot be enforced for gpt-4o — no published rate is
known, so the cost meter reads zero. The step and time limits still apply.
```

در شروع نشست گفته می‌شود، و در `comodor doctor`:

```
  warn  spend limit    $2.00 per task cannot be enforced for gpt-4o
                       → No published rate is known for this model, so the
                         cost meter reads zero and the limit never fires.
                         The step and time limits still apply.
```

برای مدلی که روی دستگاه خودتان اجرا می‌شود چیز دیگری می‌گوید، چون آنجا از اول
هیچ هزینه‌ای ندارد.

## چه چیزی واقعاً پول خرج می‌کند

**اسکرین‌شات‌ها.** هر کدام حدود ۱,۶۰۰ توکن بصری با بودجهٔ پیش‌فرض — و دوباره در
هر نوبتی که در گفت‌وگو بمانند. کامودور دو تای آخر را نگه می‌دارد و بقیه را با
خطی جایگزین می‌کند که می‌گوید یکی آنجا بوده. بدون این، یک وظیفهٔ سی‌گامی
دسکتاپ چیزی نزدیک به پنجاه هزار توکنِ پیکسل حمل می‌کند که صفحاتی را توصیف
می‌کنند که از آن به بعد کلیک شده‌اند.

```json
{ "agent":    { "keep_screenshots": 2 } }
{ "computer": { "screenshot_tokens": 1600 } }
```

`screenshot_tokens` را خیلی پایین نگذارید. عکسی که مدل نتواند بخواند از بی‌عکسی
بدتر است: به جای پرسیدن حدس می‌زند. به
[استفاده از صفحهٔ شما](computer.md#screenshots-and-what-they-cost) نگاه کنید.

**خروجی بزرگ ابزار.** با `agent.max_tool_chars` کران‌دار می‌شود. چیزی که جا
نمی‌شود در فایلی نوشته می‌شود که به مدل گفته می‌شود چطور بخواندش، پس فقط وقتی
هزینه می‌دهد که نگاهش کند.

**بازاندیشی (reflection).** یک فراخوان مدل در پایان هر وظیفه. به سمت مدلی
ارزان‌تر نشانه بگیرید:

```json
{ "learning": { "reflect_model": "claude-haiku-4-5" } }
```

یا خاموشش کنید. خط رایگان — اصلاح‌ها، قواعد، اعلان‌ها — به هر حال کارش را
می‌کند. [نحوهٔ یادگیری آن](learning.md#the-two-lanes).

**مرورگر، وقتی نگاه کند.** `browse` به صورت پیش‌فرض متن برمی‌گرداند و فقط وقتی
خواسته شود اسکرین‌شات می‌دهد، چون عکس یک صفحه هر بار همان‌قدر هزینه دارد و
قابل کوتاه‌کردن نیست.
