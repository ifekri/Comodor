# مستندات کامودور

یک عامل (agent) کدنویسی در ترمینال که از نحوهٔ اصلاح‌های شما یاد می‌گیرد.

تازه رسیده‌اید؟ **[شروع به کار](getting-started.md)** حدود پنج دقیقه طول می‌کشد و
با کاری مفید از طرف عامل به پایان می‌رسد.

## کوتاه‌ترین نسخهٔ ممکن

```bash
curl -fsSL get.comodor.ai | sh      # macOS, Linux
irm get.comodor.ai | iex           # Windows

comodor                  # چند پرسش می‌پرسد، فقط یک بار
```

سپس بنویسید چه می‌خواهید. وقتی اشتباه کرد اصلاحش کنید — فایل را ویرایش کنید،
یا همین‌طور بگویید — و یاد می‌گیرد. `/progress` نشان می‌دهد که آیا این واقعاً
جواب می‌دهد.

```bash
comodor run "fix the failing test in tests/test_parser.py"   # یک وظیفه، بدون رابط
comodor web                                                  # از یک مرورگر
comodor doctor                                               # همه‌چیز سر جایش است؟
comodor help                                                 # صفحهٔ راهنمای مکتوب
```

## چه چیزی آن را متفاوت می‌کند

**از اصلاح‌ها یاد می‌گیرد، نه از تعریف و تمجید.** بیشتر عامل‌ها به محض پایان
نشست همه‌چیز را فراموش می‌کنند. کامودور می‌بیند که در خروجی‌اش چه تغییر می‌دهید
و از آن درسی می‌سازد با اطمینانی که وقتی درست از آب درآید بالا می‌رود و وقتی
درست از آب درنیاید پایین می‌آید. [نحوهٔ یادگیری آن](learning.md) سازوکار را
توضیح می‌دهد؛ `/progress` مدرک را نشان می‌دهد.

**قبل از عمل می‌پرسد، و همه‌چیز برگشت‌پذیر است.** خواندن بی‌صدا انجام می‌شود.
نوشتن می‌پرسد. اجرای یک فرمان بلندتر می‌پرسد. هر نوشتن یک نقطهٔ بازگشت دارد و
`/undo` آخرین آن را برمی‌گرداند. [ایمنی و مجوزها](safety.md).

**فقط یک وابستگی.** کلاینت HTTP، خوانندهٔ SSE، وب‌سوکت مرورگر، رمزگذار PNG برای
تصاویر صفحه — همه بخشی از خود بسته‌اند. نصب کامودور `rich` را می‌کشد و هیچ
چیز دیگری را.

**می‌تواند از یک مرورگر واقعی و یک میزکار واقعی استفاده کند.** یک دریافت‌کنندهٔ
متن نیست: مرورگری که جاوااسکریپت را اجرا می‌کند و کوکی‌ها را نگه می‌دارد، و —
در ویندوز — موس و کیبورد، با هاله‌ای روی صفحه که نشان می‌دهد کجا قرار است
کلیک کند. [مرورگر](browser.md)، [صفحهٔ نمایش](computer.md).
