# انتخاب یک مدل

کامودور با هر چیزی کار می‌کند که با API های OpenAI یا Anthropic حرف بزند —
هفده ارائه‌دهنده از جعبه بیرون می‌آید، به علاوه هر چیز دیگری که یک URL داشته
باشد.

---

## پاسخ کوتاه

| می‌خواهید که | انتخاب |
|---|---|
| آسان‌ترین شروع، یک کلید، همه‌چیز | **OpenRouter** |
| قوی‌ترین کار عامل‌محور | **Anthropic**، `claude-sonnet-5` |
| هیچ پرداختی نکنید و آفلاین بمانید | **Ollama** یا **LM Studio** |
| خیلی ارزان، خوب در کد | **DeepSeek** |
| خیلی سریع | **Groq** یا **Cerebras** |

```bash
comodor setup        # یکی را انتخاب کن، فقط یک بار
```

---

## هر ارائه‌دهنده

**میزبانی‌شده، یک کلید:** OpenRouter · Anthropic · OpenAI · Google Gemini ·
DeepSeek · xAI · Mistral · Groq · Cerebras · Moonshot (Kimi) · Z.AI (GLM) ·
Qwen · Together · Fireworks · Xiaomi MiMo

**روی دستگاه شما، بدون کلید:** Ollama · LM Studio

**هر چیز دیگری:** گزینهٔ *Something else* را انتخاب کنید و یک base URL بدهید.
هر endpoint سازگار با OpenAI کار می‌کند.

---

## اجرای محلی، به قیمت صفر

```bash
ollama pull qwen2.5-coder:14b
comodor setup           # Ollama را انتخاب کن
```

بدون کلید، بدون هزینه، بدون شبکه. یک مدل کدنویس ۱۴B واقعاً برای کارهای روزمره
قابل استفاده است؛ فرق در وظایف طولانی چندمرحله‌ای نشان می‌دهد.

## جابه‌جایی

```bash
comodor --model claude-haiku-4-5      # فقط همین اجرا
```

```
/model                  # فهرست آنچه ارائه‌دهنده دارد
/model gpt-4o           # با نام
/provider               # یک ارائه‌دهندهٔ کاملاً دیگر
```

عقربهٔ زمینه دنبال مدل می‌رود. رفتن از یک مدل میلیون‌توکنی به یک مدل ۱۲۸ هزار
توکنی سقف را همان لحظه عوض می‌کند — که اهمیت دارد، چون عامل گفت‌وگو را در یک
کسری از آن فشرده می‌کند، و یک سقف کهنه یعنی هرگز فشرده نمی‌کند و بعد در سقف
واقعی ارائه‌دهنده گیر می‌کند.

برای دائمی کردن جابه‌جایی: `/save`، یا ویرایش
`~/.comodor/config.json`.

---

## کلیدها

هر کدام از این دو جا درست است، و هیچ‌کدام به آن یکی کپی نمی‌شود:

```json
{ "providers": { "anthropic": { "api_key": "sk-ant-…" } } }
```

```bash
export ANTHROPIC_API_KEY=sk-ant-…
```

کلیدی که در محیط شما باشد **همان‌جا می‌ماند** — `/save` آن را روی دیسک
نمی‌نویسد. Export کردن به جای ذخیره کردن یک تصمیم است، و به آن احترام
می‌گذارند.

فایل پیکربندی خود کامودور با مجوزهای فقط‌مالک نوشته می‌شود، و کلید شما هرگز در
یک لاگ، یک transcript، یک خروجی یا یک traceback ظاهر نمی‌شود.
[ایمنی](safety.md#your-keys).

## دروازه

به جای ثابت کردن یک ارائه‌دهنده، میان چندتا مسیر بدهید.

```
/gw                    # یا F5
```

```json
{
  "gateway": {
    "enabled": true,
    "policy": "quality",
    "chain": ["anthropic", "openrouter", "deepseek"],
    "failure_threshold": 3
  }
}
```

`policy` یکی از `cost`، `speed` یا `quality` است. ارائه‌دهنده‌ای که سه بار پیاپی
شکست بخورد، یک دقیقه از کنارش رد می‌شوند. خط وضعیت وقتی روشن است `GW: Quality`
را نشان می‌دهد و وقتی خاموش است `GW: Disable`.

## بینایی

بعضی ابزارها عکس برمی‌گردانند — `browse look`، و تک‌تک اسکرین‌شات‌های `computer`.
آن‌ها به مدلی نیاز دارند که بتواند ببیند. همهٔ خانوادهٔ فعلی Claude و GPT-4o
می‌توانند؛ بیشتر مدل‌های باز نمی‌توانند.

اگر قصد دارید از [صفحهٔ نمایش](computer.md) استفاده کنید، اول چک کنید مدل چشم
دارد، وگرنه به او عکسی داده می‌شود که نمی‌تواند بخواند و حدس خواهد زد.

## چه هزینه‌ای دارد


[هزینه](cost.md) نگاه کنید.
