# از مرورگر

همان ایجنت، در یک زبانه‌ی مرورگر. روی همین ماشین، یا روی سروری که با SSH به آن
می‌رسید.

```bash
comodor web
```

```

  / ____/___  ____ ___  ____  ____/ /___  _____
 / /   / __ \/ __ `__ \/ __ \/ __  / __ \/ ___/
/ /___/ /_/ / / / / / / /_/ / /_/ / /_/ / /
\____/\____/_/ /_/ /_/\____/\__,_/\____/_/

  it learns the way you correct it   0.9.0  ·  claude-sonnet-5

  Comodor is at  http://127.0.0.1:8765/?token=EYhO9St_VTy95k4gHtJytb
  Working in     /home/you/projects/api-server

  Only this machine can reach it. Ctrl-C to stop.
```

پیوند را باز کنید. توکن درون آن است.

---

## گزینه‌ها

```bash
comodor web --port 9000
comodor web --no-browser            # do not open one for me
comodor web --token mytoken         # a fixed token
comodor web --host 0.0.0.0          # reachable from elsewhere — read below
```

---

## توکن

در هر اجرا یکی تازه، پس URL دیروز راه ورود به امروز نیست. درون URL می‌آید، با
یک کوکی مبادله می‌شود، و هر درخواستِ پس از آن توسط کوکی مجاز شمرده می‌شود.

برای پایدار ماندنش در میان ری‌استارت‌ها:

```bash
export COMODOR_WEB_TOKEN=something-long-and-random
```

هر کسی که توکن را داشته باشد، یک پوسته روی آن ماشین دارد. با آن همان‌طور رفتار
کنید.

---

## بایند به بیش از loopback

`--host 0.0.0.0` رابط را روی تک‌تک رابط‌های ماشین قرار می‌دهد. **این پورت یک
پوسته است.** Comodor همین را می‌گوید، به‌جای آنکه فرض کند قصداً این را خواسته‌اید:

```
  Listening on every address on this machine.
  Anyone who can reach this port can run commands as you.
```

بهتر، وقتی ایجنت روی یک سرور است: بگذارید روی loopback بماند و تونل بزنید.

```bash
ssh -N -L 8765:127.0.0.1:8765 you@server
```

سپس به‌صورت محلی `http://127.0.0.1:8765` را باز کنید. پورت هرگز افشا نمی‌شود و
SSH احراز هویت را انجام می‌دهد.

## دیدن کارکردش با یک صفحه‌نمایش

اگر ایجنت یک دسکتاپ را می‌راند، فریمی که دیده در رابط ظاهر می‌شود، با نشانه‌ای
در جایی که عمل کرده:

```
┌────────────────────────────────────────────┐
│                                            │
│   [ the screen the model saw ]      ✛      │
│                                            │
│   clicking Save                            │
└────────────────────────────────────────────┘
```

نقش اصلی همین است. پوششِ روی صفحه روی ماشینی ترسیم می‌شود که در حال رانده‌شدن
است، که وقتی آن ماشین یک سرور یا کانتینر است به هیچ کار نمی‌آید — پنل، راه تماشا
از جای دیگر است.

تصویر برای هر فریم یک بار از `/api/screen` گرفته می‌شود، نه اینکه در جریان
رویداد حمل شود: یک اسکرین‌شات حدود یک مگابایت است، و مرورگری که گزارش رویداد را
دوباره می‌خواند، باید تک‌تک فریم‌هایی را که تاکنون دیده بود دانلود می‌کرد.

[استفاده از صفحه‌نمایش شما](computer.md).

## آنچه انجام نمی‌دهد

**شروع بدون ارائه‌دهنده.** می‌تواند میان ارائه‌دهنده‌هایی که از پیش راه‌اندازی
شده‌اند جابه‌جا شود، اما جایی درونش برای تایپ کلید نیست، و زبانه‌ی مرورگری جای
خوبی برای آن نیست. به‌جای آنکه URL‌ای سرو کند که در نخستین کار شکست می‌خورد،
می‌گوید چه چیزی کم است و می‌ایستد:

```
Comodor has no provider configured, and the browser interface has no way to
add one.

  In Docker, pass a key in as an environment variable:
    -e ANTHROPIC_API_KEY=...    -e OPENAI_API_KEY=...
  or mount a config file at ~/.comodor/config.json.
  Anywhere with a terminal, `comodor setup` asks a few questions.
```

در ترمینال به‌جایش پرسش‌های راه‌اندازی را می‌پرسد. در کانتینر همیشه پیام را چاپ
می‌کند — کانتینر یک ترمینال دارد، چه کسی به آن وصل باشد چه نباشد، و کانتینری
detached در غیر این صورت تا ابد منتظر پرسشی می‌ماند که کسی نمی‌تواند به آن پاسخ
دهد.

**گسترش آنچه ایجنت مجاز است لمس کند.** تأیید خودکار برای نوشتن‌ها و فرمان‌ها در
Admin نشان داده می‌شود و آنجا قابل تغییر نیست. پیام‌های اجازه از پیش به‌صورت
عمل‌به‌عمل همان انتخاب را پیش روی کسی می‌گذارند که باید با آن زندگی کند؛ صفحه‌ای
که هر دارنده‌ی پیوند می‌تواند به آن برسد، جای درستی برای تبدیل کردن آن به سیاست
دائمی نیست. آن را جایی تغییر دهید که Comodor اجرا شده — به
[ایمنی](safety.md) ببینید.

## آنچه روی صفحه است

**گفتگو**، در حال جریان همان‌طور که می‌رسد، با کدهای محصورشده‌ی محفوظ به‌صورت
کد، و هر فراخوانی ابزار به‌صورت ردیفی که می‌توانید بازش کنید و ببینید واقعاً چه
کرد.

**فهرست چت‌ها**، سمت چپ. هر گفتگو در `~/.comodor/sessions` نوشته می‌شود — همان
پوشه‌ای که ترمینال استفاده می‌کند، پس چتی که در پرامپت آغاز شده در مرورگر بازشدنی
است و برعکس. جست‌وجو درونشان را می‌کاود، نه فقط عنوان‌هایشان را.

**Admin**، زبانه‌ی دوم، که پاسخِ «این چیز قرار است با ماشین من چه کند» است:

| | |
|---|---|
| مدل | کدام ارائه‌دهنده و مدل پاسخ می‌دهد، و جابه‌جایی میان آن‌هایی که برایشان کلید دارید |
| چگونه اجرا می‌شود | حالت، اینکه آیا خودش به راه ادامه می‌دهد، و چهار سقف — زمینه، گام‌ها، زمان، خرج |
| مجوزها | چه کاری را بدون پرسیدن می‌کند، چه چیزی درباره‌اش می‌پرسد، و چه چیزی در این جلسه اعطا شده |
| چه آموخته | قواعد، درس‌ها، مهارت‌ها، کارها، و چند تای‌شان موفق شد |
| ابزارها | هر ابزاری که به آن می‌رسد، کدگذاری‌شده با رنگ بر اساس خطر، به‌علاوه‌ی مهارت‌های شما و هر سرور MCP |
| این ماشین | نسخه، Python، و اینکه تنظیمات، چت‌ها و مغز کجا زندگی می‌کنند |

**نوار وضعیت** در امتداد پایین: آیا صفحه وصل است، پوشه‌ی کاری، چقدر زمینه پر
است، این جلسه چه هزینه‌ای داشته، و چند قاعده‌ی آموخته‌شده در جریان است.

**پنل صفحه‌نمایش**، وقتی ایجنت در حال راندن یکی است — آخرین فریمی که دیده، با
نشانه‌ای در جایی که در شرف کلیک است. به [استفاده از صفحه‌نمایش
شما](computer.md) ببینید.

## صفحه‌کلید

| | |
|---|---|
| `Enter` | ارسال |
| `Shift`+`Enter` | خط جدید |
| `Esc` | توقف کار جاری، یا بستن نوار کنار |
| `Ctrl`/`⌘`+`K` | جست‌وجوی چت‌ها |
| `Ctrl`/`⌘`+`B` | نمایش یا پنهان کردن نوار کنار |
| `/` | پرش به جعبه‌ی پیام |

## روی گوشی

همان صفحه. زیر ۹۰۰ پیکسل فهرست چت‌ها به یک کشو روی گفتگو تبدیل می‌شود، نه ستونی
کنار آن، چون ۲۹۲ پیکسل نوار کنار روی صفحه‌ای ۳۹۰ پیکسلی، هیچ جایی به اندازه‌ی
کافی برای خواندن کد باقی نمی‌گذارد. بیرونش را بزنید، `Esc` را بفشارید، یا از
دکمه‌ی بستن برای جمع کردنش استفاده کنید.

از گوشی‌تان به آن برسید، همان‌گونه که به هر چیز دیگری روی ماشین‌تان می‌رسید —
یک تونل SSH، نه بایند عمومی. [بایند به بیش از
loopback](#binding-to-more-than-loopback) توضیح می‌دهد چرا.

## نوشتن به هر زبانی

به فارسی، عربی یا عبری تایپ کنید و جعبه‌ی پیام همان‌طور که تایپ می‌کنید جهتش
عوض می‌شود؛ پاسخ‌ها به آن زبان‌ها وقتی می‌رسند راست‌به‌چپ چیده می‌شوند. هیچ چیز
پیکربندی نمی‌شود و تنظیمی برای زبان نیست: هر پیام به تنهایی قضاوت می‌شود، پس
گفتگویی که میان زبان‌ها در حرکت است، با آن حرکت می‌کند.

قضاوت با شمردن است، نه با حرف نخست — چیزی که دو حالت دشوار را درست درمی‌آورد:
جمله‌ی فارسی‌ای که با نام یک بسته آغاز می‌شود همچنان فارسی است، و جمله‌ی انگلیسی‌ای
که یک واژه‌ی فارسی را نقل می‌کند همچنان انگلیسی. کدها، مسیرها و URL‌ها درون
پاراگراف راست‌به‌چپ، چپ‌به‌راست چیده می‌شوند، همان‌جا که به آن‌ها تعلق دارند.

متنِ با خط عربی با فونت Vazirmatn چیده می‌شود، که درون خود بسته سفر می‌کند،
نه اینکه از یک میزبان فونت گرفته شود: این باید روی ماشینی کار کند که به اینترنت
نمی‌رسد. به کاراکترهای با خط عربی اعمال می‌شود و به هیچ چیز دیگر، پس خطی که
فارسی را با یک شناسه‌ی انگلیسی می‌آمیزد، برای هر یک چهره‌ی درستش را می‌گیرد.
