# آمده از عامل دیگری

اگر از قبل از **OpenClaw** یا **Hermes** استفاده می‌کنید، کامودور بار اول که
اجرایش می‌کنید پیشنهاد می‌دهد تنظیمات شما را بیاورد.

کلیدهای API تان را از قبل پیدا کرده‌اید و جای شما pasted کرده‌اید. دوباره
انجام دادنش اولین برداشت بدی است.

---

## در اولین اجرا

```
 1/7  You already use OpenClaw
  OpenClaw  1 API key, the model (claude-sonnet-5), 1 skill
  /home/you/.openclaw

  Nothing is moved and nothing already set here is replaced.
  Keys are copied into your config; the other tool keeps working.

  1.  bring it over   keys, model and skills
  2.  keys only       leave the skills and the model
  3.  start fresh     import nothing
```

این پرسش فقط وقتی ظاهر می‌شود که چیزی برای وارد کردن باشد.

---

## بعدش

یکی از آن‌ها را بعداً نصب کرده‌اید، یا «start fresh» را جواب داده‌اید و نظرتان
عوض شده:

```bash
comodor import              # بیاوردش
comodor import --dry-run    # بگو چه می‌خواهی برداری، هیچ چیز را عوض نکن
comodor import --keys-only  # مهارت‌ها و مدل را رها کن
```

دو بار اجرا کردنش امن است — بار دوم می‌گوید چیزی جدید نیست.

---

## چه چیزی می‌آید

| | |
|---|---|
| **کلیدهای API** | تمام آن ملالت. از `.env` آن‌ها، و از JSON درون‌خطی OpenClaw |
| **مدل** | اگر کامودور بتواند میزبانی‌اش کند |
| **مهارت‌ها** | هر دو ابزار یک فرمت باز مکتوب را می‌نویسند، پس این‌ها فایل‌هایی برای کپی کردن‌اند |

سه قاعده در کل مسیر، چون این فایل‌های یک برنامهٔ دیگر را می‌خواند:

- **هیچ چیزی بازنویسی نمی‌شود.** کلیدی که از قبل اینجا پیکربندی شده برنده است؛
  وارد کردن، فقط شکاف‌ها را پر می‌کند.
- **هیچ چیزی جابه‌جا نمی‌شود.** هر خواندن، فقط یک خواندن است. ابزار دیگر دقیقاً
  مثل قبل کار می‌کند.
- **یک فایل ناقص رد می‌شود، نه مرگ‌آور است.** نیمی از ارزش این است که روی
  ماشینی اجرا می‌شود که عامل دیگرش در وضعیتی عجیب است.

---

## چه چیزی نمی‌آید، و چرا

**حافظهٔ آن‌ها.** بلند و آشکار گفته می‌شود، نه در سکوت رد:

```
not imported: MEMORY.md — its memory is prose; this agent's is lessons with
confidence and evidence, and inventing those would poison recall
```

مغز کامودور درس‌هایی با یک اطمینان، یک مدرک، و یک محوشدن است که از اصلاح‌ها
یاد گرفته شده. یک `MEMORY.md` متن نثر است. وارد کردن یکی به جای دیگری، اطمینان‌هایی
می‌سازد که هیچ‌کس اندازه نگرفته و recall را با مدخل‌هایی پر می‌کند که هرگز
استحقاقشان اندازه‌گیری نشده. عاملی بدتر می‌گیرید که شبیه عاملی بهتر-مطلع است.

**شخصیت‌ها، پیام‌رسانی، متن‌به‌گفتار.** کامودور معادلی برای هیچ‌کدام ندارد، و
تنظیمی که وارد هیچ‌چیز شود بدتر از بی‌تنظیمی است.

**کلیدی که جای دیگری ذخیره شده.** OpenClaw اجازه می‌دهد یک کلید، ارجاعی به یک
فایل یا یک فرمان باشد. آن‌ها روی ماشینی که برایش نوشته شده‌اند معنا دارند و اینجا
هیچ، پس گزارش می‌شوند به جای اینکه حدس زده شوند.

---

## مهارت‌ها، و یک نکته که ارزش دانستن دارد

مهارت‌های وارد‌شده نام‌فضادار می‌شوند — `review` می‌شود `openclaw-review` — پس
یک وارد کردن هرگز آرام و بی‌سروصدا یکی از مهارت‌های خودتان را جایگزین نمی‌کند.

یک پوشهٔ مهارت فایل‌به‌فایل کپی می‌شود، و **پوشه‌ای که درون خودش لینک به بیرون
داشته باشد رد می‌شود**. یک مهارت فایلی است که محتوایش به درون یک پرامپت خوانده
می‌شود، پس وگرنه یک symlink به `~/.ssh/id_rsa` که در پوشهٔ مهارت‌های برنامهٔ
دیگری نشسته باشد، کپی می‌شد و به یک مدل فرستاده می‌شد. رد می‌شود، و نام برده
می‌شود:

```
not imported: the skill sneaky — it contains a link out of that folder
```

---

## کجاها را نگاه می‌کند

| | |
|---|---|
| OpenClaw | `~/.openclaw`، `~/.clawdbot`، `~/.moltbot` |
| Hermes | `~/.hermes` |

پوشه‌های قدیمی‌تر OpenClaw هنوز روی ماشین‌های واقعی‌اند — دو بار تغییر نام داده
بود — پس هر سه بررسی می‌شوند.

برای اینکه اصلاً نگاه نکند:

```bash
export COMODOR_NO_IMPORT=1
```
