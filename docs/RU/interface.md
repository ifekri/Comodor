# Интерфейс

Что вы видите, что нажимаете и все 29 команд.

```bash
comodor          # запустить
comodor --demo   # весь интерфейс, офлайн, без ключа
```

---

## Раскладка

```
┌────────────────────────────────────────────────────────────────────────┐
│  Comodor                              Anthropic · claude-sonnet-5      │
│  ────────────────────────────────────────────────────────────────────  │
│                                                                        │
│  TASKS                    > fix the failing parser test                │
│  ● read the test          ▸ read_file  tests/test_parser.py     0.1s   │
│  ◐ find the cause         ▸ run_shell  pytest tests/test_pa…    2.3s   │
│  ○ fix it                                                              │
│                           The test expects `parse("")` to raise, but…  │
│                                                                        │
│  ────────────────────────────────────────────────────────────────────  │
│  ▌Type a task, or / for commands                                       │
│                                                                        │
│  act · loop on · 12% of 1M · $0.03      ⏎ send  ^O attach  F3 mode     │
└────────────────────────────────────────────────────────────────────────┘
```

**Боковая панель** — это план, когда он есть. `F2` её скрывает — стоит сделать
на узком терминале.

**Строка состояния** показывает режим, идёт ли итерация, насколько заполнен
контекст и сколько стоила эта сессия. Цифра контекста настоящая: она следует
за моделью, поэтому переход с модели на миллион токенов на модель на 128k
меняет её мгновенно.

Работает примерно от 60 колонок и выше. Ниже боковая панель убирается сама.
`comodor preview 80x24` отрисовывает интерфейс любого размера, не запуская
сессию.

## Режимы

| Режим | Что агенту разрешено | |
|---|---|---|
| **act** | Всё, с запросом подтверждения перед записями и командами | по умолчанию |
| **plan** | Только чтение. Никаких записей, команд, сети | для «что бы ты сделал?» |
| **chat** | Вообще без инструментов | для вопроса о вставленном коде |

`F3` переключает их по кругу. `/mode plan` задаёт режим напрямую.

Режим plan действительно доступен только для чтения — это обеспечивается на
уровне разрешений, а не вежливой просьбой к модели. Инструмент с риском выше
«safe» отклоняется до запуска.

## Клавиши

| | |
|---|---|
| `Enter` | отправить |
| `Ctrl+J` | перевод строки внутри сообщения |
| `Esc` | остановить то, что он делает |
| `Ctrl+C` | остановить; дважды — выйти |
| `F1` | помощь |
| `F2` | боковая панель |
| `F3` | режим |
| `F4` | loop вкл/выкл |
| `F5` | шлюз |
| `Ctrl+O` | прикрепить файл |
| `Ctrl+L` | очистить разговор |
| `PgUp` `PgDn` | прокрутка |

Про `!` стоит помнить. `!git status` выполняет её и показывает вам вывод;
модель вопрос никогда не видит. Дешевле и быстрее, чем спрашивать.

## Команды

Введите `/` — и список фильтруется по мере ввода.

### Попросить его изменить то, что он делает

| | |
|---|---|
| `/mode [act\|plan\|chat]` | что ему разрешено делать |
| `/loop` | работать до завершения или ответить один раз |
| `/model [id]` | выбрать модель — список или назвать |
| `/provider [name]` | выбрать провайдера |
| `/gw` | шлюз: маршрутизация между провайдерами по цене, скорости или качеству |

### Обучить его

| | |
|---|---|
| `/good` | тот ответ был правильным |
| `/bad` | тот ответ был неверным |
| `/teach <text>` | запомнить это |
| `/memory` | чему он научился |
| `/rules` | доменные правила, извлечённые из вашего кода и ваших правок |
| `/progress` | доказательства того, что он улучшается |
| `/skills` | процедуры, которым он следует, когда работа совпадает |

`/good` и `/bad` — самое дешёвое, что вы можете для него сделать. См.
[Как он учится](learning.md).

### Отменить и оглянуться назад

| | |
|---|---|
| `/undo` | восстановить последний изменённый им файл |
| `/clear` | начать новый разговор |
| `/resume [id]` | открыть прежнюю сессию заново |
| `/search <text>` | найти что-то в прежнем разговоре |
| `/export [path]` | записать эту сессию в файл |

### Расширить его возможности

| | |
|---|---|
| `/computer [15m\|1h this app\|stop]` | дать ему пользоваться вашим экраном — [руководство](computer.md) |
| `/mcp` | серверы MCP и их инструменты — [руководство](mcp.md) |
| `/attach <path>` | добавить файл к следующему сообщению |

### Настроить его

| | |
|---|---|
| `/settings` | что настроено прямо сейчас |
| `/approve [writes\|shell\|all]` | больше не спрашивать перед этим |
| `/theme [name]` | ember, midnight, matrix, mono |
| `/save` | записать текущие настройки в ваш файл конфигурации |
| `/cost` | токены, расходы и что сэкономил кэш |
| `/copy [all\|task]` | последний ответ или всё — в буфер обмена |
| `/mouse [on\|off]` | отслеживание мыши, чтобы вы сами могли выделять текст |
| `/help` | всё это — внутри интерфейса |
| `/quit` | выйти |

**`/save` записывает только то, что вы выбрали.** Не настройки репозитория, не
ключ, который вы храните в окружении, не `--model`, переданный на один запуск.
См. [Конфигурация](configuration.md#what-save-writes).

## Подтверждения

Когда агент хочет записать файл или выполнить команду:

```
  Write  src/parser.py
  ────────────────────────────────────────────
   - def parse(text):
   -     return text.split(",")
   + def parse(text):
   +     if not text:
   +         raise ValueError("nothing to parse")
   +     return text.split(",")

  [a] allow   [A] allow always this session   [d] deny
```

`A` запоминается на сессию по каждому типу действий — разрешение записей не
разрешает команды.

Отказ не пропадает зря. Отказ — самый ясный сигнал предпочтения, который
интерфейс вообще собирает, и он попадает в механизм обучения: агент с меньшей
вероятностью предложит это снова.

Чтобы вообще перестать получать вопросы:

```
/approve writes      файлы — да; команды — всё ещё спрашивать
/approve all         всё
```

Всё по-прежнему фиксируется контрольными точками. `/undo` работает в любом
случае.

## Копирование текста наружу

Пока мышь отслеживается, перетаскивание принадлежит Comodor, и терминал его
никогда не видит — так что привычное «выделить и скопировать» не работает.
Три способа обойти это:

```
/copy              последний ответ
/copy all          весь разговор
/copy task         последнее, о чём вы просили
/mouse             отслеживание мыши выключено, выделение работает как обычно
```

`/copy` не требует ничего установленного на Windows или macOS. На Linux он
использует `wl-copy`, `xclip` или `xsel` — что найдётся, — и говорит, чего
не хватает, если нет ничего.

По SSH он переходит к escape-последовательности, которая просит *ваш* терминал
установить *ваш* буфер обмена, — так что текст от агента на сервере попадает
туда, куда вы можете его вставить, а не на сервер, у которого буфера обмена нет.

Большинство терминалов также позволяют выделять текст с зажатым **Shift** —
это обходит отслеживание мыши, не выключая его.

## Кто говорит

Каждая реплика лежит на спокойной полосе — одного оттенка позади того, что
ввели вы, другого позади ответа:

```
▌ › why does the parser drop the last field?              ← warm

▌   Because split is called with a maxsplit of 2 …        ← neutral
▌
▌   ┌─ python ────────────────────────┐
▌   │ return text.split(',', 2)       │
▌   └─────────────────────────────────┘
```

Это приглушено намеренно. Полосы лежат под основным текстом, который вы читаете
минутами подряд, а фон с собственным характером конкурирует со словами.
У каждой темы своя пара оттенков, на несколько процентов отличающихся от её
фона; у `mono` их нет, потому что тема, чья суть — отсутствие цвета, не хочет
и двух.

Они не занимают вертикального пространства — границей служит само изменение
цвета.

## Текст справа налево

Персидский, арабский и иврит выводятся справа, где начинаются их строки, со
стеком шрифтов, который им подходит. Смешанные абзацы — английский идентификатор
внутри персидского предложения — обрабатываются построчно, а не пофайлово, что
и происходит на самом деле в техническом разговоре.

## Темы

```
/theme midnight
```

`ember` (по умолчанию, тёплый янтарный), `midnight` (холодный синий), `matrix`
(зелёный), `mono` (без цвета вовсе).

`--ascii` заменяет символы псевдографики на ASCII — для терминалов без них.
`NO_COLOR` в вашем окружении учитывается.
