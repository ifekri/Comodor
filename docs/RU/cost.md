## Кэширование промпта — большая часть экономии

Каждый запрос заново отправляет неизменяемые части — системный промпт, схемы
инструментов, разговор на текущий момент. Провайдеры повторно отдают
байт-идентичный префикс примерно за десятую часть цены.

Comodor построен вокруг этого, и оно включено по умолчанию:

```json
{ "agent": { "prompt_cache": true, "prompt_cache_ttl": "5m" } }
```

Измерено на реальных сессиях: **86% входных токенов отданы из кэша**.

### Почему в системном промпте нет ничего динамического

Кэширование работает только на префиксе, байт-в-байт совпадающем с прошлым разом.
Системный промпт *и есть* этот префикс. Всё, что меняется от хода к ходу, —
вспомненные уроки, совпавший навык, время суток, — делает его недействительным,
и вы платите полную цену за всё, каждый ход.

Поэтому вспомненные уроки едут на *ходе*, как часть сообщения пользователя. Одно
это изменение подняло измеренную долю попаданий в кэш с 72% до 87%.

Если добавляете собственные постоянные инструкции, кладите их в
`agent.system_prompt_extra` — он стабилен, — а не варьируйте их.

### Часовой кэш

```json
{ "agent": { "prompt_cache_ttl": "1h" } }
```

Запись *стоит* примерно на 25% дороже и хранится час вместо пяти минут. Стоит,
если возвращаетесь к сессии многократно; расточительно для одного всплеска
работы.

## Потолки

```json
{
  "agent": {
    "max_steps": 0,
    "max_seconds": 3600,
    "max_cost_usd": 2.0
  }
}
```

Что наступит раньше, то и останавливает задачу, а `0` означает отсутствие лимита.
`stopped` в `--json` говорит, какой именно сработал.

**Лимита шагов по умолчанию нет.** Двадцать четыре шага — ничто на настоящей
кодовой базе: рефакторинг на дюжине файлов упёрся в них на полуслове, — а число
шагов никак не связано с вредом: десять шагов на чтение файлов почти ничего не
стоят. Потолки, соответствующие вреду, — это время и деньги, и они остаются
включёнными. Задайте `max_steps` число, если хотите вернуть жёсткую остановку.

Когда один из них всё же останавливает задачу, сообщение говорит, как его
пройти, и «continue» продолжит с того места.

### Когда лимит не может сработать

**Лимит расходов работает только для модели с опубликованным тарифом.**

Таблица цен намеренно оставляет тарифы незаданными для моделей, в которых она
не уверена, — выдуманная цена даёт неверные числа, что хуже, чем их отсутствие.
Для модели без цены счётчик расходов читает ноль, так что
`spent >= max_cost_usd` никогда не истинно и лимит не срабатывает никогда.

Comodor так и говорит, вместо того чтобы позволить вам верить, что вы защищены:

```
the $2.00 spend limit cannot be enforced for gpt-4o — no published rate is
known, so the cost meter reads zero. The step and time limits still apply.
```

Это говорится в начале сессии и в `comodor doctor`:

```
  warn  spend limit    $2.00 per task cannot be enforced for gpt-4o
                       → No published rate is known for this model, so the
                         cost meter reads zero and the limit never fires.
                         The step and time limits still apply.
```

Для модели, работающей на вашей собственной машине, сказано другое, потому что
там она и так ничего не стоит.

## Что на самом деле стоит денег

**Скриншоты.** Около 1,600 визуальных токенов каждый при бюджете по умолчанию —
и столько же на каждом ходу, пока они остаются в разговоре. Comodor хранит
последние два и заменяет остальные строкой о том, что один там был. Без этого
задача на рабочем столе в тридцать шагов несёт почти пятьдесят тысяч токенов
пикселей, описывающих экраны, по которым давно кликнули.

```json
{ "agent":    { "keep_screenshots": 2 } }
{ "computer": { "screenshot_tokens": 1600 } }
```

Не задавайте `screenshot_tokens` слишком низко. Картинка, которую модель не может
прочитать, хуже, чем никакой: она угадывает вместо того, чтобы спросить. См.
[Использование экрана](computer.md#screenshots-and-what-they-cost).

**Большой вывод инструментов.** Ограничен `agent.max_tool_chars`. То, что не
помещается, записывается в файл, и модели говорят, как его прочитать, так что
платит она, только если посмотрит.

**Рефлексия.** Один вызов модели в конце задачи. Направьте её на модель
подешевле:

```json
{ "learning": { "reflect_model": "claude-haiku-4-5" } }
```

Или выключите её. Бесплатная полоса — исправления, правила, объявления — работает
в любом случае. [Как он учится](learning.md#the-two-lanes).

**Браузер, когда он смотрит.** `browse` по умолчанию возвращает текст и скриншот
только по запросу, потому что картинка страницы стоит одинаково каждый раз и её
нельзя ужать.
