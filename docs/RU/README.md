заканчивается тем, что агент делает что-то полезное.

## Самая короткая версия

```bash
curl -fsSL get.comodor.ai | sh      # macOS, Linux
irm get.comodor.ai | iex           # Windows

comodor                  # задаёт несколько вопросов, один раз
```

Затем напишите, что хотите. Исправляйте его, когда он ошибается — отредактируйте
файл или просто скажите об этом — и он учится. `/progress` показывает, работает
ли это на самом деле.

```bash
comodor run "fix the failing test in tests/test_parser.py"   # одна задача, без интерфейса
comodor web                                                  # из браузера
comodor doctor                                               # всё ли в порядке?
comodor help                                                 # текстовая страница помощи
```

## Чем он отличается

**Он учится на исправлениях, а не на похвале.** Большинство агентов забывают всё в
момент завершения сессии. Comodor наблюдает за тем, что вы меняете в его выводе,
и превращает это в урок с уверенностью, которая растёт, когда урок подтверждается,
и падает, когда нет. [Как он учится](learning.md) объясняет механизм; `/progress`
показывает доказательства.

**Он спрашивает, прежде чем действовать, и всё обратимо.** Чтение проходит молча.
Запись требует подтверждения. Запуск команды требует подтверждения громче. Каждая
запись фиксируется контрольной точкой, а `/undo` возвращает последнюю.
[Безопасность и разрешения](safety.md).

**Одна зависимость.** HTTP-клиент, чтение SSE, WebSocket для браузера, кодировщик
PNG для скриншотов — всё часть пакета. Установка Comodor приносит `rich` и больше
ничего.

**Он может использовать настоящий браузер и настоящий рабочий стол.** Не
текстовый загрузчик: браузер, который исполняет JavaScript и хранит cookie, а —
на Windows — мышь и клавиатуру, с ореолом на экране, показывающим, куда он
собирается нажать. [Браузер](browser.md), [экран](computer.md).
