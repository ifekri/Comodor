# Как он учится

Большинство агентов забывают в момент, когда сессия заканчивается. Этот
наблюдает, что вы меняете в его результате, и сохраняет это.

---

## Идея

Похвала дёшева, а поправки дороги, поэтому учится он именно на поправках.

Когда вы правите написанный им файл или прямо говорите ему, что он был неправ,
это становится **уроком**: коротким правилом с уверенностью, которая растёт
каждый раз, когда оно подтверждается, и убывает, когда не используется. Уроки
вспоминаются, когда ситуация выглядит похоже, и вводятся в тот ход — никогда в
системный промпт, что стоило бы кэша промпта.

Ничего не покидает вашу машину. Мозг — это SQLite-файл под каталогом вашей
конфигурации.

---

## Две полосы

### Рефлекс — бесплатно, мгновенно, всегда включён

Ни вызова модели, ни токенов, ни задержки.

- **Поправки.** Вы меняете `"` на `'` в файле, который он написал. Это diff,
  а diff — факт.
- **Правила.** Он разово читает ваш существующий код в начале и выводит из него
  соглашения — отступы, стиль кавычек, как называются тесты.
- **Объявления.** Когда правило применяется, он об этом говорит, одной строкой.
  Правило, которое вы не видите, — правило, которое вы не можете поправить.
- **Предзагрузка.** Вспоминание начинается, пока вы ещё печатаете.

Эта полоса работает, даже когда рефлексия выключена, потому что ничего не стоит.

### Рефлексия — вызов модели, после задачи

В конце задачи он смотрит, что произошло, и записывает то, что должен помнить.
Эта стоит вызова. Используйте подешевле модель, если хотите:

```json
{ "learning": { "reflect_model": "claude-haiku-4-5" } }
```

Или выключите её, оставив Рефлекс:

```json
{ "learning": { "reflect": false } }
```

---

## Научить его, намеренно

| | |
|---|---|
| `/good` | тот ответ был верен |
| `/bad` | тот ответ был неверен |
| `/teach we use pytest, never unittest` | запомнить это |

`/good` и `/bad` стоят одного нажатия клавиши и являются самым дешёвым, что вы
можете для него сделать.

Отказ в запросе разрешения тоже учит его. Отказ — самый ясный сигнал
предпочтения, который собирает интерфейс, и он трактуется как таковой.

## Увидеть, что он знает

```
/memory
```

Ищущийся список — каждый урок с тем, что его запускает, что он говорит, его
видом и его текущей уверенностью:

```

│ ›  #41 writing Python strings                                      │
│      Use single quotes for string literals.  [style 91%]           │
│    #38 adding a test                                               │
│      Tests go in tests/, mirroring the src layout.  [layout 84%]   │
│    #29 adding a dependency                                         │
│      Ask before adding one; this project has exactly one.  [78%]   │
│    #12 parsing empty input                                         │
│      Raise, do not return an empty list.  [behaviour 62%]          │
└────────────────────────────────────────────────────────────────────┘
  ↑↓ move   enter open   type filter   esc close
```

`/memory <text>` ищет. Открытие одного позволяет закрепить его, чтобы он
перестал убывать, или удалить его, если он был неверен.

```
/rules
```

Домашние правила, которые он вывел из вашего кода, а не из того, что вы ему
сказали.

## Вспоминание, и почему его нет в системном промпте

Вспомненные уроки едут на ходе, как часть сообщения пользователя, а не в
системном промпте.

Это решение о стоимости. Кэширование промпта работает только на
байт-идентичном префиксе, а системный промпт — это префикс. Поместить туда
что-либо зависящее от запроса — инвалидировать кэш на каждом отдельно взятом
ходе. Перенос вспоминания на ход поднял измеренный уровень попаданий кэша с
72% до 87%. См. [Стоимость](cost.md).

## Слова, которым он учится у вас

Он также учится, какие из *ваших* слов ходят вместе, из ваших же завершённых
задач — что «парсер» и «токенизировать» принадлежат одному углу вашей кодовой
базы. Это не стоит ни токенов, ни вызова модели; это подсчёт.

Именно это позволяет уроку, записанному о «токенизаторе», всплыть, когда вы
спрашиваете о «лексере».

```json
{ "learning": { "associative": true } }
```

---

## Область

```json
{ "learning": { "share_scope": "project" } }
```

`project` держит уроки в репозитории, где они выучены, — верное умолчание,
поскольку соглашение в одной кодовой базе неверно в другой. `global` делится
ими везде.

---

## Забывание

Урок, который не используется, убывает. `half_life_days` (45 по умолчанию)
задаёт, как быстро, а `min_confidence` (0.15) — пол, ниже которого он перестаёт
вспоминаться.

Это важно: кодовая база меняет мнение, и агент, держащий двухлетнее соглашение
с полной уверенностью, хуже того, который забыл.

---

## Выключение

```json
{ "learning": { "enabled": false } }
```

Всё продолжает работать. Он просто начинает каждую сессию незнакомцем.

## Где он живёт
