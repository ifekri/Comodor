# Использование вашего экрана

Comodor может управлять машиной так, как это делает человек — смотреть на экран,
двигать мышь, кликать и печатать — в любом приложении, не только в браузере.

Это самое мощное из того, что он умеет, и самое опасное. Прочитайте
[модель разрешений](#permission), прежде чем включать его.

> **Пока только Windows.** Бэкенды для macOS и Linux не написаны. На этих
> платформах инструмент не предлагается вовсе, а не предлагается и не работает —
> см. [Почему его нет](#why-it-is-not-there).

---

## Как это выглядит

Вы наблюдаете за происходящим. Прежде чем указатель сдвинется, в месте будущего
клика появляется ореол:

```
   ┌─────────────────────────────────────────┐
   │   Comodor · 14m 32s left, anywhere      │   ← панель, сверху по центру
   │   move the mouse to a corner to stop    │
   └─────────────────────────────────────────┘


               ╭──────────╮
               │   Save   │      ◎  ← ореол, рисуется до движения
               ╰──────────╯
                               clicking (842, 517)
```

Затем указатель перемещается туда примерно за треть секунды, а не телепортируется,
и рябью отмечается место, куда пришёлся клик.

**Пауза — не украшение.** Это момент, в который вы ещё можете его остановить.
Курсор, который прыгает и кликает в одно и то же мгновение, не даёт вам ничего.

Если агент работает где-то ещё — на сервере, в контейнере — то же самое
появляется в [веб-интерфейсе](web.md): кадр, который он рассматривал, с меткой
в месте действия.

---

## Включение

Два шага, намеренно. Ни один не происходит сам собой.

**1. Разрешить инструменту существовать**, в `~/.comodor/config.json`:

```json
{
  "computer": {
    "enabled": true
  }
}
```

Пока это не задано, модель вовсе не получает этот инструмент. Его нет в списке
инструментов, поэтому она не может его запросить и не может быть уговорена.

**2. Разрешить ему действовать**, в момент, когда это важно:

```
/computer 15m              пятнадцать минут, в любом месте экрана
/computer 1h this app      один час, только пока текущее окно на переднем плане
/computer                  как обстоят дела
/computer stop             закончить прямо сейчас
```

Или позвольте модели спросить. Первый раз, когда ей понадобится экран, вы
увидите это:

```
  Let Comodor use your screen, mouse and keyboard?

  It will be able to see everything on your screen and to click and type
  anywhere, in any application.

  Screenshots go to the model. Whatever is on screen goes with them - open
  messages, tokens, anything visible. Redaction works on text and cannot
  read pixels.

  It will never touch a password manager, a window asking for a password,
  a locked screen, or Comodor's own window.

  To stop it at any moment: move your mouse into a corner of the screen.

  [15 minutes]  [15 minutes, this app only]  [1 hour]  [no]
```

## Остановка

**Подведите мышь к углу экрана.** Это и есть весь способ.

Он работает, пока агент удерживает указатель, чего не может обещать ни одно
клавиатурное сочетание — в тот момент агент может печатать в окно. Это также то,
что люди реально делают, когда их экран начинает двигаться сам по себе.

Касание угла завершает запуск и отбирает разрешение. Повторный запрос — это
новая выдача.

Агент всё ещё может сам кликнуть в угол — кнопку «Пуск», крестик закрытия. Он
помнит, где оставил указатель, поэтому вашим касанием считается только указатель,
переместившийся туда, куда его не помещал никто.

Другие способы остановить его, когда руки на клавиатуре:

```
/computer stop       завершает действие разрешения
Esc                  прерывает текущую задачу
```

## Разрешение

Выдача — это три вещи одновременно, и ни одна из них не является галочкой.

| | |
|---|---|
| **Область** | везде, или одно приложение по заголовку его окна |
| **Часы** | у неё есть срок, и оставшееся время всё это время на экране |
| **Выход** | угол, который работает, пока указателем управляют |

Проверка выполняется **перед каждым отдельным действием**, а не один раз в начале.
Окно, появившееся посреди выданного запуска, будет перехвачено.

### Отказывается независимо от того, что вы разрешили

- Менеджер паролей — 1Password, Bitwarden, KeePass, LastPass, Dashlane,
  NordPass и системные хранилища учётных данных.
- Любое окно, в заголовке которого упоминаются пароль, парольная фраза, 2FA или
  одноразовый код.
- Приложение-кошелёк или аппаратный кошелёк — MetaMask, Ledger Live, Trezor.
- Всё, что похоже на онлайн-банкинг.
- Экран блокировки.
- **Собственное окно Comodor.** Агент, кликнувший в терминал, который им
  управляет, печатает в собственный запрос.

Добавьте свои:

```json
{
  "computer": {
    "never": ["Internal HR", "Payroll"]
  }
}
```

Совпадение ищется в любом месте заголовка окна, без учёта регистра.

### Чем выдача не является

Она **никогда не записывается в ваш файл конфигурации**. Закрытие Comodor
завершает её. Для экрана нет «всегда разрешать», и это упущение намеренно.

Репозиторий не может это включить. `computer` нет в списке того, что может
задавать `.comodor/config.json` проекта, а репозиторий, который пытается,
получает громкий отказ. См. [Безопасность](safety.md#what-a-repository-may-set).

## Что уходит модели

**Скриншоты и всё видимое в них.** На этом стоит остановиться.

Если менеджер паролей открыт позади вашего редактора, если в окне чата есть
сообщение, если API-ключ напечатан в терминале — это на картинке, и картинка
уходит тому провайдеру, которого вы настроили.

Маскирование Comodor работает с текстом и не умеет читать пиксели. Обойти это
невозможно: суть функции — «позволь модели видеть ваш экран».

Практический совет:

- Закройте то, что не вставили бы в окно чата.
- Используйте `/computer 1h this app`, чтобы он действовал только пока одно окно
  на переднем плане — хотя он всё равно *видит* всё, что попало на скриншот.
- Предпочитайте [инструмент браузера](browser.md), когда работа — веб-страница.
  Он возвращает текст, а не пиксели, и стоит в разы дешевле.

## Что он умеет

Семнадцать действий за одним инструментом. Названия — от Anthropic, потому что
модели обучаются на этом словаре.

### Разглядывание

| Действие | Что оно делает |
|---|---|
| `screenshot` | Активный монитор. `whole_desktop: true` для всех мониторов. |
| `zoom` | Область в полном разрешении — так он читает мелкий текст |
| `cursor_position` | Где находится указатель |

### Наведение

| Действие | |
|---|---|
| `mouse_move` | Переместиться куда-то без клика |
| `left_click` `right_click` `middle_click` | С необязательными клавишами-модификаторами |
| `double_click` `triple_click` | Тройной выделяет строку в большинстве редакторов |
| `left_click_drag` | Из одной точки в другую |
| `left_mouse_down` `left_mouse_up` | Для всего, что перетаскивание не выражает |
| `scroll` | Вверх, вниз, влево, вправо, щелчками колеса |

### Печать

| Действие | |
|---|---|
| `type` | Текст, по символам — верно на любой раскладке клавиатуры |
| `key` | `Return`, `ctrl+s`, `alt+Tab`, `F5`, `Page_Down`, … |
| `hold_key` | Удерживать клавишу или сочетание заданное время |
| `wait` | Дать чему-то на экране завершиться |

Текст вводится **по символам, а не по позиции клавиш**. Нажатие клавиши, где `@`
находится на американской клавиатуре, даёт что-то другое на французской; имя
символа даёт `@` везде, включая раскладки, где для него нет клавиши.

## Введено — не значит доставлено

Приложения переписывают то, что в них вводят.

«Блокнот» Windows 11 по умолчанию включает автозамену. Ввод `ümlaut` даёт
`umlaut`. По пути ничего не потерялось — каждый из тридцати акцентированных и
нелатинских символов приходит целым при одиночной отправке, а `üxqzv` в той же
позиции не тронут. Его изменило приложение.

Comodor говорит об этом при каждом `type`:

```
Typed 29 characters. Applications can autocorrect or reformat what is
typed into them - take a screenshot if what arrived matters.
```

Если точный текст важен — поле пароля, значение конфигурации, сообщение коммита —
попросите его посмотреть ещё раз.

## Скриншоты и их стоимость

Скриншот — самая дорогая вещь, которую отправляет этот инструмент.

Размер подгоняется под то, что примет модель: длинная сторона в 2 576 пикселей
и бюджет токенов. Бюджет по умолчанию — 1 600 визуальных токенов, что даёт
читаемую картинку на каждом испытанном экране.

| Ваш экран | При бюджете по умолчанию | Стоимость |
|---|---|---|
| 1920 × 1080 | 1480 × 833 | ~1,590 токенов |
| 3840 × 1080 | 2068 × 582 | ~1,554 токенов |
| 3840 × 2160 | 1064 × 599 | ~836 токенов |

**Не задавайте это слишком низко.** Распространённый совет «снимать с шириной
1280» предполагает экран 16:9. На дисплее 3840 × 1080 это означает трёхкратное
уменьшение, и при таком размере модели достаётся текст, который она не может
прочитать — тогда она угадывает вместо того, чтобы спрашивать. Измерено на таком
экране: подписи меню нечитаемы при ширине 1280 и прекрасно видны при 2068.

```json
{
  "computer": {
    "screenshot_tokens": 1600
  }
}
```

700 — дёшево и всё ещё читаемо на ноутбуке. 4784 — максимум, что принимает модель.

**Старые скриншоты удаляются автоматически.** В разговоре остаются только два
последних; остальные превращаются в строку о том, что один там был. Без этого
задача в тридцать шагов несла бы почти пятьдесят тысяч токенов пикселей, почти
все из которых описывают экран, по которому давно кликнули. Измените это через
`agent.keep_screenshots`, если есть причина.

## Все настройки

```json
{
  "computer": {
    "enabled": false,
    "screenshot_tokens": 1600,
    "grant_seconds": 900,
    "travel_seconds": 0.32,
    "overlay": true,
    "never": []
  }
}
```

| Настройка | По умолчанию | |
|---|---|---|
| `enabled` | `false` | Предлагается ли модели инструмент вообще |
| `screenshot_tokens` | `1600` | Читаемость против цены. Максимум 4784 |
| `grant_seconds` | `900` | Сколько длится простая выдача |
| `travel_seconds` | `0.32` | Сколько указатель тратит на перемещение. `0` работало бы, но за этим невозможно следить |
| `overlay` | `true` | Рисовать ореол и панель. Отключите для машины, за которой никто не сидит |
| `never` | `[]` | Дополнительные заголовки окон, которые никогда не трогать |

## Почему его нет

Если `computer` нет среди инструментов, верно одно из этих утверждений:

**У платформы нет бэкенда.** Пока только Windows. Инструмент не предлагается, а
не предлагается и падает каждый раз — инструмент, который модель видит и никогда
не использует, приглашает к напрасному вызову на каждом ходе.

**Он выключен.** `computer.enabled` по умолчанию `false`.

Спросите напрямую:

```
/computer
```

```
no screen control: it is switched off. Set computer.enabled in your config.
```

## Под капотом

Для любопытных и для всех, кто переносит его на другую платформу.

**Без зависимостей.** Захват экрана — GDI через `ctypes`; уменьшение —
`StretchBlt` в режиме `HALFTONE`, который усредняет, а не выбрасывает пиксели —
разница между читаемым мелким текстом и зернистостью. Кодирование PNG — `zlib`
и `struct`, около сорока строк. Ввод — `SendInput`.

**Уведомление о DPI устанавливается прежде, чем что-либо читает метрику экрана.**
На дисплее с масштабом 125% — стандарт для большинства ноутбуков на Windows —
процессу, не объявившему себя DPI-aware, сообщают, что экран меньше, чем он есть,
и каждый клик приходит с недолётом ровно в коэффициент масштаба. Причина
невидима; это выглядит так, будто модель не умеет целиться.

**Координаты преобразуются в одном месте.** Модель отвечает в пикселях картинки,
которую ей показали, — уменьшенного фрагмента экрана с началом координат, о
котором ей не сообщили. `Shot.to_screen` — единственный код, знающий об этом,
потому что вторая копия — это второй шанс ошибиться.

**Наложение — это окно с прохождением кликов, никогда не получающее фокус.**
`WS_EX_LAYERED |
WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`, поэтому указатель достаёт до того, что
под ним, а клавиатура остаётся там, где была. Оно работает в собственном потоке
со своим циклом событий, и неудача отрисовки — это отсутствие картинки, а не
отсутствие функции — агент работает вовсе без отображения.

Перенос на macOS или Linux означает написание одного файла рядом с `win32.py`
с той же дюжиной функций. Ничто выше этого слоя не импортирует `ctypes`.
