# Переход от другого агента

Если вы уже пользуетесь **OpenClaw** или **Hermes**, Comodor при первом запуске
предложит перенести вашу настройку.

Вы уже нашли свои API-ключи и вставили их куда-то. Делать это снова — плохое
первое впечатление.

---

## При первом запуске

```
 1/7  You already use OpenClaw
  OpenClaw  1 API key, the model (claude-sonnet-5), 1 skill
  /home/you/.openclaw

  Nothing is moved and nothing already set here is replaced.
  Keys are copied into your config; the other tool keeps working.

  1.  bring it over   keys, model and skills
  2.  keys only       leave the skills and the model
  3.  start fresh     import nothing
```

Вопрос появляется только тогда, когда есть что импортировать.

---

## После этого

Установили один из них позже или ответили «start fresh» и передумали:

```bash
comodor import              # перенести
comodor import --dry-run    # сказать, что взял бы, ничего не меняя
comodor import --keys-only  # оставить навыки и модель
```

Запустить его дважды безопасно — во второй раз он скажет, что нового нет.

---

## Что переносится

| | |
|---|---|
| **API-ключи** | вся скука целиком. Из их `.env` и из встроенного JSON OpenClaw |
| **Модель** | если Comodor может её принять |
| **Навыки** | оба инструмента пишут один и тот же открытый формат, так что это просто файлы для копирования |

Три правила на всём протяжении, потому что это читает файлы другой программы:

- **Ничто не перезаписывается.** Ключ, уже настроенный здесь, побеждает; импорт
  заполняет пробелы.
- **Ничто не перемещается.** Каждое чтение — это чтение. Другой инструмент
  продолжает работать ровно как раньше.
- **Битый файл пропускается, а не становится фатальной ошибкой.** Половина ценности
  в том, что это работает на машине, чей другой агент находится в странном
  состоянии.

---

## Что не переносится, и почему

**Их память.** Она названа вслух, а не пропущена молча:

```
not imported: MEMORY.md — its memory is prose; this agent's is lessons with
confidence and evidence, and inventing those would poison recall
```

Мозг Comodor — это уроки с уверенностью, доказательством и угасанием, извлечённые
из исправлений. `MEMORY.md` — это проза. Импортировать одно вместо другого —
значило бы изобрести уверенности, которые никто не измерял, и заполнить
воспоминание записями, которые никогда не были заслужены. Вы получили бы худшего
агента, выглядящего как лучше информированный.

**Персоны, мессенджинг, синтез речи.** У Comodor нет эквивалента, а настройка,
импортированная в никуда, хуже, чем отсутствие настройки.

**Ключ, хранящийся где-то ещё.** OpenClaw позволяет ключу быть ссылкой на файл
или команду. Они что-то значат на машине, для которой были написаны, и ничего
здесь, поэтому о них сообщают, а не угадывают.

## Навыки, и одна вещь, которую стоит знать

Импортированные навыки получают пространство имён — `review` становится
`openclaw-review` — так что импорт никогда не может тихо заменить ваш собственный.

Папка навыка копируется файл за файлом, и **папка, содержащая ссылку за свои
пределы, отвергается**. Навык — это файл, чьё содержимое читается в промпт, так
что симлинк на `~/.ssh/id_rsa`, лежащий в каталоге навыков другой программы,
иначе был бы скопирован внутрь и отправлен модели. Он отвергается, и называется:

```
not imported: the skill sneaky — it contains a link out of that folder
```

---

## Где он ищет

| | |
|---|---|
| OpenClaw | `~/.openclaw`, `~/.clawdbot`, `~/.moltbot` |
| Hermes | `~/.hermes` |

Старые каталоги OpenClaw всё ещё живут на настоящих машинах — его переименовывали
дважды, — так что проверяются все три.

Чтобы он вообще не искал:

```bash
export COMODOR_NO_IMPORT=1
```
