# Выбор модели

Comodor работает с чем угодно, что говорит на OpenAI или Anthropic API, —
семнадцать провайдеров из коробки плюс что угодно ещё с URL.

---

## Короткий ответ

| Вы хотите | Выберите |
|---|---|
| Самый лёгкий старт, один ключ, всё | **OpenRouter** |
| Самую сильную агентную работу | **Anthropic**, `claude-sonnet-5` |
| Ничего не платить и оставаться офлайн | **Ollama** или **LM Studio** |
| Очень дёшево и хорошо в коде | **DeepSeek** |
| Очень быстро | **Groq** или **Cerebras** |

```bash
comodor setup        # выбрать одну, один раз
```

---

## Все провайдеры

**Хостинговые, один ключ:** OpenRouter · Anthropic · OpenAI · Google Gemini ·
DeepSeek · xAI · Mistral · Groq · Cerebras · Moonshot (Kimi) · Z.AI (GLM) ·
Qwen · Together · Fireworks · Xiaomi MiMo

**На вашей машине, без ключа:** Ollama · LM Studio

**Что-нибудь ещё:** выберите *Something else* и дайте базовый URL. Подойдёт любой
эндпоинт, совместимый с OpenAI.

---

## Запуск локально и бесплатно

```bash
ollama pull qwen2.5-coder:14b
comodor setup           # выбрать Ollama
```

Ни ключа, ни затрат, ни сети. Кодерная модель 14B действительно пригодна для
повседневной работы; разница проявляется на длинных многошаговых задачах.

## Переключение

```bash
comodor --model claude-haiku-4-5      # только этот запуск
```

```
/model                  # список того, что предлагает провайдер
/model gpt-4o           # по имени
/provider               # вообще другой провайдер
```

Индикатор контекста следует за моделью. Переход с модели на миллион токенов на
модель на 128k меняет лимит немедленно — и это важно, потому что агент
уплотняет разговор на доле от лимита, а устаревший лимит означает, что он
никогда не уплотняет и затем падает на настоящем потолке провайдера.

Чтобы сделать переключение постоянным: `/save` или правка
`~/.comodor/config.json`.

## Ключи

Работает либо место, и ни одно не копируется в другое:

```json
{ "providers": { "anthropic": { "api_key": "sk-ant-…" } } }
```

```bash
export ANTHROPIC_API_KEY=sk-ant-…
```

Ключ в вашем окружении **остаётся там** — `/save` не запишет его на диск.
Экспортировать, а не сохранять — это решение, и оно уважается.

Собственный файл конфигурации Comodor записывается с правами только для
владельца, и ваш ключ никогда не появляется в логе, транскрипте, экспорте или
трейсбеке. [Безопасность](safety.md#your-keys).

## Шлюз

Маршрутизация между несколькими провайдерами вместо закрепления за одним.

```
/gw                    # или F5
```

```json
{
  "gateway": {
    "enabled": true,
    "policy": "quality",
    "chain": ["anthropic", "openrouter", "deepseek"],
    "failure_threshold": 3
  }
}
```

`policy` — это `cost`, `speed` или `quality`. Провайдер, отказавший трижды подряд,
обходится стороной на минуту. Строка состояния показывает `GW: Quality`, когда он
включён, и `GW: Disable`, когда нет.

## Зрение

Некоторые инструменты возвращают картинки — `browse look` и каждый скриншот
`computer`. Для них нужна модель, которая умеет видеть. Всё нынешнее семейство
Claude и GPT-4o умеет; большинство открытых моделей — нет.

Если планируете пользоваться [экраном](computer.md), сначала проверьте, что у
модели есть глаза, иначе ей дадут картинку, которую она не сможет прочитать, и
она начнёт угадывать.
