# Поиск неисправностей

## Начните здесь

```bash
comodor doctor
```

Он проверяет файл конфигурации и его разрешения, провайдера, модель, предел
трат, мозг, поисковый индекс, ваши навыки, оставшиеся файлы, серверы MCP и то,
есть ли более новый релиз.

```bash
comodor doctor --fix
```

чинит то, что чинится. Он никогда не меняет ничего, о чём не сообщил сначала.

---

## Он не запускается

**`comodor: command not found` сразу после установки** — установщик положил его
в ваш `PATH`, но дочерний процесс не может изменить среду оболочки, которая его
запустила. Каждый *новый* терминал уже работает. Для того, в котором вы
находитесь, установщик напечатал строку для вставки; или:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

**`comodor: command not found` в новом терминале** — это настоящая проблема.
`python -m comodor` подтверждает, установлен ли он вовсе, а
`ls ~/.local/bin/comodor` — на месте ли он.

**`No provider is configured`** — запустите `comodor setup` или экспортируйте
ключ:

```bash
export ANTHROPIC_API_KEY=sk-ant-…
```

**Python слишком старый.** Comodor нужны 3.11 или новее. Проверьте командой
`python --version`.

## Настройка, кажется, ничего не делает

Comodor сообщает, когда отвергает одну:

```
config: agent.max_steps must be a whole number; keeping 0
config: this project cannot set safety, computer — only your own can
```

Если ничего не сказано и она всё ещё без действия, проверьте, какой слой
побеждает:

```
/settings          # что фактически загружено
```

```bash
comodor doctor     # то же, плюс где каждый файл
```

`--model` в командной строке бьёт ваш файл конфигурации, а ключ в вашей среде
бьёт ключ в файле. Это намеренно —
[Конфигурация](configuration.md#what-wins).

---

## `/save` не сохранил то, что я ожидал

По замыслу. Он записывает **только то, что вы выбрали** — не настройки
репозитория, не ключ, который вы держите в среде, не флаг, переданный на один
запуск.

Чтобы сделать настройку репозитория своей, задайте её сначала сами
(`/model x`), а затем сохраняйте.

## Запросы падают

**`401` или `invalid api key`** — ключ неверен, истёк или принадлежит другому
провайдеру. `comodor doctor` показывает, какой провайдер активен.

**`404 model not found`** — этот провайдер не обслуживает такой id модели.
`/model` перечисляет то, что он фактически предлагает.

**Таймауты.** Локальная модель на скромной машине может честно занимать минуты.
Поднимите `providers.<name>.timeout`.

**Он останавливается раньше времени.** Посмотрите на `stopped`. `max_steps` и
`budget` — потолки, делающие свою работу, а не отказы. Поднимите их на один
запуск с `--max-steps` или навсегда под `agent`.

## Инструмент браузера

**«no browser found»** — установите Chrome, Chromium, Edge или Brave или задайте
`browser.executable`. Без него `browse` переключается на текстовый браузер,
который всё равно отвечает на большинство вопросов о странице.

**Я хочу наблюдать, как он работает** — `browser.headless: false`.

**Ему нужен вход, который у меня уже есть** — запустите свой браузер с портом
DevTools и задайте `browser.port`, чтобы он использовал ту сессию вместо того,
чтобы передавать ему ваш профиль.

## Инструмент экрана

**Его нет в списке инструментов.** Либо у этой платформы нет бэкенда — пока
только Windows, — либо `computer.enabled` ложен. Спросите его:

```
/computer
```

**Клики приходят не туда.** Этого не должно случаться: уведомление о DPI
устанавливается до того, как прочитана любая метрика экрана. Если случается,
пожалуйста, сообщите об этом, указав масштабирование и разрешение дисплея.
Это настоящий баг.

**Он остановился сам.** Мышь ушла в угол экрана, что намеренно завершает выдачу.
`/computer 15m` начинает другую.

**Прибывший текст — не тот текст, что он набрал.** Его переписало приложение —
«Блокнот» Windows 11 делает автозамену на лету. Это не баг Comodor, и он говорит
об этом при каждом `type`. [Подробнее](computer.md#typed-is-not-the-same-as-arrived).

## Веб-интерфейс

**Он отказывается запускаться.** Провайдер не настроен, и браузерному интерфейсу
некуда добавить его. Сообщение называет то, что задать.

**«Unauthorised».** Новый токен генерируется при каждом запуске — используйте
URL из *этого* запуска или задайте `COMODOR_WEB_TOKEN`, чтобы держать его
стабильным.

**В Docker, ничего на `localhost:8765`.** Проверьте, что порт опубликован как
`127.0.0.1:8765:8765`. [Docker](docker.md).

---

## Что-то медленно

**Первый запрос сессии.** Ещё ничего не закэшировано; второй гораздо быстрее.

**Рефлексия после каждой задачи.** Один вызов модели. Используйте
`learning.reflect_model` для подешевле или `reflect: false`.

**Скриншоты.** Около 80 мс на снимок плюс модель, разглядывающая их. Опустите
`computer.screenshot_tokens`, если результат всё ещё читаем.

## Начать заново

```bash
comodor uninstall --dry-run     # что уйдёт, поимённо
comodor uninstall               # сделать это
```

Или только мозг, сохранив настройки:

```bash
rm ~/.comodor/brain.db
```
