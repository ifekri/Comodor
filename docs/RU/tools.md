# Что умеет агент

Тринадцать инструментов. Каждый объявляет уровень риска, который решает, спросит
ли он сначала, — см. [Безопасность](safety.md#risk-tiers).

---

## Файлы

| | Риск | |
|---|---|---|
| `read_file` | safe | Прочитать текстовый файл. Потоково, так что кусок большого лога достижим |
| `list_dir` | safe | Записи каталога, с размерами |
| `glob` | safe | Найти файлы по шаблону имени — `src/**/*.py` |
| `grep` | safe | Искать в содержимом регулярным выражением |
| `write_file` | write | Создать файл или заменить его целиком |
| `edit_file` | write | Заменить точную строку в файле |

Всё ограничено папкой проекта, если вы не выключите
`safety.workspace_only`.

Для изменения существующего файла `edit_file` предпочтительнее `write_file`:
оно меньше, его можно просмотреть как diff, и оно не может молча потерять
остальную часть файла.

## Запуск вещей

| | Риск | |
|---|---|---|
| `run_shell` | dangerous | Команда shell в рабочем пространстве |
| `run_python` | dangerous | Короткий фрагмент Python, в субпроцессе |

Оба спрашивают перед запуском, оба подчиняются `safety.deny_commands`, и у обоих
ограничен вывод — см. [Когда вывод слишком большой](#when-output-is-too-big).

В интерфейсе можно обойти модель целиком:

```
!git status
```

Выполняет её, показывает вам вывод и никогда не упоминает её модели. Быстрее и
дешевле, чем спрашивать.

## Веб

| | Риск | |
|---|---|---|
| `web_fetch` | dangerous | Скачать URL и вернуть его читаемый текст |
| `web_search` | dangerous | Искать и вернуть заголовки, URL и фрагменты |
| `browse` | dangerous | Настоящий браузер — JavaScript, cookie, входы в аккаунты |

`web_fetch` — дешёвый: он вычищает страницу до текста. Используйте его, когда
страница — документ.

`browse` — для случая, когда это приложение: что-то, что требует JavaScript,
входа или клика. [Полное руководство](browser.md).

## Машина

| | Риск | |
|---|---|---|
| `computer` | dangerous | Мышь, клавиатура и экран, в любом приложении |

Выключен, пока вы его не включите, и всё равно не разрешён, пока не выдадите
доступ. [Полное руководство](computer.md). Пока только Windows.

## Учёт хода работы

| | Риск | |
|---|---|---|
| `todo_write` | safe | Список задач, который вы видите в боковой панели |

Агент пишет сюда свой собственный план. Это не украшение — так длинная задача
остаётся связной, и так вы видите, где он находится.

## Иногда есть, иногда нет

Comodor предлагает модели только тот инструмент, которым она действительно может
воспользоваться. Инструмент, который она видит, но никогда не может применить
успешно, приглашает к напрасному вызову на каждом ходу.

| | Появляется, когда |
|---|---|
| `read_skill_file` | установленный вами навык несёт с собой файлы |
| `search_history` | есть прошлые сессии для поиска |
| `delegate` | можно породить суб-агента |
| `computer` | у платформы есть бэкенд **и** вы его включили |
| инструменты MCP | сервер настроен и включён |

У `browse` две реализации: настоящий браузер, когда установлен Chrome, Chromium,
Edge или Brave, и текстовый браузер, когда не установлен ни один. Оба называются
`browse`, потому что выбор между двумя вещами с именем «browser» — это ход,
который модели не стоит тратить.

## Когда вывод слишком большой

Команда, печатающая пятьдесят тысяч строк, не обрезается до бесполезности и не
взрывает контекст.

Что помещается, идёт модели — начало и конец, потому что обычно именно там
находится ответ. Остальное записывается в файл под `~/.comodor/output/`, и модели
сообщают путь и то, как его прочитать. Так что она может пойти и посмотреть, если
нужно, и не платит ничего, если не нужно.

```json
{ "agent": { "max_tool_chars": 12000 } }
```

## Суб-агенты

`delegate` запускает второго агента в **git worktree** — изолированном checkout
того же репозитория. Он работает там, и его изменения возвращаются патчем,
применённым трёхсторонним слиянием.

У него нет памяти, он не может делегировать дальше, и ему не даётся экран.
Он наследует отмену родителя, так что `Esc` останавливает и его.

Полезно для чего-то действительно отдельного — «портируй этот модуль на новый API,
пока я продолжаю работать» — и расточительно для всего остального.

## Инструменты MCP

Всё, что предоставляет включённый сервер Model Context Protocol, появляется рядом
со встроенными инструментами и проходит ровно тот же фильтр разрешений.

```bash
comodor mcp list
```

[Полное руководство](mcp.md).
