# Навыки

Навык — это записанная процедура, которой агент следует, когда работа её требует.

Не промпт, который вы вставляете каждый раз, — файл, который он сам загружает,
когда ситуация совпадает.

---

## Где их взять

`comodor setup` один раз предлагает библиотеку в конце. Двигайтесь стрелками,
нажимайте **space**, чтобы отметить сколько хотите, и **enter** установит их
все. Изначально ничего не отмечено, и enter без отметок не берёт ничего — вам
никогда не дают то, о чём вы не просили.

```
┌─ Skills ──────────────────────────────────────────────────┐
│    ☑ review        Review a change before it is committed │
│ ›  ☐ commit-style  Match the commit messages already here │
│    ☑ python-tests  Write tests the way this project does  │
└───────────────────────────────────── 2 selected ──────────┘
  ↑↓ move   space select   enter install 2   tab more   esc cancel
```

**Одна строка на навык**, так что весь список помещается на один экран, какой
бы длинной ни становилась библиотека, а окно следует за стрелкой, а не отстаёт
от неё. Некоторые описания тянут на абзац — **tab** открывает полное описание
того, на чём стоит стрелка, в том же кадре, и ещё раз tab его закрывает.

Ввод текста фильтрует список, что быстрее прокрутки, когда пунктов больше
нескольких. Отметки сохраняются во время фильтрации, так что вы можете сузить
список, отметить что-то, сбросить фильтр и отметить что-то ещё.

Без терминала он может взять управление на себя — пайп, скрипт, `curl | sh`, —
и тогда тот же вопрос задаётся нумерованным списком, по странице за раз:

| | |
|---|---|
| `1,3` или `1 3` | взять эти |
| `m` / `b` | следующая страница, предыдущая страница |
| `/word` | показать только совпадения |
| `?7` | прочитать полное описание номера 7 |
| enter | готово |

Номера абсолютные: номер 92 — это девяносто второй навык, на какой бы странице
или в каком поиске вы ни находились, так что записанный номер остаётся тем
номером, который вы вводите.

## Как пользоваться навыком

```bash
comodor skills browse            # что доступно
comodor skills add review        # установить его
comodor skills list              # что у вас есть
```

```
/skills                          # то же самое, в интерфейсе
```

С этого момента, когда вы просите о том, что покрывает навык, он загружается,
и агент следует ему. Вам сообщают, когда это происходит:

```
  ▸ skill: review — Review a change for correctness before it is committed
```

Навык, применение которого вы не видите, — навык, который вы не можете
исправить.

## Как написать навык

Папка с файлом `SKILL.md` внутри:

```
~/.comodor/skills/our-tests/SKILL.md
```

```markdown
---
name: our-tests
description: How tests are written and run in this project.
---

# Tests in this project

- pytest, never unittest.
- One file per module, mirroring `src/`.
- Name the test after the behaviour, not the function:
  `test_an_empty_input_raises`, not `test_parse_2`.
- Never mock what you can construct.

## Running them

    uv run pytest -x -q

Not `python -m pytest` — the project needs the venv's own interpreter.
```

**Description** важнее всего. Именно Comodor сопоставляет его с вашим запросом,
чтобы решить, загружать ли навык вообще, так что пишите его как ситуацию,
а не как заголовок.

Перезапуск, или `/skills`, — и навык на месте.

### Прилагающиеся файлы

Навык может нести файлы рядом с `SKILL.md`:

```
~/.comodor/skills/our-tests/
  SKILL.md
  references/
    fixtures.md
    conventions.md
```

`SKILL.md` ссылается на них; агент читает файл, только когда он нужен. Это
держит сам навык коротким — что важно, потому что навык загружается в ход,
и длинный стоит токенов независимо от того, понадобилась ли деталь.

---

## Для каждого проекта

```
./.comodor/skills/<name>/SKILL.md
```

Коммитятся вместе с репозиторием, так что все, кто работает над ним, получают
одни и те же процедуры. Навыки проекта загружаются рядом с вашими.

---

## Бюджет

```json
{
  "skills": {
    "enabled": true,
    "top_k": 2,
    "max_tokens": 12000
  }
}
```

`top_k` — сколько навыков может быть загружено за один ход; `max_tokens` —
потолок того, сколько они могут стоить вместе. Навык, слишком большой, чтобы
поместиться, пропускается, и вам сообщают какой, — здесь молчание было настоящей
ошибкой, когда слишком большой навык тихо вытеснял меньшие.

## Управление ими

```bash
comodor skills add review taste output    # несколько за раз
comodor skills update                     # обновить установленные
comodor skills remove review
comodor skills list                       # с версиями
```
