# Из браузера

Тот же агент, во вкладке браузера. На этой машине или на сервере, до которого вы
добираетесь по SSH.

```bash
comodor web
```

```

  / ____/___  ____ ___  ____  ____/ /___  _____
 / /   / __ \/ __ `__ \/ __ \/ __  / __ \/ ___/
/ /___/ /_/ / / / / / / /_/ / /_/ / /_/ / /
\____/\____/_/ /_/ /_/\____/\__,_/\____/_/

  it learns the way you correct it   0.9.0  ·  claude-sonnet-5

  Comodor is at  http://127.0.0.1:8765/?token=EYhO9St_VTy95k4gHtJytb
  Working in     /home/you/projects/api-server

  Only this machine can reach it. Ctrl-C to stop.
```

Откройте ссылку. Токен в ней.

---

## Опции

```bash
comodor web --port 9000
comodor web --no-browser            # не открывать за меня
comodor web --token mytoken         # фиксированный токен
comodor web --host 0.0.0.0          # доступно из других мест — читайте ниже
```

---

## Токен

Новый при каждом запуске, поэтому URL из вчерашнего дня — не путь внутрь сегодня.
Он приходит в URL, обменивается на cookie, и каждый последующий запрос
авторизуется cookie.

Чтобы сохранить его стабильным между перезапусками:

```bash
export COMODOR_WEB_TOKEN=something-long-and-random
```

Любой с токеном имеет оболочку на той машине. Относитесь к нему как к ней.

---

## Привязка к большему, чем loopback

`--host 0.0.0.0` выкладывает интерфейс на каждый интерфейс машины. **Этот порт
есть оболочка.** Comodor говорит об этом, а не предполагает, что вы имели это в
виду:

```
  Listening on every address on this machine.
  Anyone who can reach this port can run commands as you.
```

Лучше, когда агент на сервере: оставьте его на loopback и туннелируйте.

```bash
ssh -N -L 8765:127.0.0.1:8765 you@server
```

Затем откройте `http://127.0.0.1:8765` локально. Порт никогда не выставляется
наружу, а SSH делает аутентификацию.

## Наблюдая, как он пользуется экраном

Если агент управляет рабочим столом, кадр, который он рассматривал, появляется
в интерфейсе с меткой в месте действия:

```
┌────────────────────────────────────────────┐
│                                            │
│   [ the screen the model saw ]      ✛      │
│                                            │
│   clicking Save                            │
└────────────────────────────────────────────┘
```

В этом его смысл. Наложение на экране рисуется на управляемой машине, что
бесполезно, когда та машина — сервер или контейнер; панель — это то, как вы
наблюдаете откуда-то ещё.

Картинка загружается один раз за кадр с `/api/screen`, а не несётся в потоке
событий: скриншот — это около мегабайта, и браузер, перечитывающий журнал
событий, скачивал бы каждый кадр, который когда-либо видел.

[Использование вашего экрана](computer.md).

## Чего он не будет делать

**Запускаться без провайдера.** Он может переключаться между уже настроенными
провайдерами, но вводить в него ключ некуда, и вкладка браузера — плохое место
для ключа. Вместо того чтобы обслуживать URL, падающий на первой задаче, он
говорит, чего не хватает, и останавливается:

```
Comodor has no provider configured, and the browser interface has no way to
add one.

  In Docker, pass a key in as an environment variable:
    -e ANTHROPIC_API_KEY=...    -e OPENAI_API_KEY=...
  or mount a config file at ~/.comodor/config.json.
  Anywhere with a terminal, `comodor setup` asks a few questions.
```

В терминале он вместо этого задаёт вопросы настройки. В контейнере он всегда
печатает сообщение — у контейнера есть терминал, подключён кто-то или нет, и
отсоединённый иначе ждал бы вечно ответа на вопрос, который никто не может
задать.

**Расширять то, чего агенту можно касаться.** Автоодобрение записей и команд
показано в Admin и не может быть изменено там. Запросы разрешений уже
предлагают этот выбор на каждое действие, перед человеком, которому с этим
жить; страница, доступная любому, у кого есть ссылка, — неверное место, чтобы
делать его постоянной политикой. Измените это там, где Comodor был запущен —
см. [Безопасность](safety.md).

## Что на экране

**Разговор**, потоковый по мере поступления, с блоками кода, сохранёнными как
код, и каждым вызовом инструмента в виде строки, которую можно открыть и увидеть,
что он на самом деле сделал.

**Список чатов**, слева. Каждый разговор записывается в `~/.comodor/sessions` —
ту же папку, что использует терминал, поэтому чат, начатый в приглашении,
открывается в браузере и наоборот. Поиск заглядывает внутрь них, а не только в
их заголовки.

**Admin**, вторая вкладка, — ответ на вопрос «что эта штука собирается сделать
с моей машиной»:

| | |
|---|---|
| Model | какой провайдер и модель отвечают, и переключение между теми, на которые у вас есть ключи |
| How it runs | режим, продолжает ли он сам по себе, и четыре потолка — контекст, шаги, время, траты |
| Permissions | что он может делать, не спрашивая, о чём он спросит, и что было выдано в этой сессии |
| What it has learned | правила, уроки, навыки, задачи и сколько из них удалось |
| Tools | каждый инструмент, до которого он может дотянуться, с цветовой маркировкой по риску, плюс ваши навыки и любые серверы MCP |
| This machine | версия, Python и где живут настройки, чаты и мозг |

**Полоса статуса** внизу: подключена ли страница, рабочая папка, насколько полон
контекст, чего стоила сессия и сколько выученных правил действует.

**Панель экрана**, когда агент управляет одним, — кадр, который он рассматривал
последним, с меткой, где он собирается кликнуть. См. [Использование вашего
экрана](computer.md).

## Клавиатура

| | |
|---|---|
| `Enter` | отправить |
| `Shift`+`Enter` | новая строка |
| `Esc` | остановить текущую задачу или закрыть боковую панель |
| `Ctrl`/`⌘`+`K` | поиск по чатам |
| `Ctrl`/`⌘`+`B` | показать или скрыть боковую панель |
| `/` | перейти к окну сообщения |

## На телефоне

Та же страница. Ниже 900 пикселей список чатов становится выдвижной панелью над
разговором, а не колонкой рядом с ним, потому что 292 пикселя боковой панели на
экране в 390 пикселей не оставляют ничего достаточно широкого, чтобы читать код.
Коснитесь вне её, нажмите `Esc` или используйте кнопку закрытия, чтобы убрать.

Доберитесь до него с телефона так, как добрались бы до чего угодно ещё на вашей
машине — SSH-туннель, а не публичная привязка. [Привязка к большему, чем
loopback](#binding-to-more-than-loopback) объясняет почему.

## Письмо на любом языке

Набирайте на персидском, арабском или иврите, и окно сообщения разворачивается,
пока вы печатаете; ответы на этих языках устанавливаются справа налево, когда
приходят. Ничего не настраивается, и настройки языка нет: каждое сообщение
судится само по себе, поэтому разговор, пересекающийся между языками,
перемещается вместе с ними.

Суждение — подсчётом, а не по первой букве, что и заставляет два неудобных
случая выходить правильно: персидское предложение, открывающееся именем пакета,
всё ещё персидское, а английское предложение, цитирующее одно персидское слово,
всё ещё английское. Код, пути и URL устанавливаются слева направо внутри
абзаца справа налево, где им и место.

Текст арабского письма набирается шрифтом Vazirmatn, который едет внутри пакета,
а не загружается с хоста шрифтов: это обязано работать на машине, которая не
может выйти в интернет. Он применяется к символам арабского письма и ни к чему
больше, поэтому строка, смешивающая персидский с английским идентификатором,
получает правильное начертание для каждого.
