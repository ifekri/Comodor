# Начало работы

Пять минут, в конце которых агент делает что-то полезное.

---

## 1. Установка

Одна строка. Остальное он выяснит сам.

**macOS · Linux · BSD**

```bash
curl -fsSL get.comodor.ai | sh
```

**Windows** — PowerShell

```powershell
irm get.comodor.ai | iex
```

```
Comodor — it learns the way you correct it.

  Linux x86_64
> Installing uv, a package manager Comodor needs (about 15 MB)
  from https://astral.sh/uv — it fetches a Python too, if one is missing
> Installing with uv

✓ comodor 0.9.0

  Linked into /usr/local/bin, which is on your PATH.

  comodor              start the interface
  comodor --demo       try it offline, no API key needed
  comodor doctor       check what is configured
```

**Один адрес для всего.** `get.comodor.ai` не содержит имени файла. Он определяет,
кто спрашивает, и отправляет `curl` и `wget` к установщику для shell, PowerShell —
к установщику для Windows, а браузер — на эту страницу, так что строка, которую вы
вставляете, одинакова на всех системах, и выбирать ничего не нужно.

**Он доводит установку до конца.** Человек, запускающий одну строку с веб-страницы,
не соглашался ничего отлаживать, поэтому скрипт устанавливает то, что нужно, —
изолированное окружение, менеджер пакетов, Python — вместо того чтобы
останавливаться и объяснять, что у вас уже должно было быть установлено.
Проверено на чистом `debian:bookworm-slim` вообще без Python.

### Почти всегда ничего не нужно вводить после установки

Там, где это возможно, он помещает `comodor` туда, куда ваша оболочка уже
смотрит, так что он работает в том же терминале, откуда вы его запустили, —
без `export` и без нового окна. Это охватывает root, контейнеры, CI и любой Mac
с Homebrew.

Там, где это невозможно, — обычная учётная запись Linux, где ни один каталог
на `PATH` недоступен для записи, — не поможет ни один установщик, потому что
дочерний процесс не может изменить окружение оболочки, которая его запустила.
Поэтому он так и говорит:

```
  Every new terminal can run comodor already.
  This one started before the install, and no installer
  can reach back into the shell that ran it. For this
  terminal only:

    export PATH="/home/you/.local/bin:$PATH"
```

Откройте новый терминал — и всё просто работает. Строка добавляется и в rc-файл
вашей оболочки, и в профиль входа, так что её находит оболочка любого типа —
интерактивная, login, неинтерактивная и сеанс рабочего стола.

### Если вы не хотите передавать скрипт в shell через пайп

Совершенно разумно. Оба скрипта — обычный текст, который можно сначала прочитать;
они названы напрямую, потому что короткий адрес отправляет всё, что не является
загрузчиком, на страницу:

```bash
curl -fsSL https://comodor.ai/install.sh  | less
curl -fsSL https://comodor.ai/install.ps1 | less
```

Или используйте менеджер пакетов, который у вас уже есть:

```bash
uv tool install comodor      # изолированно, и быстрее всего
pipx install comodor         # изолированно
pip install comodor          # в то окружение, где вы находитесь
```

Comodor нужен только **Python 3.11 или новее** — и больше ничего.

### Проверьте, что он установился

```bash
comodor --version
```

Если оболочка его не находит, установщик добавил каталог в ваш `PATH`, о котором
этот терминал ещё не знает. Откройте новый или выполните строку `export`,
которую напечатал установщик.

### Опции, которые понимают установщики

| | |
|---|---|
| `COMODOR_FORCE_TOOL` | зафиксировать способ: `uv`, `pipx`, `venv` или `pip` |
| `COMODOR_NO_BOOTSTRAP` | никогда не загружать инструмент; вместо этого завершиться с ошибкой |
| `COMODOR_NO_MODIFY_PATH` | не трогать профиль вашей оболочки |
| `COMODOR_INSTALL_REF` | установить из git-ref или локального пути вместо PyPI |

```bash
COMODOR_NO_MODIFY_PATH=1 curl -fsSL get.comodor.ai | sh
```

> **Пока не уверены, что хотите устанавливать?** `comodor --demo` запускает весь
> интерфейс против сценарного офлайн-провайдера. Ни ключа, ни аккаунта, ни сети.

## 2. Выбор модели

Запустите его. В первый раз он задаст шесть вопросов — и больше никогда.

```bash
comodor
```

```
 1/6  Which model provider?
┌─  Providers  ───────────────────────────────────────────┐
│ ›  OpenRouter        One key, hundreds of models         │
│    Anthropic         Claude, direct from the source      │
│    OpenAI            GPT models, direct                  │
│    Ollama (local)    Runs on your machine. No key        │
└──────────────────────────────────────────────────────────┘
  ↑↓ move   enter choose   tab more   esc cancel
```

Стрелки или ввод текста для фильтрации. **Tab** открывает полное описание
того, на чём стоит курсор, в том же кадре — списки показывают одну строку на
пункт, чтобы помещаться на экране, а некоторые описания длиной в целый абзац.

При передаче через пайп или в скрипте те же вопросы приходят в виде нумерованного
списка, так что процесс можно автоматизировать.

**Нет ключа и денег?** Выберите **Ollama** или **LM Studio**. Они работают на вашей
машине, не требуют ключа и ничего не стоят. Всё в этой документации работает
с ними, кроме мест, где сказано иное.

**Уже пользуетесь OpenClaw или Hermes?** Первый экран предложит перенести ваши
ключи, модель и навыки. Ничего не перемещается, и ничто уже настроенное здесь
не заменяется. См. [Переход от другого агента](migrating.md).

Ваши ответы сохраняются в `~/.comodor/config.json`, доступном только вам.
Передумаете позже — `comodor setup`, или по одной настройке за раз — см.
[Конфигурация](configuration.md).

### Последний вопрос — про ваш телефон

```
 6/6  Run it from your phone?
┌─  From your phone  ─────────────────────────────────────────────┐
│ ›  Not now    you can set any of them up later                   │
│    Telegram   one token from @BotFather — about a minute         │
│    Slack      an app from a manifest, two tokens — five minutes  │
│    WhatsApp   a Meta app and a public address — twenty minutes   │
└──────────────────────────────────────────────────────────────────┘
```

**Telegram** берёт токен у [@BotFather](https://t.me/botfather), проверяет его
у Telegram прямо на месте и показывает код, который нужно отправить боту, чтобы
он знал, какому аккаунту отвечать, — минута от начала до конца.
См. [С телефона](telegram.md).

**Slack** занимает около пяти минут. Приложение создаётся из манифеста, который
печатает Comodor, так что это одна вставка вместо страницы с чекбоксами, а
Socket Mode означает, что публичный адрес вообще не нужен — см.
[Из Slack](slack.md).

**WhatsApp** делает то же самое и занимает около двадцати минут: приложение Meta,
бизнес-номер, секрет приложения и публичный HTTPS-адрес — ничто из этого нельзя
создать из терминала. Стоит того, только если обязательно нужен WhatsApp — см.
[Из WhatsApp](whatsapp.md).

В любом случае он только читает и планирует, пока вы не скажете иное, а отказ
стоит одного нажатия клавиши.

### А затем он предлагает запуститься

```
 What now?
   1  Start Comodor          — the interface, here in this terminal
   2  Start the Telegram bot — in the background, answers while this is closed
   3  Both
   4  Nothing yet            — `comodor` starts it whenever you want
```

Раньше настройка на этом заканчивалась — вы возвращались к приглашению оболочки,
и ничего не работало. Строка про телефон появляется для каждого подключённого
и сопряжённого канала и названа по нему — тому, кто настроил WhatsApp, не
предлагают «бота Telegram».

## 3. Он спрашивает, в какой папке работать

```
  Work in  /home/you/projects/api-server ?
```

Спрашивается один раз для каждой папки. Всё, к чему агент может прикасаться,
находится внутри неё — он не может читать или писать за её пределами, пока вы
намеренно не отключите это. Одобренные папки запоминаются.

## 4. Попросите о чём-нибудь

Напишите и нажмите Enter.

```
> the tests in tests/test_parser.py are failing, work out why and fix it
```

Он прочитает файлы, запустит тесты и что-то изменит. Перед записью файла вы
получите diff и выбор:

```
  Write  src/parser.py
    - 12 lines removed, 8 added
  [a] allow   [A] allow always this session   [d] deny
```

Ответьте `a` один раз или `A`, если хотите, чтобы он перестал спрашивать до конца
сессии. В любом случае каждая запись фиксируется контрольной точкой: `/undo`
возвращает последнюю.

## 5. Исправьте его — это самая важная часть

Когда он делает что-то не так, скажите ему об этом. Два способа, и оба учат его
одному и тому же:

**Отредактируйте файл сами.** Comodor замечает, что вы изменили в его выводе.

**Скажите словами.**

```
> no — we use single quotes in this codebase, not double
```

В любом случае это становится уроком: он вспоминается в следующий раз, когда
ситуация выглядит похоже, с уверенностью, которая растёт, когда урок
подтверждается, и угасает, когда нет.

После нескольких сессий:

```
> /progress
```

## 6. Что стоит знать с первого дня

```
/help          every command
/mode          act · plan (read-only) · chat (no tools)     F3 cycles
/undo          restore the last file it changed
/cost          tokens, spend, what the cache saved
Esc            stop it, mid-thought
Ctrl-C twice   leave
```

## Если что-то пошло не так

```bash
comodor doctor
```

Он проверяет всё, что может, и говорит, что делать с каждой найденной проблемой.
`comodor doctor --fix` исправляет то, что исправимо. См.
[Устранение неполадок](troubleshooting.md).
