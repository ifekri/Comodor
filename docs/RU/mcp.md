# Серверы MCP

Model Context Protocol — это способ для инструмента описать себя агенту. Comodor
говорит на нём, поэтому всё, у чего есть MCP-сервер, становится тем, чем агент
может пользоваться.

---

## Добавление

```bash
comodor mcp catalogue          # серверы, которые Comodor может настроить для вас
comodor mcp add filesystem     # один из них
comodor mcp list               # что у вас есть и что каждый предлагает
```

Чего нет в каталоге:

```bash
comodor mcp custom notes -- npx -y @some/mcp-notes
comodor mcp remote github https://mcp.example.com/sse
```

Затем проверьте, что он действительно работает, прежде чем доверять:

```bash
comodor mcp test notes
```

```
  notes            started in 0.8s
    create_note    Create a note with a title and body
    search_notes   Find notes by text
    delete_note    Delete a note by id
```

---

## Включение и отключение

```bash
comodor mcp enable notes
comodor mcp disable notes
comodor mcp remove notes       # забыть его полностью
```

```
/mcp                           # то же самое, в интерфейсе
```

Отключённый сервер не запускается, и его инструменты не предлагаются.

---

## Это инструменты, как любые другие

Что бы ни предоставлял сервер, оно появляется рядом со встроенными инструментами
и проходит через **ровно тот же шлюз разрешений**. MCP-инструмент, пишущий файл,
спрашивает так, как спрашивает `write_file`. Заднего входа здесь нет.

## Проект может объявлять, но не включать

`.comodor/config.json` репозитория может перечислять используемые им серверы:

```json
{
  "mcp": {
    "servers": {
      "project-db": { "command": "npx", "args": ["-y", "@acme/db-mcp"] }
    }
  }
}
```

Это полезно: новый человек клонирует репозиторий и видит, чего ожидает проект.

**Они приходят выключенными.** Назвать сервер — это предложение; запуск одного
исполняет команду на вашей машине, и это ваше решение. Включите его, когда
посмотрите:

```bash
comodor mcp enable project-db
```

Проект не может задавать `mcp.enabled`, главный переключатель, вовсе.
[Безопасность](safety.md#what-a-repository-may-set).

## Транспорты

| | |
|---|---|
| **stdio** | команда, которую Comodor запускает и с которой общается через пайпы. Обычный случай |
| **Streamable HTTP** | сервер, уже работающий где-то, поверх HTTP |

Оба реализованы в пакете — без зависимостей ни для одного.

---

## Когда один ведёт себя плохо

Сервер, который не запускается или отвечает слишком долго, о котором сообщается
и который пропускается. Он не тянет за собой всю сессию.

```bash
comodor mcp test <name>        # запустить его и посмотреть
comodor doctor                 # включает каждый настроенный сервер
```
